核心技術一：初日制霸！氣功波壓制與近身打摔無限擇

不知火舞的首日最核心策略，便是利用其氣功波的簡易性與對手的不熟悉，建立無腦卻高效的壓制循環。

  • 操作指令：
    1. 遠/中距離壓制：持續施放 ↓↘→ + P (氣功波)。
    2. 命中/防禦確認：若氣功波命中對手或被防禦，立即步行或利用角色固有移速貼近。
    3. 近身擇：在對手身前執行 LP+LK (投擲) 或 LP / LK (輕攻擊) 進行打擊。
  • 打擊判定與幀數心法：
    • 氣功波：其發生幀數與彈道速度在初期對手難以掌握，會造成心理壓力。由於對手不熟悉，不易找到確反點，使得重複發波成為安全且高回報的選項。
    • 近身擇：在氣功波的掩護下貼近，即便氣功波被防禦，不知火舞通常處於近身有利或微不利幀數，這為簡單的 投擲 或 輕攻擊 創造了完美的50/50擇機。對手需要精準判斷是起跳、出輕攻擊解除投擲，或是防禦打擊。在不知火舞沒有花費資源的情況下，這是一個極度低風險高回報的壓制循環。
  • 實戰心法：
    • 低風險高回報：初期無需追求複雜連段，只需掌握「發波 -> 貼身 -> 投擲」這個基本循環。
    • 心理壓制：對手在承受重複投擲後，往往會選擇起跳或出輕攻擊來嘗試解投，此時可轉換為對空或反擊。
    • 角落效益翻倍：在角落，此壓制方式讓對手幾乎無處可逃，迫使其交出寶貴的Drive Meter資源或承受巨大傷害。

核心技術二：中蓄力扇/OD扇確認綠衝摔，建立全場威脅

當對手開始適應單純氣功波的壓力後，中扇/中蓄力扇與 OD 扇的快速確認綠衝摔將是不知火舞全場掌控局面的核心技巧。

  • 操作指令：
    1. 中扇/蓄力扇出招：在任何距離下施放 236MP 或蓄力 236[MP]（或 OD花蝶扇 236PP）【字幕校正：修正原手冊 214 指令】。
    2. 命中/防禦確認與綠衝：確認扇子牽制住對手時，立即發動生綠衝 (前前 + MP+MK) 快速貼身。
    3. 貼身打摔：綠衝貼身後，迅速執行投擲 (LP+LK) 或打擊擇。
  • 打擊判定與幀數心法：
    • OD中扇：其發生速度快，彈道穩定，且作為OD技通常具備更佳的有利幀數，即使被防禦也較安全。命中時，其硬直時間足夠不知火舞進行綠衝追擊。
    • 綠衝：命中確認後的綠衝，提供極大的貼身幀數優勢。此時對手處於被動硬直，無法反擊，被迫面對不知火舞的壓制。
    • 打摔：綠衝後的大量有利幀，讓投擲成為極難應對的選項。對手若選擇防禦，則會被投擲；若預讀投擲嘗試起跳或出招，則會被不知火舞的後續攻擊命中。
  • 實戰心法：
    • 高風險高回報的升級擇：相較於氣功波的簡單壓制，OD中扇確認綠衝摔是需要精準練習的「硬核」技巧，但一旦掌握，其威脅性將覆蓋全場。
    • 威懾力：一旦對手知道不知火舞能隨時從中距離發動此套路，他們將不敢輕易站立不動或進行鬆散的立回。
    • 應對「凹」：在某些情況下，OD中扇甚至可以用來引誘對手出「凹」技，然後利用綠衝的強判定或無敵幀進行反制。

核心技術三：角落高傷害上火連段與現代模式SA1連段效益

不知火舞在角落擁有極致的爆發潛力，其獨有的「上火」連段能最大化傷害與後續壓制。同時，現代模式玩家能更輕鬆地整合SA1，提供穩定高傷。

  • 操作指令：
    1. 角落高傷連段：雖然名師未給出具體指令，但強調需要耗費三格氣。此連段通常會涉及特定的特殊技、OD技組合，最後銜接SA技。
    2. 現代模式SA1連段：現代模式下，SA1通常透過簡單的 S + H 即可發動，且有許多內建連段能自然地將對手帶入SA1。
  • 打擊判定與幀數心法：
    • 三氣角落連段：其核心在於「打更痛」和「上火」。這意味著此連段不僅傷害數值更高，更能施加一種獨特的「火」狀態（或可理解為特殊的Oki狀態或額外傷害觸發），賦予不知火舞後續極大的壓制或資源優勢。對於幀數的理解，則需深入挖掘哪些特殊技或OD技能在連段中提供足夠的幀數連貫性以銜接最終的SA。
    • 現代模式SA1連段：現代模式的優勢在於簡化了連段操作，其內建的SA1連段設計得極為實用。雖然可能無法達到傳統模式的最高理論傷害，但其發生速度快、判定穩，且能直接將對手帶入一個高傷害且往往具備有利幀的狀態，使得資源利用效率極高。
  • 實戰心法：
    • 角落爆發威脅：一旦將對手逼入角落，不知火舞便擁有高額斬殺能力。學習並精通這個三氣角落連段，將是決定勝負的關鍵。
    • 「上火」狀態的利用：需深入研究「上火」狀態的具體效果，是持續性傷害、減緩對手Drive Meter恢復、還是提供額外的連段潛力，並據此調整後續Oki策略。
    • 現代模式的戰略簡化：對於不擅長複雜連段的現代玩家，利用內建的SA1連段提供穩定且可觀的傷害輸出，讓不知火舞的戰略更容易執行，降低了操作門檻，提高了實戰勝率。

大師避坑禁忌與天梯對局心得

  1. 盲目綠衝追擊：新手往往會過度使用綠衝 (DR) 嘗試貼近，尤其是在氣功波發出後。淡水人明確指出，在對手不熟悉時，簡單的「丟波 -> 步行貼近 -> 輕攻擊/摔」更有效率且安全。過早綠衝可能被對手對空或反擊，浪費寶貴的Drive Meter。

    • 高階修正訣竅：初期應先建立穩定的氣功波壓制與近身打摔循環，觀察對手的應對模式。當對手開始頻繁防禦或試圖反擊氣功波時，再導入中扇子確認綠衝摔的擇。綠衝應作為確定性進攻手段，而非探路。

  2. 忽視角落高傷連段的開發：許多玩家可能滿足於中等傷害連段，而未深入研究不知火舞在角落的爆發潛力。名師強調三氣角落連段的「更痛」與「上火」特性。

    • 高階修正訣竅：將不知火舞的角落壓制視為關鍵戰場。優先練習並熟練這個「上火」三氣連段，掌握其操作指令與最佳使用時機。這將顯著提升不知火舞的斬殺效率，並讓對手懼怕被逼入角落。

  3. 低估氣功波在大師以下區間的壓制力：玩家可能覺得氣功波是基礎技能而輕視，或在大師級別以上對手熟悉波戰而刻意規避。

    • 高階修正訣竅：明確認知不知火舞的氣功波在大師以下（包括大師本身）仍是極其強大的區域控制和心理壓制工具。不要因為其「簡單」而忽略其戰略價值。在不同級別的對局中靈活調整波戰強度，並與中扇、綠衝等手段結合，形成多層次的遠程壓制。

  4. 現代模式玩家過度追求複雜連段：現代模式的簡化操作有時會讓玩家誤以為需要尋找更長的連段來彌補傷害。然而，不知火舞在現代模式下，僅需「整天一直用一氣」即可有效。

    • 高階修正訣竅：現代模式玩家應將重點放在資源的高效利用，而非最大化連段長度。學會利用一氣的OD技維持壓制，並善用天生即可帶入SA1的連段，能更穩定地輸出傷害並維持戰場控制。其「下線不高」的特性，讓現代玩家更容易上手並打出有威脅的對局。

實戰關鍵 Q&A

Q1：對方習慣蹲防氣功波，不知火舞該如何打開防禦？ A1 (教練級解答)：當對手習慣蹲防氣功波時，正是轉入近身打摔擇機的絕佳時機。在氣功波命中或被防禦後，利用步行快速貼近對手，施展 LP+LK (投擲)。若對手被投擲數次後開始預判起身出輕攻擊解投或起跳，此時則可將投擲替換為 LP/LK (輕攻擊) 或 ↓+LK (蹲輕腳) 進行打擊，確認後銜接簡易連段，或直接接續更具威脅的特殊技。核心在於，氣功波本身是掩護你進入近身50/50擇的手段，而非單純的傷害來源。

Q2：進入中距離後，不知火舞的主要立回手段和確認技是什麼？ A2 (教練級解答)：不知火舞在中距離的立回核心在於 站中拳 (5MP)、站重拳 (5HP)、站重腳 (5HK) / 站中腳 (5MK) 和 蹲中腳 (2MK) 搭配綠衝 (DR)【字幕校正：修正原前推方向誤植】。 * 站中拳 (5MP)：具備良好的發生速度和判定，是一個非常可靠的確認起手技，能穩定銜接連段。 * 站重拳 (5HP) / 站重腳 (5HK)：具備極長的攻擊距離與強大壓制判定，用於中距離牽制與製造打康 (Counter Hit)。 * 蹲中腳綠衝 (2MK > DR)：蹲中腳的滑步距離優勢結合綠衝，讓不知火舞能迅速從中距離啟動進攻摸獎，是打破對方防線或拉近距離發動中扇確認打摔的重要手段。

Q3：我是現代模式玩家，不知火舞有哪些特別的優勢讓我能快速上手並具備威脅力？ A3 (教練級解答)：現代模式下的不知火舞擁有數項獨特優勢，使其成為新玩家或現代玩家的理想選擇： 1. 簡化的資源管理：你無需複雜思考斬殺連段，只需專注於「整天一直用一氣」來釋放OD技或維持壓制，大大降低了學習成本。 2. 高效的氣功波壓制：利用一鍵波動技能輕鬆發動花蝶扇，在大師以下級別，這種持續性的遠程壓制本身就極具威脅，許多玩家難以有效應對；若對手起跳則直接一鍵昇龍或一鍵 SA1 對空。 3. 便捷的SA1連段：現代模式天生就有內建的 Auto 中連段（歐中連段） 能穩定直接帶入 SA1【字幕補充】，這意味著你可以更頻繁、更可靠地打出高傷害並進入「焔」強化狀態，而不必苦練複雜連段。淡水人特別指出，相較於極度吃基本功的嘉米（Cammy），不知火舞具備非常簡便的上手手段與極高下限。 結合這些優勢，現代不知火舞玩家可以專注於立回和壓制策略，透過簡化的操作就能在天梯中打出亮眼表現。
