一、 什麼是合格的壓起身（Oki）？核心物理原則 (00:00 - 01:38)

一個高段位的標準起攻，必須同時滿足以下五大條件： 1. 贏起床搶輕拳 (Beat wakeup mashing)：敵人在 4F 搶鍵會被直接打出 Counter。 2. 贏起床搶投 (Beat wakeup throws)：先手打擊壓制直接碎投。 3. 贏起床起跳 (Beat wakeup jumps)：對手後跳或垂直跳直接在地面或空轉被截擊。 4. 贏起床暴躁迸擊 (Beat wakeup Drive Impact)：壓制技或波動能破除或及時回防。 5. 同時兼容兩種受身：無論對手是「原地起身 (In-place recovery)」還是「後受身 (Back recovery)」，公式化壓制均能穩定覆蓋！

壓起身的公式架構： $$\text{Oki} = \text{Frame Kill (幀數消費)} + \text{Meaty (持續壓制肉身技)}$$ - Frame Kill：透過特定前衝 (Dash)、綠衝 (DR) 或揮空拳腳 (Whiff move)，精準消耗對手倒地硬直的多餘時間。 - Meaty：使我方的攻擊剛好在對手起身的第 1 幀（Active Frame 1）或後續持續幀命中，從而獲得遠超常態的「被防禦有利 (+ob)」與「命中高傷確認 (+oh)」！

二、 中央場地擊倒壓起身 (Midscreen Oki) (01:39 - 10:13)

1. 弱龍卷 (214LK) 擊倒後 (01:39)

  • 明星神技：前衝 ➔ 214LP (弱波衝擊)：
  • 幀數效果：被防禦對我方 +2F 有利！命中 +2F，Counter 命中對手浮空 (ch Launch)！
  • 後續收益：
    • 被擋：我方處於 +2F 貼身優勢，直接進入打擊與普通投擲二選一。
    • 命中：直接確認接 5MP > 2MP > OD波拳 打出 2000+ 傷害並立即儲存電刃練氣 (Denjin Charge)，或推入版邊！
  • 手動步法：前衝 ➔ 微走 (Micro-walk)：
  • 前衝後按住前走約 7 幀：直接進入投擲射程，形成最自然的打擊/投擲二選一；也可跳過對手頭頂釣起床無敵昇龍。
  • 生綠衝偷摸：前衝 ➔ 綠衝 ➔ 2LK：
  • 下段偷摸，被擋 +2F，命中可確認接 4HP > 強足刀 (236HK) 獲取額外傷害與電刃蓄力。
  • 強足刀突襲：直接出 236HK：
  • 被擋也是 +2F 有利，打中起跳對手直接擊落，但缺點是動作大容易被起身 Parry。

2. 強昇龍 (623HP) 擊倒後 (03:32)

  • 前衝 ➔ 5HP (站強拳)：
  • 被擋 -1F（極度安全，對手完全無法反擊），命中 +4F，Counter +6F 隨後接連段。
  • 防守方如果因畏懼打擊而起跳，Ryu 有充裕時間拉昇龍對空。
  • 236LP (弱波拳) 遠程防空陷阱 (Anti-air Bait)：
  • 擊倒後原地放弱波拳。若對手後受身起跳想避開，剛好會跳入 Ryu 的強昇龍拳擊墜射程！
  • 綠衝壓中段：生綠衝 ➔ 6MP (鎖骨割中段)：
  • 被擋 +1F，命中 +6F，Counter +8F！破除蹲防神技。
  • 綠衝大技：生綠衝 ➔ 6HP / 6HK：
  • 6HP 被防禦 +5F 巨大有利；6HK 被防禦 +3F 有利！

3. 中龍卷 (214MK) 擊倒後 (05:35)

  • 最霸道綠衝：生綠衝 ➔ 5HP：
  • 綠衝 5HP 壓在對手起身上，被防禦高達 +5F 有利！命中 +10F，Counter +12F！ 對手防守壓力極大。
  • 無氣起攻：前衝 ➔ 2MP：
  • 被擋 -1F，命中 +7F。
  • 驚喜迸擊：直接按 DI (Drive Impact)：
  • 由於中龍卷推開距離遠，且靠近版邊，直接出 DI 經常能出其不意打出壁崩。

4. 重龍卷 (214HK) 換邊後 (07:17)

  • 成功逃離版邊換邊後的起攻：
  • 生綠衝 ➔ 5HP：被防禦 +2F，命中 +7F。
  • 236LP 遠程壓波：對手起跳直接昇龍擊墜。

5. 前投 (Forward Throw) 擊倒後 (07:46)

  • 警示：切忌在前投後按前衝 (Don't Dash)！
  • 前投擊倒後若前衝，Ryu 貼在對手面前是負幀 (Negative)，會直接被對手起床輕拳打出 Counter！
  • 正解方案： 1. 生綠衝 (Drive Rush)：接 5HP（Counter 命中 +16F！）、5MP 或 2MK 壓制。 2. 原地放弱波動拳 (236LP)：安全建立立回優勢。

6. 蹲強K (2HK 掃腿 / 滑鏟 Sweep) (08:28)

  • 普通命中：前衝 ➔ 5HP（被防禦 +2F，命中 +7F）。
  • Punish Counter 命中後的兩大神級 Frame Kill： 1. 6HK (旋風腳) 揮空消費：旋風腳長距離前探，剛好卡在對手起身的打擊/投擲二選一射程。 2. 奇蹟神技：原地垂直跳 (Neutral Jump) 幀數消費：
    • 掃腿打出 PC 後，原地垂直跳一次！
    • 落地瞬間剛好是 +2F 貼身有利！
    • 優勢：零鬥氣消耗，落地直接壓 2LK 或投擲，而且在空中能安全避開對手的起床無敵昇龍/SA！

三、 版邊壓制與投擲地獄 (Corner Oki) (10:14 - 18:15)

1. 版邊 強昇龍 (623HP) 擊倒後 (10:17)

  • 5LP 揮空消費 ➔ 214LP (弱波衝擊)：
  • 被防禦 +2F 有利！命中打出大連段。注意必須是 Frame Perfect（立即出招）。
  • 5MP 揮空消費 ➔ 5MP (Meaty)：
  • 被防禦 +2F 有利！極度穩定。
  • 直接 214HP (強波衝擊)：
  • 被防禦 +2F，直接削掉對手近半格鬥氣槽！
  • 職業選手 翔 (Kakeru) 專屬秘密神技：2MK 揮空消費 (11:39)：
  • 原理：版邊強昇龍後原地揮空 2MK，Ryu 剛好停在「貼身但恰好超出投擲範圍」的微觀距離！
  • 實戰制裁：專殺喜歡「延遲拆投 (Delay Tech)」的玩家！對手延遲拆投必定原地空抓，Ryu 不用後退直接在原地按 5HP 痛打 Punish Counter，且能直接防住對手的起床無敵技！

2. 版邊 前投 (Forward Throw) 投擲地獄 (12:22)

  • 5LP 揮空消費 ➔ 投擲 / 5MP：
  • 著名的 Ryu 版邊投循環 (Throw Loop)！揮空 5LP 剛好精準在對手起身的第 1 幀壓投，專破死防；對手若試圖拆投，出 5MP 痛打 3170+ 傷害！
  • 【字幕校正】直接 6HP (大戈斯 / Solar Plexus Strike)：
  • （原手冊誤植為 6MP，6MP 為中段鎖骨割，6HP 才是大戈斯）。
  • 剛好在第 3 幀壓中，被防禦 +1F 有利，且無法被對手起床 Parry 完美格擋！
  • 【字幕補充】若 6HP 成功打出 Counter，可直接確認接站強拳 5HP > 版邊連段，打出無資源 3,170 的高額版邊民工傷害 (BNB)。

3. 版邊 浮空輕昇龍 (Juggle 623LP) 後的起攻 (13:23)

  • 2LP 揮空消費 ➔ 236LP (弱波拳壓起身)：
  • 被防禦 +3F 有利！
  • 神級對策價值：敵方若企圖用 Level 1 SA 起床反抗（如 Cammy, Lily, Kimberly, Aki，這些 SA1 只有打擊無敵、沒有飛行道具無敵），會直接被波動拳撞爛打出 Punish Counter！
  • 214LP / 4HP 揮空消費 ➔ 打擊/投擲二選一 (+2F 有利)。
  • 5LK 揮空消費 ➔ 6HP (+1F 被擋有利) 或 6MP (中段破防)。

4. 版邊 中足刀 (236MK) 擊倒後 (14:19)

  • 5LK 揮空消費 ➔ 6MP (中段) / 投擲。
  • 214LP 揮空消費 ➔ 5MP / 投擲 (+1F 有利)。
  • 5LP 揮空消費 ➔ 立即迸擊 (DI)：壓在對手起身的瞬間。

5. 後投 (Back Throw) 評價 (15:05)

  • 後投擊倒對手後有利幀數差（只有 11F），強行壓進去極易挨打。
  • 唯一穩妥的進攻只有花 2 氣出 OD 波動拳 (236PP)。若不想花氣，建議原地站好保持立回，享受對手在版邊的站位劣勢即可。

6. 版邊 終極安全跳 (Safe Jump) 秘密路徑 (17:20)

  • 改版重要微調：
  • 版邊進行 3 氣連段（如通常技 > OD 龍卷 214KK）後：
  • 不要出強昇龍，改出「重足刀 (236HK) 浮空截擊」！
  • 擊倒後立即向前跳躍 (Jump Forward)，形成完美的 安全跳 (Safe Jump)！
  • 代價與回報：僅損失 50 點傷害，卻換來 100% 防住所有起床昇龍與 SA 的安全跳！

四、 必殺技與超必殺技擊倒壓起身 (Super Oki) (20:24 - 23:56)

  1. SA1 (真空波動拳, 版邊)： - 5LP 揮空消費 ➔ 5HP (Meaty)：被防禦高達 +2F 有利！
  2. SA2 (真・昇龍拳 蓄滿, 版邊)： - 214HK (重龍卷) 揮空消費：落地剛好在對手身邊形成 +4F 絕對先手，直接打擊/投擲二選一！
  3. SA3 (滅・昇龍拳) 擊倒後： - 版中可出 2 氣 OD 波拳誘騙防空；通常建議冷靜前進幾步，保持在最舒適的中距離立回射程。
