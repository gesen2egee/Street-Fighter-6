    在《快打旋風 6》中，「知道什麼招式能確反」與「能否在實戰中用最高傷害連段痛懲對手」是決定勝率的最核心基石。

    「天梯上大量對手之所以敢肆無忌憚地在中距離伸出各類必殺技（如迪潔中迴旋踢、春麗霸山蹴、將軍剪刀腳、吉米突進、瑪濃倒身踢），就是因為防守方在防住後常常發呆、或者只敢按一下輕拳抓癢！只要你把確定反擊的肌肉記憶練到 100% 成立，對手的立回體系就會在第一回合徹底崩潰！」

    五大角色核心必殺技微觀確定反擊深層解析

    第 1 章：瑪濃（Manon）——破除芭蕾步法的長臂揮動與倒身踢【00:00～02:04】

    1.1 站重拳（5HP 斧刃下劈）【00:06】

    • 微觀幀數：發生 12F，命中擊倒，近中距離被防 -6F（防守方 +6F 有利）。
    • 距離陷阱：
    • 若在極限尖端防住，防守方通常技會夠不到；
    • 但實戰中瑪濃常在壓制或綠衝中使用 5HP，深刺防住時防守方享有完整的 6 幀窗口。
    • 隆的最優確反：
    • 深刺防住瞬間，直接出 2MP（6F 發生，判定極佳）：
      2MP (Punish Counter) -> 2HP -> 236KK (OD 足刀) -> 623HP（穩定輸出 3,180 傷害！）。

    1.2 強倒身踢（214HK Dégagé）【00:32】

    • 微觀幀數：發生 24F，中段踢擊，被防硬直差為 -9F（防守方 +9F 有利）。
    • 深刺 vs 尖端的博弈：
    • 深刺防住時，隆直接出 2MK 或 2MP 進行地面確認；
    • オバハン 秘傳神技：若在最遠距離尖端防住，大掃腿（2HK）距離不夠容易揮空，「此時果斷使用 SA1（真空波動拳）或 SA3 進行超長射程確反！」，直接穿透空間將瑪濃打飛！

    1.3 弱倒身踢（214LK Dégagé 下段）【01:11】

    • 微觀幀數：發生 16F，下段滑擊，被防硬直差高達驚人的 -24F（防守方 +24F 有利）！
    • 隆的滿額處決：
    • 防住弱倒身踢後，隆有極充裕的時間走上前：
      走步 -> 蓄力 5HP (PC) -> 綠衝 5HP -> 4HK -> 214MK -> 623HP（輸出 4,200+ 傷害！）。

    1.4 ★SA2 換位陷阱——第 2 段打擊直接插斷！【01:26】

    • 瑪濃 SA2 的欺騙性：
    • 瑪濃的 SA2 是多段旋轉踢擊，若防守方老老實實防完，瑪濃會穿過防守方身體完成版邊換位，反而將防守方逼入版邊！
    • オバハン 直傳致命破綻：
    • 「防住 SA2 第 2 段打擊的瞬間，中間存在巨大的非連續防禦空隙！防守方可以直接用通常技打擊插斷（打撃で割り込む）！」
    • 隆的操作：防住第 2 段踢擊瞬間，立即按 2LP 或 5LP，直接在動作中將瑪濃打斷擊落！不僅阻止了換位，更原地收下大確反！

    第 2 章：春麗（Chun-Li）——穿波霸山蹴的破綻與逆擇百裂腳的蹲姿神防【02:05～04:15】

    2.1 OD 霸山蹴（214KK 穿波跳踢）【02:07】

    • 招式盲區：
    • 很多玩家以為 OD 招式被防都是有利或安全，對春麗的 OD 霸山蹴不敢動彈。
    • 真相：OD 霸山蹴被防硬直為 -5F（防守方 +5F 有利）！
    • 隆的最速確反：
    • 防住瞬間，隆直接出 5LK（5F 發生）：
      5LK (PC) -> 623LP (輕昇龍拳) 或 5LK -> 236MK (中足刀)！

    2.2 弱霸山蹴（214LK）與霸山蹴空中打落【02:26～02:50】

    • 弱霸山蹴被防：硬直差為 -9F，防住用 2MP 或 2HP 確反。
    • 中/強霸山蹴：被防無確反，但前搖長達 25F+。
    • オバハン 空中打落心法：
    • 「霸山蹴在起跳騰空途中，全角色都可以用輕拳（小技）直接打落！」
    • 看到春麗起跳空翻，隆原地站按 5LP，春麗直接在空中被打落強制倒地！

    2.3 弱/中天昇腳（623K 昇龍）【02:53】

    • 防住硬直差為 -8F，隆 2MP 穩定帶入滿額連段。

    2.4 ★春麗的「逆擇弱百裂腳」——蹲姿完全揮空神技！【03:06～04:15】

    • 春麗的惡毒套路（逆択）：
    • 春麗倒地起身時，極度喜歡凹「弱百裂腳（236LK）」。若防守方上前走投，投擲發生前會被百裂腳踢中打出 Counter Hit！
    • オバハン 揭秘的幾何死穴：
    • 「弱百裂腳對處於『下蹲姿態（しゃがみ）』的角色完全打不中（当たらない）！」
    • 隆的破解策略：
    • 策略 A（下蹲等待打空）：壓起身時做下蹲防禦（1），春麗的百裂腳在隆頭頂連續踢空，隆原地出 5HP (PC) 痛懲！
    • 策略 B（+5F 完美壓投）：在防守方取得 +5F 以上優勢時直接前進走投，百裂腳發生 12F，直接在起手被隆抓走！

    第 3 章：將軍（M. Bison）——剪刀腳各強度確反與 OD 剪刀腳 -15F【04:16～05:35】

    3.1 剪刀腳（Double Knee Press 4蓄6K）微觀確反表【04:21～04:51】

    • 【字幕校正】將軍剪刀腳為蓄力必殺技，正確指令為 4蓄6K（原誤植為 236K）。
    • 弱剪刀腳 / 中剪刀腳：被防 -5F（隆 +5F 有利）。
    • 深刺時隆直接出 5LK（5F 發生）-> 236MK 穩定確反！
    • 強剪刀腳：被防 -4F（隆 +4F 有利）。
    • 防住瞬間出 2LP（4F 發生）-> 5LK -> 623HP 確反！

    3.2 普通精神衝擊（Psycho Crusher Attack 4蓄6P）【04:54】

    • 將軍玩家若出現連段確認失誤裸出普通精神衝擊，被防全強度為 -11F 到 -13F。
    • 隆防住直接出 5HP (Punish Counter) 綠衝滿額連段！

    3.3 OD 剪刀腳（4蓄6KK）——高達 -15F 的送命大失誤！【05:12】

    • 將軍出 OD 剪刀腳（4蓄6KK）被防後，硬直差為 -15F（隆 +15F 有利）！
    • 隆直接在眼前執行最大電刃處決連段：
      5HP (PC) -> 綠衝 5HP -> 4HK -> 214HP (電刃強波掌) -> 623HP -> SA3（輸出 6,100+ 傷害！）。

    3.4 【字幕補充】將軍下段滑鏟（3HK）與空中交差之確反【05:30～05:35】

    • 下段滑鏟（3HK）：即使在尖端防住也有破綻，深刺時防守方可直接以中攻擊（2MP/2MK）確反。
    • 空中位移交差：將軍空中突進交差飛越頭頂時，防守方轉身可直接使用綠衝（Drive Rush）迅速追擊確反！

    第 4 章：迪潔（Dee Jay）——中 Sobat 的 6F 確反與目標連段【05:36～07:14】

    4.1 中雙重迴旋踢（中ソバット 236MK）——必須確反的核心技【05:42】

    • 微觀破綻：
    • 中 Sobat 是迪潔在中距離最核心的牽制踢擊。被防硬直差為 -6F（隆 +6F 有利）。
    • オバハン 嚴肅警告：
    • 「如果深刺防住中 Sobat 你不出 6F 技確反，迪潔就會整場無限踢你，讓你立回極其痛苦！」
    • 隆的指令：
    • 深刺防住瞬間，按住 2 鍵推 2MP（6F 發生），100% 確反打入大連段！

    4.2 迪潔 5MP 目標連段 3段目【07:00】

    • 迪潔常用 5MP -> 5HP -> HK 進行連攜打亂動。
    • 防住第 3 段後，硬直差為 -8F（隆 +8F 有利）。
    • 隆直接出 5MK（8F 發生） 或 2MP 穩定確反！

    第 5 章：吉米（Jamie）——突進技確反與 OD 昇龍「垂直跳極限起手」【07:15～08:45】

    5.1 突進技（弱/中無影拳 236P）【07:18】

    • 弱版與中版無影拳被防為 -6F。深刺時隆出 2MP 穩定確反。

    5.2 ★OD 昇龍（點火杯）防住——「原地垂直跳」最大傷害神技！【07:49】

    • 常規玩家的確反：
    • 吉米 OD 昇龍被防硬直高達 +43F！多數玩家只會站在地面出 5HP 打康。
    • オバハン 親授職業級傷害最大化技巧：
    • 「防住吉米 OD 昇龍後，原地垂直跳起（垂直ジャンプ），在最高點按跳 HP！」
    • 為什麼垂直跳更強？
      • 跳 HP (Punish Counter) 命中享有更高的初期傷害與浮空加成；
