  • 核心定位：打破「隆是簡單角色」的刻板印象！詳細剖析隆在追求「極限理論值最大傷害（97~100 分）」時，全角色難度第一的嚴苛目押、微步（微歩き）、延遲（Delay）、電刃練氣（集中狀態）有無判定與性價比神級連段庫。

導讀：隆的「70 分」與「100 分」

Kawano 在開場直言：

「如果只是想拿 70 分，隆的連段確實很簡單；但如果要追求 90~100 分的最大理論值火力，隆在全快打 6 角色中難度絕對是最高級別的，甚至連職業選手都容易頭皮發麻！」

本影片分為兩大階段： 1. 入門與實戰基礎體系（00:09 ~ 12:57）：小技確認的壓起身陷阱、站中拳起手的氣槽效益、各類常用帶 SA 修正路線。 2. 窺探深淵（深淵を覗く人，12:57 ~ 30:25）：無敵技確反（Punish Counter）、集中（電刃）狀態切換、版邊撞牆（Wall Splat）、暈眩（Stun）斬殺與極限黑科技。

第一部分：隆入門必修與實戰關鍵連段體系 (00:09 - 12:57)

一、 小技（2LP / 2LK）起手的確認與壓起身陷阱

在 2025/6 版本更新後，重龍卷旋風腳著地硬直從 15F 縮短至 12F，倒地時間增加 5F，重昇龍拳更是核心擊倒技。但小技確認存在極深的心戰與距離細節：

1. 小技 3 發 vs 小技 2 發的致命差別

  • 小技 3 發（如 2LP ➔ 2LK ➔ 2LP ➔ 623HP 強昇龍）：
  • 雖然連段成立，但對手被推開太遠，起身後「隆完全不在普通投擲射程內」！對手只要後拉或站防，隆的投擲就會落空（空揮）。
  • 理論值最優解：小技 2 發確認（如 2LK ➔ 2LP ➔ 623HP 強昇龍）：
  • 目押難度高，但命中後擊倒，對手原地起身隆剛好在「密著投擲射程內」，即使對手後退也能穩穩抓到普通摔，形成絕對的打投二選一！
  • 新手妥協路線：小技 3 發 ➔ 214LK（弱龍卷）：
  • 若 2 發確認反應不過來，改接弱龍卷擊倒。
  • 後續壓制 Tech：弱龍卷擊倒後直接打出 214LP (弱波衝擊) 做持續幀壓制：
    • 若命中：可接 2MP (蹲中拳) 繼續打一套連段！
    • 若被防：對我方為 +2F 有利，剛好處於投擲距離！

2. 小技版邊專用持續中段 Setup

  • 在版邊小技確認接 623HP (強昇龍) 擊倒後：
  • 2LK (空揮消耗幀數) ➔ 6MP (中段鎖鏈手)：剛好成為持續幀命中！打對手蹲防並能繼續目押連段。

3. 小技取消綠衝 vs OD 龍卷的傷害效益

  • 2LK ➔ 2LP ➔ 取消綠衝 ➔ 4HP ➔ 236HK ➔ 623MP：花費 3 格鬥氣，傷害僅 1901。
  • 2LK ➔ 2LP ➔ 214KK (OD 龍卷) ➔ 623HP：僅花費 2 格鬥氣，傷害高達 1970！
  • 結論：小技打中若想補傷害，優先出 OD 龍卷，傷害更高且更省氣。

二、 站中拳 (5MP) 起手的傷害最大化與陷阱

站中拳是隆近身最關鍵的打擊技（被擋 +1F，命中可目押引強P）：

1. 經典零氣耗路線 (3280 傷害)

  • 5MP ➔ 4HP (引強P) ➔ 236HK (強足刀) ➔ 623MP (中昇龍)
  • 常見新手誤區：許多人習慣在 4HP 後接 OD 龍卷 ➔ 強昇龍，傷害只有 3180！不但白白浪費 2 格鬥氣，傷害反而比零氣耗的強足刀路線（3280）低了 100 點！

2. 綠衝滿氣極限斬殺 (6068 傷害！)

  • 鬥氣全滿時的極限延伸：
  • 5MP ➔ 4HP 取消綠衝 ➔ 5HP ➔ 4HP ➔ 【微步 (微歩き)】 ➔ 綠衝 2HP ➔ 236HK ➔ 623HP ➔ SA3
  • 白身兄い極限細節：在 4HP 後靠極短的「微步」偷回微量鬥氣槽，剛好能壓線打出最後的綠衝 2HP，打出 6068 滿血斬殺！

3. 3 格鬥氣的高性價比路線 (5984 傷害！)

  • 若起手只有 3 格鬥氣：
  • 5MP ➔ 4HP ➔ 214KK (OD 龍卷) ➔ 生綠衝 2MP ➔ 4HP ➔ 236HK ➔ 623HP ➔ SA3
  • 僅需 3 格氣即可飆出將近 6000 點傷害，性價比極高。

4. 電刃集中狀態下的 5MP 起手 (6200+ 傷害)

  • 集中狀態下，4HP 替換為 214PP (電刃強化 OD 波衝擊)：
  • 5MP ➔ 214PP ➔ 5HP ➔ 214KK (OD 龍卷) ➔ 生綠衝 2MP ➔ 4HP ➔ 236HK ➔ SA3
  • 初手直接用電刃 OD 波掌打出大崩潰，傷害直衝 6200 以上。

三、 版中中距離牽制與綠衝延伸

1. 2MK (蹲中K) / 5HP 取消綠衝的最優選擇

  • 標準推進路線：2MK ➔ 綠衝 4HP ➔ 214HP (強波衝擊) ➔ 214MK (中龍卷) ➔ 前前衝壓制。
  • 職業選手細節：綠衝後為什麼選 4HP（引強拳）而不是 5HP？因為 4HP 是隆所有強攻擊中增加 SA 量表最多的普通技！
  • 接 SA3 路線：
  • 最大傷害：2MK ➔ 綠衝 5HP ➔ 4HP ➔ 綠衝 5HP ➔ 4HP ➔ 623HP ➔ SA3。
  • 失誤備案（Ad-lib 救場）：若肌肉記憶失誤打出了強波衝擊，可在強波命中後不帶取消、直接手動目押 214MP (中波衝擊) ➔ SA3，挽救連段！

第二部分：窺探深淵——極致最優化連段庫 (12:57 - 30:25)

本區間為 Kawano 與「白身兄い」針對特定情境下的「數值理論極限」全面拆解。

一、 無敵技確反 Punish Counter (對手大升龍揮空)

對手出無敵技揮空落地時，隆有充足時間走位施展大傷害確反。

1. 零氣耗 (No Gauge)

狀態 起手與連段路線 傷害 關鍵難點與註解
集中無 / 有 皆同 5HK (PC) ➔ 4HP ➔ 236HK (強足刀) ➔ 623MP (中昇龍) 3760 最穩定之零氣極限。最後中昇龍可改為 OD 昇龍（4040 傷害）。不需要微步。

2. 鬥氣消耗 4 格以上（綠衝大傷路線）

狀態 起手與連段路線 傷害 關鍵難點與註解
集中無 5HK (PC) ➔ 214HP ➔ 綠衝 2HP ➔ 綠衝 2HP ➔ 236HK ➔ 623HP 4147 【微觀難點】：第 2 個綠衝 2HP 必須稍作延遲（Delay）輸入，否則後續強足刀無法全段打中！

3. 鬥氣消耗 2 格（OD 波衝擊路線）

狀態 起手與連段路線 傷害 關鍵難點與註解
集中有（穩定版） 5HK (PC) ➔ 214PP (電刃OD波) ➔ 2HP (空振/低空命中) ➔ 214MP ➔ 623HP 4260 命中後自身鬥氣會回補 1 格，性價比超高！
集中有（極限版） 5HK (PC) ➔ 214PP (電刃OD波) ➔ 【微步】4HP ➔ 236HK ➔ 623MP 4460 【深淵級難度】：214PP 後必須精準微步接 4HP，搖桿選手極易失誤。

二、 確反 PC 帶 SA 終結最優解

1. 帶 SA1 路線

集中有（2格氣） 5HK (PC) ➔ 2HP (空中) ➔ 214HP ➔ 旋風 OD 龍卷 ➔ SA1 4680 雙重浮空判定，傷害極其穩定。
強足刀 PC（集中有） 236HK (PC) ➔ 旋風 OD 龍卷 ➔ 強化 SA1 4880 集中狀態下 SA1 獲得電刃強化，一發蒸發近半條血！

2. 帶 SA2 路線（零氣耗核彈）

集中有（零消耗，5HK起手） 5HK (PC) ➔ SA2 第一段 ➔ 4HK ➔ 623HP (強昇龍) 5500 零鬥氣消耗直接打出 5500 傷害！（5HK 起手打 SA2 浮空角度剛好能接強昇龍）。
集中有（零消耗，強足刀起手） 236HK (PC) ➔ SA2 第一段 ➔ 4HK ➔ 236MK (中足刀) 5860 【白身兄い極微觀提醒】：強足刀起手若最後打強昇龍會變成擦傷（カス当たり），改接中足刀才能全段命中飆至 5860！
集中無（2格氣） 5HK (PC) ➔ 2HP (空中) ➔ OD 龍卷 ➔ SA2 第一段 ➔ 4HK ➔ 623HP 4640 穩定好記的實戰備選。
集中有（2格氣） 5HK (PC) ➔ SA2 第一段 ➔ 4HK ➔ 623KK (OD 昇龍) 5620 補上 OD 昇龍的極限斬殺。

三、 版邊撞牆 (Wall Splat) 最優化

1. 常規與花氣最優化

  • 零氣耗：5HP ➔ 214MP ➔ 623HP
  • 花氣最優化（2HP 綠衝起手）：2HP ➔ 綠衝 2HP ➔ 236HK ➔ 623HP (2544 傷害)。

2. 集中狀態版邊撞牆

  • 零氣耗：2HP ➔ 214HP (強化波) ➔ J.MP (跳中P 2段命中) ➔ 空中龍卷 (J.214K) (2232 傷害)
  • 技巧：跳中拳必須打滿 2 段，隨後立刻取消空中龍卷。
  • 花氣路線（1格氣）：2HP ➔ 214HP ➔ 綠衝 5HP ➔ 236LK (弱足刀) ➔ 623HP (2789 傷害)。

3. 版邊撞牆帶 SA 最優解

  • 帶 SA1：
  • 零氣耗：2HP ➔ 214MP ➔ SA1 (2560 傷害)。
  • 2 格氣（集中有無皆同）：旋風 OD 龍卷 ➔ SA1 (3088 傷害)。
  • 帶 SA2：
  • 集中有（零氣）：2HP ➔ SA2 第一段 ➔ 4HK ➔ 236MK (4080 傷害)。
  • 集中無（2格氣）：2HP ➔ OD 龍卷 ➔ SA2 第一段 ➔ 4HK ➔ 623HP (3296 傷害)。
  • 集中有（2格氣）：2HP ➔ SA2 第一段 ➔ 4HK ➔ OD 昇龍 (4272 傷害)。
  • 帶 SA3：2HP ➔ 綠衝 2HP ➔ 綠衝 2HP ➔ 236HK ➔ 623HP ➔ SA3。

四、 對手破防暈眩 (Stun) 處理與深淵黑科技

對手因燃盡（Burnout）在版邊被 Drive Impact 撞牆暈眩時，硬直時間長達 200F 以上：

  1. 第一動作鐵則：原地打出 22P (電刃練氣) 存好集中狀態！
  2. 零氣耗穩定路線： - 前跳 J.HP ➔ 4HP ➔ 236HK ➔ 623MP (2780 傷害)。
  3. 花 2 格氣（強化 OD 波掌路線）： - 前跳 J.HP ➔ 214PP (電刃OD波) ➔ 前前 (前衝) ➔ 2HP ➔ 214MP ➔ 623HP (3020 傷害)。
  4. 帶 SA1 路線： - 零氣耗：前跳 J.HP ➔ 5HK ➔ 2MK ➔ SA1 (2970 傷害)。 - 2 格氣：強化 OD 波掌 ➔ 旋風 OD 龍卷 ➔ SA1 (3480 傷害)。
  5. 帶 SA2 路線： - 零氣耗：生 SA2 (第 2 段微蓄力釋放) ➔ 4HK ➔ 623HP (4040 傷害)。 - 2 格氣：生 SA2 (第 2 段微蓄力釋放) ➔ 4HK ➔ OD 昇龍 (4160 傷害)。
  6. 帶 SA3 傳統路線 vs SA2>SA1 黑科技： - 傳統滿氣 SA3 路線傷害約 4972。 - 深淵爆發體系：SA2 ➔ 綠衝 2HP ➔ 214MP ➔ 623HP ➔ 銜接 SA1，傷害高達 5231！消耗 2+1 條 SA 槽，傷害直接超越常規 SA3！
  7. 白身兄い極限玩具：Delay 波動拳接 SA1 (【字幕校正】3020 傷害)： - 原地 22P 存氣 ➔ 後退步 (Backdash) ➔ 垂直起跳 J.HK ➔ 落地 5HP ➔ 【延遲 (Delay) 236P 波動拳】 ➔ SA1 (真空波動拳)！ - Kawano 在實況中直接傻眼：「延遲波動拳接 SA1？！你這是出大學聯考題目吧？！」 - 機制解密：利用後退垂直跳的落地距離差，5HP 後故意慢半拍出波動拳（依角色不同部分角色最速也可，但為保險建議延遲），剛好在對手浮空即將落地的最後幾幀命中，硬直判定剛好能連上 SA1！比常規無氣 SA1 (2970) 再多出 50 點傷害（達到 3020）。 - 【字幕補充】：白身兄い最後也笑稱，其實「旋風腳 (OD旋風腳) 帶 SA1 的資源轉換效率實在太高，實戰中其實全部情境無腦接旋風腳也完全說得通」。

總結：Kawano 的實戰心法建議

面對白身兄い列出的龐大深淵資料庫，Kawano 給出最真誠的建議： 1. 切勿一次全背：全部硬背只會讓大腦當機（頭パンク）。 2. 先挑 5 個核心套路熟練： - ① 小技 2 發確認出重昇龍（搶回投擲射程）。 - ② 中P起手不浪費氣，打 5MP > 4HP > 236HK > 623MP。 - ③ 昇龍確反帶 SA1：一律記 旋風 OD 龍卷 ➔ SA1。 - ④ 昇龍確反帶 SA2：集中狀態下一律記 SA2 第一段 ➔ 4HK ➔ 623HP / OD昇龍。 - ⑤ 暈眩時務必先原地 22P 存氣。 3. 逐步邁向理論值：當這 5 套刻進肌肉記憶後，再依照自身對局情況，逐步引入微步目押與延遲技巧，邁向 97 分的頂尖隆！
