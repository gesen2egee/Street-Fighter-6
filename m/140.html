    🔄 第一章：春麗的三大基本進攻循環與底層邏輯 [00:00 - 00:52]

    影片開宗明義指出，春麗的所有戰術運作，都是圍繞著其「鬥氣量表（Drive Gauge）」在三種狀態之間不斷循環：

    mermaid graph TD A[狀態 1：綠槽充盈] -->|下中K/追突拳 消耗 3 格取消綠衝| B[狀態 2：氣槽匱乏] B -->|後退拉開距離 施放強氣功拳安全回氣| C[狀態 3：氣槽回滿] C -->|發射極慢弱氣功拳 隨波前衝推進佔領版面| A

    1. 循環 1（強攻推進）：當春麗手握 3 格以上鬥氣時，在中距離瘋狂使用「下中K (2MK) ➔ 取消綠衝」或「追突拳 (5MP) ➔ 取消綠衝」，以高速突進將對手逼入近身攻防。
    2. 循環 2（安全蓄氣）：綠衝猛攻結束後，春麗進入氣槽低下期，此時她會主動後拉至遠距離，施放全體硬直極短的「強氣功拳 (4蓄6HP)」來干擾對手並快速回復鬥氣。
    3. 循環 3（隨波壓制）：氣槽回滿後，春麗轉為施放飛行速度極慢且貫穿全螢幕的「弱氣功拳 (4蓄6LP)」，自己跟在氣功波後方高速前推，將對手一步步壓迫進版邊。

    [!IMPORTANT]
    面對春麗，絕對不能用同一套防守邏輯貫穿整場！必須觀察春麗當下的「鬥氣存量」精準切換應對模式：氣多時防其綠衝陷阱、氣少時步進封殺其強氣功回氣、隨波時頂住壓力絕不後撤！

    🟢 第二章：情境對策 ①——春麗綠槽充盈時的防禦與搶招 [00:52 - 02:19]

    當春麗手握 3 格以上綠槽時，地面立回的核心威脅就是下中K（2MK）與追突拳（5MP）的取消綠衝。

    1. 立回端應對方針

    • 差合（Whiff Punish）意識：春麗的 2MK 伸出距離長，但收招判定留存明顯，可利用中距離稍退半步的走位，以 2MK 或 5HP 差合其空揮。
    • 故意防住並以防禦反擊切斷節奏：若在牽制距離防住其取消綠衝，春麗消耗了整整 3 格鬥氣。此時防守方手握充足防守資源，可考慮以「無敵技（OD 昇龍 / SA）」或「Drive Reversal（鬥禦反擊，防住中輸入 6HP+HK）」強行打斷其攻勢，直接沒收對手的 3 格綠槽回報！

    2. 春麗 Cancel 綠衝後的常見壓制與致命陷阱

    當防住春麗的「2MK / 5MP ➔ Cancel 綠衝」後，春麗常規有三種進攻手段：
    - 手段 A：最速弱拳（2LP / 5LP）：利用綠衝加幀構成連續防禦（連ガ），確認命中或維持微有利。
    - 手段 B：中拳（5MP / 2MP）：強行搶佔 +2F~+3F 絕對先手，開啟打擊 vs 普通投的 50/50 猜拳。
    - 手段 C（致命陷阱！）：延遲前強K（6HK，踏步前重K）！

    ⚠️ 致命陷阱剖析：延遲 6HK 專殺「延遲拆投（遅らせグラップ）」

    • 春麗玩家的心理：春麗綠衝貼身後，多數防守方為了同時防下小拳打擊與防摔，會習慣性使用「延遲拆投」。
    • 春麗看準這一點，會在綠衝滑行稍微停頓後，按下 6HK (踏步前重K)！
    • 6HK 的發生較慢（17F），剛好會精準打在防守方延遲按下普通摔的拆投動作空揮上！
    • 觸發 大破綻懲罰（Punish Counter）！春麗後續可接續大傷害浮空連段，直接帶走 40%~50% 體力並搬入版邊！

    [!CAUTION]
    鐵則：防住春麗的 Cancel 綠衝後，絕對不可盲目使用延遲拆投！
    在春麗面前濫用延遲拆投，等同於主動將自己送上 6HK PC 暴斃的斷頭台！

    6HK 被防後的幀數與破綻

    • 若春麗使出 6HK 且你冷靜蹲防防住，被防幀數為「0F（雙方五分，互不佔優）」！
    • 應對手段：防住 6HK 的瞬間，立刻按下你角色的最速 4F 輕攻擊搶招（4フレ暴れ）！只要春麗敢出任何大於 4F 的動作，必定被你打斷！

    3. 春麗近身戰惡習：小拳預約中拳（2LP ➔ 中攻擊入れ込み）

    • 統計顯示，春麗在綠衝逼近後，除了普通摔之外，最普遍的動作就是：弱P (2LP) ➔ 中攻擊 (5MP 或 2MP) 預約。
    • 原因剖析：如果 2LP 打出 Counter Hit，中攻擊能形成連段。但春麗玩家無法在單發 2LP 命中的瞬間用肉眼確認是否命中，因此無論對手是防住還是挨打，春麗玩家有高達 80% 以上的機率會「手癖預先輸入」中攻擊！
    • 終極反制神技：
      👉 防住春麗第一發 2LP 的硬直結束瞬間，立刻以最速時間按出我方的「中拳 (5MP，6F)」還擊！
    • 春麗的 2LP 被防後只有微弱優勢，接續中攻擊時存在極小縫隙。
    • 我方的最速中拳會直接截擊並 Counter 春麗預約的中攻擊！
    • 一旦成功打出 Counter，防守方即可帶入整套中攻擊確反大連段，徹底打崩春麗玩家的預約心理！

    🎮 第三章：訓練場特訓 ①——中攻擊預約連攜打斷特訓 [02:19 - 03:14]

    在訓練模式中重現春麗手癖預約，訓練自己在防住 2LP 後果斷反搶 5MP：

    🎯 假人錄製設定

    • 假人動作（Slot 1）：下中K (2MK) ➔ Cancel 綠衝 ➔ 蹲弱拳 (2LP) ➔ 站中拳 (5MP)
    • 假人動作（Slot 2）：下中K (2MK) ➔ Cancel 綠衝 ➔ 蹲弱拳 (2LP) ➔ 普通摔
    • 假人動作（Slot 3）：下中K (2MK) ➔ Cancel 綠衝 ➔ 延遲 6HK

    🏋️ 特訓執行重點

    1. 面對 Slot 1：練習在防住 2LP 的第 1 瞬間最速按下 5MP，體驗連續 Counter 截擊春麗中拳的爽快反擊。
    2. 面對 Slot 3：練習忍住不按拆摔，穩穩防住 6HK 後以 4F 輕技（2LP/5LK）點停春麗。

    🔴 第四章：情境對策 ②——春麗氣槽匱乏時的強弱氣功拳破解 [03:14 - 04:12]

    當春麗將鬥氣消耗至僅剩 1~2 格時，為了避免陷入氣絕（Burnout），她必然會後撤使用飛行道具「氣功拳（4蓄6P）」牽制，並在安全距離拖延時間以恢復綠槽。

    1. 強氣功拳 vs 弱氣功拳的微觀特性比較

    飛行道具強度 發生幀數 飛行速度 射程範圍 全體硬直 (Total Frames) 被防/命中特性
    弱氣功拳 (4蓄6LP) 14F 極慢 全螢幕（貫穿） 47F 飛行時間長，可隨波前進推進
    中氣功拳 (4蓄6MP) 12F 中等 中遠距離 45F 常規牽制波
    強氣功拳 (4蓄6HP) 10F 極快 短射程（畫面約 60% 處自動消失） 42F（全遊戲頂級神速收招！） 專門用於快速回氣，消失後無判定
    OD 氣功拳 (4蓄6PP) 10F 極快（2段） 全螢幕 40F 被防 +2F，耗費 2 格氣槽

    2. 強氣功拳的「Parry 誘騙陷阱」

    • 常見實戰慘劇：遠距離看到春麗出波，防守方反射性按下格擋（Parry）想要回氣。結果發現春麗放的是「強氣功拳」，氣功波在半空中就自動消失了！
    • 防守方按住 Parry 卻格擋空氣，白白消耗半格至一格鬥氣，反而加速了自己的氣槽劣勢！

    3. 正確應對：徹底貫徹「步進防禦（歩きガード）」

    • 面對春麗的強氣功拳，遠距離嚴禁無腦長按 Parry！
    • 採用 「往前走兩步 ➔ 下後蹲防」 的步進走防節奏。
    • 慢慢向前壓縮春麗的後撤空間，一路推進到我方通常拳腳能夠碰到的距離。
    • 只要在近中距離揮出一發拳腳擊中春麗或逼其防禦，就能強行中斷春麗的自動回氣機制！

    4. 盲目起跳的致命後果：強氣功收招極快！

    • 許多玩家以為看到春麗放波就能大跳痛懲。但春麗的強氣功拳全體硬直僅有 42 幀（甚至比豪鬼的 47F 波動拳還要少 5 幀硬直！）。
    • 若非在春麗出招前搖的第一瞬間「極限預讀起跳」，只要稍有遲疑才起跳，春麗早就已經完全收招，好整以暇使用天昇腳（22K）或站強K（5HK）將你擊落！

    🟡 第五章：情境對策 ③——春麗氣槽回滿後的「弱氣功隨波」化解 [04:12 - 04:45]

    當春麗氣槽恢復健康後，進攻模式立刻切換為：施放飛行速度極慢的「弱氣功拳 (4蓄6LP)」，隨後緊貼著氣功波一起「生綠衝」或「大步向前」進行全場推進。

    1. 鐵律原則：「絕對不後退（下がらないが大前提）」！

    • 春麗隨波推進的根本戰略目的就是「逼迫對手後退、無成本收割版面，將對手推入版邊」。
    • 如果對手因為害怕氣功波而一路後退，剛好正中春麗下懷，不出三秒就會被逼入絕境版邊！

    2. 核心破解技術：迎著波向前「步進 Just Parry」

    • 執行手法：不要後退，反而要大膽向前走一步，算準弱氣功拳觸碰身體的瞬間按下格擋，抓取 完美格擋（Just Parry）！
    • 戰略價值：
    • 打斷推進節奏：完美格擋觸發的瞬間，全場動作產生凍結時停。
    • 反抓春麗確反：緊跟在氣功拳後方衝過來的春麗，往往因為來不及剎車，直接撞上我方的最速反擊拳腳（如 4F/5F 連段），打出 Punish Counter！
    • 即使未觸發 Just Parry，普通的普通格擋（Parry）也能完全無傷吸收氣功，並成功將防線穩固在原點，粉碎春麗侵吞版面的企圖。

    🧠 第六章：春麗三大操作死穴深度剖析與破局法門 [04:45 - 06:47]
