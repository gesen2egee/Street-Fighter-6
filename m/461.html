    第一章：傑米的核心優劣勢剖析（長所與短所）

    1.1 傑米的兩大王牌長處（00:26）

    1. 極度恐怖的「削氣進攻能力」（Drive Burnout Machine）：
    2. 傑米擁有極其優秀的綠衝、連續技以及大K壓制判定。
    3. 只要大K或中足碰觸到防禦的對手，配合後續的取消與流水連段，能夠以極快的速度蒸發對手的鬥氣計量條（Drive Gauge）。
    4. 當對手陷入氣竭（Burnout）後，傑米可以在角落展開幾乎不可脫離的無限壓制狂潮。
    5. 0杯自帶無敵升龍技（OD張弓腿）（02:49）：
    6. 與很多弱勢角色不同，傑米開局 0 杯就擁有標準的完全無敵技（OD張弓腿 22KK）。
    7. 這讓傑米在起手弱勢的第 0 杯階段，依然具備頂級的凹昇龍防守反擊能力，對手不敢毫無顧忌地肆意壓制。

    1.2 傑米的兩大致命短處（03:06）

    1. 0杯基礎傷害僅有 90%（打中完全不痛）：
    2. 傑米在 0 杯時，所有通常技、特殊技與必殺技的傷害倍率被強制閹割為 90%。
    3. 即使猜對起手、完成了完整的連續技，對手血條也只掉一小截，讓新手產生「我打中三次不如別人打中一次」的挫折感。
    4. 開局招式受限且缺乏傳統氣功波：
    5. 核心破防工具（無影腳、指令投）在開局全數鎖死，必須承擔立回風險喝酒才能逐步解鎖。

    各等級核心實戰評析：

    1. 0 杯 ➔ 1 杯（質變關鍵點，07:15）：

    3. 只要升到 1 杯，傑米的跳入威脅立刻翻倍！
    4. 1 杯 ➔ 2 杯（回到凡人基準線，08:00）：

    7. 2 杯 ➔ 3 杯（破防維度全面突破，08:45）：

    第三章：立回與連段中的「安全飲酒法」

    3.1 立回篇：什麼時候可以安全喝酒？（10:15）

    1. 大距離擊飛後的確認飲酒：
    2. 例如使用重流水連段將對手推到遠端版邊時，雙方距離超過半螢幕，此時手動原地喝酒（22P）是 100% 安全的。
    3. 預讀對手被動後退時偷喝：
    4. 當對手被傑米的大K牽制打退、或者對手因忌憚綠衝而拉後防禦時，在確認對手沒有綠衝動作的瞬間偷喝一口。
    5. 警告：絕不可在對手中距離隨意喝酒：
    6. 傑米喝酒收招硬直極長，對手中距離看見動作直接生綠衝或波昇突進，傑米會吃到大確反痛痛連段！

    3.2 連段篇：連段中如何穩定升杯？（13:40）

    1. 魔身派生連段（基礎款）：
    2. 下輕拳 ➔ 下輕拳 ➔ 輕魔身（22LP）：極速將酒量從 0 杯拉到 1 杯的最穩健路徑。
    3. 流水第三段喝酒派生：
    4. 下中拳 ➔ 236P ➔ P ➔ 4K（飲酒派生）：將對手擊倒並自動喝下一杯酒。
    5. 代價分析：選擇 4K 喝酒會拉開雙方距離，失去緊接著進行壓起身（Okizeme）的機會。前中期（0~2杯）優先選喝酒，後期（3~4杯）優先選壓起身！

    第四章：綠衝與超必殺技（SA）連段體系

    4.1 核心綠衝連段（Drive Rush Combo，17:10）

    1. 中足綠衝起手：
    2. 2MK（中足）➔ 綠衝 ➔ 下強拳（2HP）➔ 236HP（重流水）
    3. 若為 2 杯以上，可派生出更高的浮空與追擊。
    4. 生綠衝偷襲起手：
    5. 生綠衝 ➔ 前強拳（6HP）或 前中拳：利用綠衝加幀強行搶到有利幀（+4以上），直接銜接點心指令投或打擊擇。

    4.2 SA 超必殺技的正確打開方式（21:15）

    1. SA1（絕唱，236236P）：
    2. 快速突進，適合在連段收尾打推板、或者中距離抓對手波動收招。
    3. SA2（天下無雙，214214P）——傑米的勝負手！：
    4. 效果：發動期間直接將酒等級瞬間提升至 4 杯滿級狀態！
    5. 實戰時機：
      • 當處於 0 杯或 1 杯劣勢時，不要再慢慢喝，直接開 SA2 變身。
      • 變身後傑米具備完全體攻擊力與指令投，配合綠衝能給予對手極大心理威脅。
      • 注意：計量條結束後會退回原本的酒量，因此變身期間必須以極高侵略性打出實質血量差或直接斬殺！
    6. SA3 / CA（月牙叉手，236236K）：
    7. 標準高傷害收尾，在 4 杯狀態下 CA 傷害極為毀滅。

    第五章：大師級醍醐灌頂——「什麼時候絕對不要喝酒！」

    這是 うりょ 老師在全片中特別標註「知らないと損」（不知道就虧大了）的最核心心法（24:45）：

    5.1 兩大「絕不可喝酒」的致命禁忌情境：

    1. 情境一：對手血量進入斬殺線（Lethal Range）時：
    2. 許多傑米玩家玩出「強迫症」，明明對手只剩最後 20% 血量，擊倒對手後卻依然順手去按 22P 喝第 4 杯酒。
    3. 大師怒斥：這時候喝到 4 杯毫無意義！你喝了這口酒，對手安全起身拉開距離，原本必勝的局面瞬間又被對手拖入立回博弈。斬殺期必須把所有回合拿來壓起身打死對手！
    4. 情境二：對手處於氣竭狀態（Burnout）時：
    5. 對手氣竭時是傑米整場最賺錢的「黃金收割期」。傑米的大K、中足流水在角落能把氣竭的對手壓到窒息甚至打出眩暈（Stun）。
    6. 如果你在這個時候跑去喝酒，對手會藉機喘息並快速恢復鬥氣條，白白浪費了千載難逢的壓制期！

    第六章：為什麼玩傑米會覺得打不出傷害？（27:40）

    很多玩家抱怨傑米「刮痧」，うりょ 指出了三大常見毛病：
    1. 輕拳摸到後沒有做有效確認：
    - 輕拳摸到後只隨便打了個小技能，沒有取消綠衝或打出完整的連段。
    2. 在 0 杯階段浪費太多資源硬拼：
    - 0 杯傷害只有 90%，在 0 杯時砸光 6 格鬥氣去打大連段，性價比極低；0 杯的資源應優先用於「安全打擊並快速喝到 1~2 杯」。
    3. 沒有將對手逼入角落與氣竭：
    - 傑米的真正高傷害不是單發，而是「壓入角落後的連續起攻」與「指令投/打擊二擇」的複合傷害。

    第七章：傑米強勢的立回距離與作戰心法（30:40）

    1. 大K的絕對領域（中遠距離）：
    2. 傑米的大K發生距離極遠、判定強硬。在對手前進或企圖出招時用大K卡位，摸到就進入削氣優勢。
    3. 中足與綠衝的中近距離威脅：
    4. 處於 2 杯以上時，中足命中可隨時取消綠衝展開毀滅連段；對手若龜縮，則利用綠衝點心指令投直接強開防禦。
    5. 核心作戰哲學總結：

      「傑米不是那種靠一兩次大賭博硬破防的角色；傑米是用極速的大K牽制把對手削進氣竭，用穩健的升杯解鎖全新武器，在對手喘不過氣的瞬間用點心與高威力連段將其徹底埋葬的全面型狂戰士！」
