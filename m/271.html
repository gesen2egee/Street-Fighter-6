核心技術一：重肩撞（Power Charge, 214HK）延遲取消深度解析

招式機制：Terry Bogard 的重肩撞 (Power Charge, 214HK【字幕校正：修正原誤植為 623HP】) 在命中對手後，會有一段獨特的滑動位移動畫。此「延遲取消」技術的核心，便是在重肩撞命中的動畫結束、特瑞開始向前滑動至特定時間差後，才輸入後續必殺技指令，而非最速取消。這讓連段的時機點更具彈性，並能達成一些原本無法最速連接的連段，同時大幅優化傷害輸出。

操作指令與打擊判定： - 基本指令: 214HK (重肩撞 / Heavy Power Charge【字幕校正】) - 打擊判定: 通常命中兩下。若為「懲罰反擊」(Punish Counter, PC)，則可命中三下。命中次數是判斷後續連段的關鍵。

K.T. 大師專屬時機判斷心法: 01:30 K.T. 教練強調，最有效的抓取時機方法是觀察「特瑞滑出去的那個感覺」。利用訓練模式的 50% 慢速功能 01:37，觀察特瑞在撞到對手後，人會先停頓一下再滑出去的動畫細節。依據特瑞滑出的距離或時間長短，判斷不同的取消時機。

三種延遲取消類型:

  1. 慢一咪咪取消 (Slow 1-frame-ish Cancel)

    • 時機判斷: 02:06 「你覺得他要滑了，按你就出招。」即在特瑞命中停頓後，感覺他剛要開始滑動時，立即輸入取消指令。
    • 應用場景:
      • 火焰踢 TC 追擊: 02:17 (例: 6MK -> 重肩撞 (慢一咪咪取消) -> 236HK) 用於確保連段穩定且有足夠時間連接。
      • 綠衝中拳搬運連段: 02:23 在綠衝 5MP 起手後，若需綠衝 5MP 本身帶有延遲（例如搬運連段），但個人對綠衝延遲按不準確，K.T. 建議 02:39 可改為「重肩撞延遲一點點出地波」，後續的綠衝中拳便可最速輸入，增加連段穩定度。

  2. 慢兩咪咪取消 (Slow 2-frame-ish Cancel)

    • 時機判斷: 02:54 讓特瑞在命中後「滑出去一點點」，「抓他滑比較久一點點的那個時機」。更具體的說，03:08 是「特瑞感覺好像快滑過對手下面，從下面穿過去的那個時機出招」。
    • 打擊次數判斷與後續連段:
      • 若重肩撞命中三下 (PC): 03:32 確認打出三下後，立即取消接 重昇龍 (623HP)。
      • 若重肩撞命中兩下: 03:38 為了保險起見，K.T. 建議取消接 中昇龍 (623MP)，確保必中，即使提早取消有時能接重昇龍，但中昇龍的穩定度更高 04:03。
    • 應用場景:
      • 重地波 (236HP) 追擊: 04:10 「慢兩咪咪」取消是連接重地波的關鍵時機，重地波後可進一步連接 SA1，是低反擊和懲罰反擊的核心高傷害連段。

  3. 慢三咪咪取消 (Slow 3-frame-ish Cancel)

    • 時機判斷: 05:14 「你就慢很多出就對了。」這是一種非常長的延遲，取消窗口非常大，容錯率極高。
    • 應用場景: 05:28 主要用於連接 CA (Critical Art)，例如 JCA (Jump Cancel Critical Art) 等特殊連段。

核心技術二：低資源高效率傷害連段策略

K.T. 大師展示了重肩撞延遲取消如何在低資源消耗下，為 Terry 帶來驚人的傷害回報，特別適用於各種反擊情境。

1. 低反擊 (Low Punish) 標準連段 * 指令: 00:20 低反 -> 6MK (前中腳【字幕校正】) / 3HP -> 重肩撞 (214HK 慢兩咪咪延遲取消) -> SA1 * 傷害: 約 3000 * 資源消耗: 1條SA能量槽 * 戰略價值: 實用的低反擊對空連段，將對手的低位攻擊或失誤跳入，即刻轉化為可觀的傷害，無需消耗驅動槽。

2. 低反擊 (Low Punish) 進階連段 * 指令: 00:43 低反 -> 6MK (前中腳) -> 重肩撞 (214HK 慢兩咪咪延遲取消) -> 重地波 (236HP) -> SA1 * 傷害: 3600 * 資源消耗: 1條SA能量槽 * 戰略價值: 在消耗相同 SA 資源下，透過精準的「慢兩咪咪」取消接重地波，進一步提升傷害。且此連段無需版邊限制，泛用性更高，是 Terry 玩家必練的高效率反擊手段。

3. 無資源懲罰反擊 (Punish Counter) 極限傷害連段 * 指令: 04:49 防禦住昇龍拳 (DP Punish) -> 5HP/2HP PC -> 重肩撞 (214HK 慢兩咪咪延遲取消) -> 重地波 (236HP) -> SA1 * 傷害: 3880 * 資源消耗: 0條驅動槽，僅1條SA能量槽 * 戰略價值: 這是 Terry 在對手 DP 失誤後，最致命且幾乎「無資源」消耗的高傷害懲罰連段。利用懲罰反擊特性完美銜接重肩撞延遲取消，接上重地波確保 SA1 的連接，造成近 4000 的巨額傷害，是決勝關鍵時刻的必殺技。

4. 綠衝 (Drive Rush) 起手搬運連段 * 原始困難點: 02:30 某些綠衝起手的搬運連段，例如綠衝中拳後需體感延遲才能接續。 * K.T. 推薦優化: 02:39 若對綠衝延遲輸入不準，可改為：綠衝中拳 -> 重肩撞 (214HK 延遲一點出地波) -> 重地波 -> 後續綠衝中拳則可「最速」輸入。 * 實戰範例 (綠衝 2HP 起手): * 高難度版本: 06:01 綠衝 2HP (延遲地波) -> 重肩撞 (214HK 延遲) -> SA1。傷害約 3500。此版本需要高難度精準延遲地波。 * K.T. 推薦穩定版本: 06:33 綠衝 2HP (最速地波 236P) -> 火焰踢 (6MK) -> 重肩撞 (214HK 延遲) -> SA1【字幕校正】。傷害約 3500 (少約40傷)，但穩定度大幅提升。 * 戰略價值: 透過延遲重肩撞的運用，即使在綠衝連段中也能找到更穩定、傷害不俗的銜接方式，有效將對手從版中搬運至版邊，或達成高輸出。

核心技術三：延遲取消的實戰輸入心法與容錯機制

指令輸入心法：分解動作，建立節奏 07:05 K.T. 大師分享的核心秘訣是：「我自己覺得把它指令分散在整個動作過程中去轉，會比較簡單。不要等到最後一刻再去抓。」這與許多玩家在最後一刻快速輸入全部指令的習慣相反。 * 實際操作: 以「慢兩咪咪」取消為例，當特瑞向前滑動時，將「下往後轉」的指令 (214) 平均分攤在這小段時間裡輸入 07:15。同樣地，慢一咪咪的火焰踢 (623K) 指令，也是將 623 分攤在特瑞滑動期間 07:34。 * 戰略價值: 這種分散輸入的方式，能有效幫助玩家建立連段的節奏感 (Rhythm)，減少因單點輸入時間壓力造成的失誤，從而提高指令的穩定性和成功率。這是一種將爆發性輸入轉化為流程性輸入的思維轉換。

練習策略：善用訓練模式的慢速功能 01:37 K.T. 強烈建議利用遊戲內建的「50% 慢速」功能。在慢速下，玩家可以更清晰地觀察特瑞命中後「人會停一下再滑出去」的微觀動畫細節 01:42，從而更精準地掌握不同「咪咪」取消的時機點。這對於培養視覺判斷與手感至關重要。

容錯機制：低風險高回報 08:12 一項極為關鍵的優勢是：「這些延遲取消的東西，你就算放槍了也不會被懲罰。」這意味著即使你沒有成功抓到最完美的延遲時機，導致取消失敗或連段未按預期進行，你也不會因此被對手懲罰或陷入不利幀數。這大大降低了學習和實戰中嘗試該技術的心理門檻，鼓勵玩家大膽練習與應用。

大師避坑禁忌與天梯對局心得

  1. 延遲時機判斷失準:

    • 禁忌: 新手常因過早或過晚取消而導致連段失敗，無法最大化傷害。例如「慢一咪咪」按成最速取消，或「慢兩咪咪」拖得過久導致無法取消。
    • 修正訣竅: K.T. 大師建議 01:30 專注於特瑞「滑出去的那個感覺」，這是核心。務必利用訓練模式 50% 慢速功能 01:37 進行反覆練習，將視覺判斷與肌肉記憶結合。寧可稍晚一點讓出招機會，也不要過早導致指令不成立。

  2. 重肩撞命中次數判斷不清:

    • 禁忌: 慢兩咪咪取消後，若未能準確判斷重肩撞是命中兩下還是三下 (PC)，便可能導致後續昇龍拳選擇錯誤而落空。
    • 修正訣竅: 03:59 K.T. 提供了「保險轉法」：若打三下接重昇龍 (623HP)，若只兩下則接中昇龍 (623MP)。雖然兩下有時也能接重昇龍，但中昇龍的穩定性更高，能確保連段成功。實戰中應優先追求穩定度。

  3. 指令輸入過於急促或僵硬:

    • 禁忌: 許多玩家習慣在取消窗口的最後一刻，快速且一次性輸入所有指令，導致 timing 難以精準掌控，節奏感差。
    • 修正訣竅: 07:05 K.T. 的「把指令分散在整個動作過程中去轉」是關鍵心法。將方向鍵或按鈕指令平均分攤在特瑞滑動動畫期間輸入，有助於建立連段的「節奏感」，而非單純的「速度」，讓輸入更流暢自然。

  4. 未善用低資源高回報機會:

    • 禁忌: 錯失低反擊、懲罰反擊等關鍵時機，未能將其轉化為高傷害連段，浪費寶貴的機會。
    • 修正訣竅: 熟練掌握 00:43 的低反 -> 6MK -> 重肩撞 (慢兩咪咪) -> 重地波 -> SA1 (3600傷)，以及 04:49 的 DP 懲罰 -> 2HP x2 -> 重肩撞 (慢兩咪咪) -> 重地波 -> SA1 (3880傷)。這些連段幾乎不消耗驅動槽，卻能造成驚人傷害，是改變戰局的重要手段。

實戰關鍵 Q&A

Q1: 在快節奏的天梯對局中，如何快速判斷重肩撞是否打了2下或3下，以選擇正確的後續連段？ * 教練解答: 實戰中，快速判斷 2 下或 3 下主要依賴視覺和聽覺提示，並將其與肌肉記憶連結。 1. 視覺判斷: 3 下命中通常會在視覺上感覺命中時間稍長，或對手被擊飛的高度/角度有微小差異。在慢速模式下多觀察這些細微差別。 2. 聽覺提示: 留意命中音效，3 下命中的音效頻率會比 2 下更快、更緊湊。 3. 肌肉記憶與保險: 最重要的是，透過大量的重複練習，讓你的手在感受到重肩撞命中後，能本能地根據「懲罰反擊」的觸發提示（畫面閃爍或聲音特效）來判斷是否為 3 下。如果判斷時間過於緊迫，K.T. 的「兩下接中昇龍」保險策略 03:59 是最穩妥的選擇，即使損失少量傷害，也確保連段成功，避免因連段失敗而被反打。

Q2: 泰瑞的重肩撞延遲取消是否適用於所有起手式？在何種情況下應優先使用？ * 教練解答: 重肩撞延遲取消並非萬能，但它在特定情境下價值極高，應優先用於： 1. 懲罰反擊 (Punish Counter): 無論是防禦住昇龍拳、錯失跳入的空中反擊、或是對手指令投失誤，重肩撞延遲取消能最大化 PC 的傷害收益 04:49。 2. 確認反擊 (Confirm Punish): 當你確定命中對手，特別是低位攻擊如 2MK 或 6MK 起手的確認，重肩撞延遲取消能有效連接高傷害後續 00:43。 3. 特定連段延伸: 當你需要將對手搬運至版邊，或在綠衝連段中需要更穩定的取消點來銜接特殊技（如地波）時，延遲取消提供更寬裕的時機 02:39。 不優先使用場景: 在簡單的確認連段或需要快速壓起身、打亂解的場面，選擇更直接、快速的連段會更有效率，不需額外承擔延遲取消的時機判斷壓力。

Q3: 如果我對KT教練提出的「看特瑞滑出去的感覺」抓 timing 方法不適應，還有其他輔助判斷技巧嗎？ * 教練解答: 每個玩家的體感和視覺偏好不同，找到最適合自己的方法是關鍵。除了 K.T. 提供的「滑動感覺」和 50% 慢速練習法 01:30，你可以嘗試： 1. 聽覺回饋: 專注於重肩撞命中時的音效。有些玩家可以透過音效的「長度」或「節奏」來判斷延遲時機。例如，在命中後心中默數一個節拍或等待特定音效結束。 2. 對手動畫觀察: 除了特瑞自身，也可以觀察被擊中對手的動畫變化。例如，對手被擊飛後開始下墜的瞬間，或身體到達某個視覺參考點時，作為取消的依據。 3. 肌肉記憶的節奏: 將重肩撞命中後的動畫與你的指令輸入想像成一個固定的「節奏」或「韻律」。嘗試跟隨這個內在節奏來輸入，而非單純的視覺反應。不斷試錯，你會找到最能讓你穩定輸入的個人化節奏點。
