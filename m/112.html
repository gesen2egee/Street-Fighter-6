    112. 格ゲーゴリラ やさい - 1分鐘掌握 Year 2 嘉米 (Cammy) 核心對策

    來源影片：1分でわかるYEAR2のキャミィ対策【SF6 ver 202502】（作者：格ゲーゴリラ やさい，長度：1分09秒，SF6 Ver 202502 最新版）

    🎯 核心概念：終結被「壓起身循環 (起き攻めループ)」滾雪球 (00:00 - 00:06)

    在快打旋風 6 (SF6) 對戰嘉米（Cammy）時，最常見的敗因（負け筋）絕大多數都是「被捲入無休止的壓起身循環」。
    而嘉米能夠發起壓起身循環的核心始動技只有 3 招：
    1. 中足（2MK / 2中K）
    2. 強旋風拳（強ナックル / Heavy Spin Knuckle）
    3. 低空刺踢（空中ストライク / Cannon Strike）

    👉 防守大原則：只要在立回與防守中牢牢封鎖並化解這 3 招，對戰嘉米的勝率就會呈現質的飛躍！

    🦵 一、中足 (2MK) 防守鐵則：提防「壓制結束後的前走偷踢」 (00:06 - 00:14)

    1. 中足的危險命中時機

    • 嘉米的中足比起純粹的遠距離立回牽制，更常出現在「近身連段壓制（固め）結束後」。
    • 嘉米通常在輕攻擊點完後，藉由超快的步行速度往前走一步突刺中足，誘導對手搶招並命中確認進入大連段。

    2. 應對核心：防住 2~3 發輕攻擊後切勿貪心

    • 嘉米在近身打完 2~3 發弱攻擊（2LP/5LP） 後，攻勢在物理距離上已經無法自然連續。
    • 守則：此時絕對不要貪心搶招（欲張らないようガードしよう）！老老實實拉後蹲下防守，嘉米前走伸長的中足就會被我方穩穩防住，完全無法發揮威脅。

    👊 二、強旋風拳 (Heavy Spin Knuckle) 破解與「D 反偷雞確反」 (00:14 - 00:27)

    1. 遠距離進攻的意識分配

    • 嘉米意圖：在遠距離時，嘉米常利用強旋風拳的穿波屬性進行穿越飛行道具、或是長距離突進強行搶回優勢幀回合。
    • 距離破綻：在此遠距離下，嘉米「無法踢出具備壓制力的強勢低空刺踢（強いストライクが撃てない）」。
    • 防守心法：此時在意識中直接排除刺踢威脅，將 100% 的專注力全部分配給旋風拳（ナックルのみに意識を向けてOK）！

    2. 攔截與應對手段

    • 弱攻擊點掉：目視到旋風拳啟動前搖，直接按出 4F/5F 輕攻擊（2LP/5LP）迎頭截擊，直接打出 Counter！
    • 完美格擋（Just Parry / ジャスパ）：若反應快或距離較近，直接瞄準打擊瞬間按 Parry 觸發完美格擋，直接進行 Punish Counter 大連段懲罰！

    3. 🔥 重點防禦反擊：D-Reversal 之後的「偷雞旋風拳」必確反！

    • 嘉米詐欺套路：當嘉米防住我方的 D-Reversal（Dリバ / 鬥氣反擊）後，非常喜歡用強旋風拳壓起身，企圖利用幀數優勢強行繼續壓制。
    • 真相：這純粹是偷雞行為（ぼったくり）！
    • 破解法：我方起身直接出 4F 弱攻擊（4フレーム技で割り込める），必定能搶在旋風拳打擊判定成立前插動擊中，打出 Punish Counter！

    🦅 三、低空刺踢 (Cannon Strike) 判定機制與「前走防禦」神技 (00:27 - 00:40)

    1. 刺踢的兩大核心戰略用途

    1. 著地時機錯位（着地ずらし）：破壞對手的防空時機，讓昇龍拳等對空技打空。
    2. 踩對手出招揮空（技の空振りを踏む）：抓對手揮動牽制技的瞬間由空中踐踏壓制。

    2. 「微不利」時的致命出招陷阱

    • 情境：嘉米在弱攻擊 2~3 發被防、中腳 (5MK/2MK) 被防、或強腳 (5HK) 被防後，嘉米處於「微不利」狀態。
    • 常見失誤：對手誤以為輪到自己的回合，急著出下段蹲姿技（しゃがみ技打ち返し，如 2MK / 2MP）進行反擊。
    • 結果：嘉米早就預讀並起跳低空刺踢，直接將我方的出招破綻踩中，造成 Punish Counter 並帶入慘痛的大連段！

    3. 正解對策：「前走防禦 (前歩きガード)」奪回主動權

    • 消極對策：在嘉米微不利時，保持耐心蹲下防守，不盲目出長硬直招式。
    • 積極正解（神技）：「前走一步立即防禦（前歩きガード）」！
    • 原理：當我方往前走時，嘉米的下落低空刺踢會被迫踩在我方的上半身或高位（高位ガード）。
    • 結果：低空刺踢在極高位置被擋下時，嘉米的負幀數大幅增加，直接轉為我方大幅有利的狀況（状況有利），瞬間搶回絕對先手權！

    🔄 四、嘉米壓起身 (起攻め) 全情境防守手冊 (00:40 - 01:03)

    1. 被普通投後的前驅衝刺（投げ＞ラッシュ） (00:40 - 00:44)

    • 嘉米套路：普通投擲將我方摔倒後，立即接生綠衝（Drive Rush）進行壓起身。
    • 破解法：起身使用「橫向判定長 / 位移大的 OD 無敵技（横に長いOD無敵技，例如隆的 OD 昇龍拳、泰瑞 OD 能量灌籃等）」，可以直接越過身位將嘉米的衝刺完全打穿！

    2. 弱連段 ＞ 螺旋箭 ＞ 即發 DI（弱攻撃＞アロー＞DI） (00:44 - 00:49)

    • 嘉米暗箭：嘉米在輕攻擊確認螺旋箭（アロー / 236LK 或 236MK）打中或被擋後，對手往往專注於起身防打擊或防投，嘉米在此時極度喜歡「冷不防即按 DI（鬥氣衝擊）」，命中率奇高！
    • 破解法：對戰嘉米時，被輕/中螺旋箭擊倒後，在意識中隨時預留「準備反擊 DI（意識を向けて返そう）」的反應餘裕，一見紅光立刻回敬 DI 反打！

    3. 終盤斬殺時的 OD 旋風拳（ODナックル）換邊逆向 (00:49 - 00:53)

    • 局面：在殘血或斬殺局面（リーサル場面），嘉米常使用 OD 旋風拳快速突進穿身繞背（裏回り）。
    • 破解法：正反向極難目視且壓力極大時，直接使用防守格擋（パリィ / Parry），格擋可同時全方位防禦正逆向攻擊，穩健化解對手的致命突擊！

    4. 強螺旋箭命中後的壓起身陷阱（強アロー＞前ステ＞2HP＞投げ） (00:53 - 01:03)

    • 幀數與情境：嘉米強螺旋箭 (236HK) 命中後前前衝刺（前ステ），嘉米處於 +3F 先動（3フレーム先に動ける） 的優勢。
    • 陷阱破解：
    • 防投：因為前前衝刺後雙方有一小段距離，嘉米若想直接摔人，投擲距離會不夠（抓空）！此時我方起身直接按 4F 弱攻擊搶招，必定能將投擲直接打斷（弱攻撃で割り込める）！
    • 防打擊：面對嘉米最愛的壓起身蹲強拳（2HP），可以抓準固定節奏瞄準 完美格擋（Just Parry / ジャスパ） 進行強力反打。

    5. 流氓組合技（フーリガン / Hooligan Combination）的殘酷現實 (01:03 - 01:10)

    • 實戰評價：截至 Year 2 / 202502 最新版本，面對嘉米的流氓組合技 (623P) 空中各派生，「目前幾乎不存在單一的萬用完全解答（完全解答はほぼない）」。
    • 應對心態：依然需要依賴對空意識與預讀應變，認清「這女人依然非常強大（まだまだ強いぞこの女）」並保持高度專注！
