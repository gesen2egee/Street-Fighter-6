  • 核心主題：胖胖拳（旋轉打擊）穿波應對、流氓組合派生猜拳破解、空插（雷擊蹴/刺踢）高低幀數判定、立回拳腳與關鍵偷招確反。

1. 胖胖拳（快旋旋風劍 / Spin Knuckle）穿波與貼近對策

  • 輕/中/重版本性能差異：
  • 輕、中版本：突進距離短，接觸到對手防禦時為負幀，通常較少裸出。
  • 重版本：具備長距離穿波無敵判定，轉進來防住後為正幀（Cammy 先動），對手若發波被抓到會被痛打一套大傷害。
  • 對策解法：
  • 【字幕補充】在立回或丟波節奏中，穿插站輕拳（Jab），能直接在半空中將旋轉中的 Cammy 點落，打亂對手抓發波硬直的預判，使其不敢輕易裸出胖胖拳。

2. 流氓組合（Hooligan Combination）派生破解

Cammy 的旋轉突進帶有多種空中派生，各派生應對如下： 1. 蓋頭（中段拳）：必須站姿防禦（專抓蹲防反應慢的對手）。依出招接觸點約 +1~+4F，若站防擋住高打點，可立即以 4F 站輕拳確反。 2. 急降落（假動作）：落地不攻擊，專門用來騙防空或防凹（Bait Reversal）。 3. 下滑（剃刀滑鏟 / 下段踢）：踢中後 Cammy 為 +2F 先動。 4. 空中指令投（Fatal Leg Twister）：血量進入斬殺線時極具威脅，對手集氣或 OD 版命中可接 SA3。對策為後後撤步（Back Dash） 或 原地垂直跳躍 避開並大確反。 5. 派生空插： - 膝蓋以上命中：防守方先動（可點拳腳確反）。 - 膝蓋以下命中：Cammy 先動。 - 【關鍵防守破解】壓起身起身時機選擇： - 【字幕校正】原手冊未說明起身體系。威森里指出：Cammy 很多流氓組合連段後壓起身是針對「後起身」設計的！ - 若防守方改用「原地起身」，Cammy 的流氓組合會直接飛過頭落空，落地硬直極大可實施最大確反（Punish Counter）。

3. 5HP 起始之 Target Combo（TC）防守陷阱

MR 1500 常見套路為 5HP 起始的 TC 連段，有兩個重要取消分支： - 取消點 1：取消空插： - 防住後雙方為 ±0F 平幀，防守方需點 4F 拳腳 搶先動主動權。 - 取消點 2：第二腳踢出後取消流氓組合或重胖胖拳： - 由於重胖胖拳進來為正幀，對手若無反應會被持續壓制。 - 對策：看到 TC 派生動作時保持注意力，直接用站輕拳點掉中斷其派生。

4. 空插（佳能突擊 / Cannon Strike）高低點判別與對空

  • 正負幀判定法則：
  • 踢中位置在膝蓋以下：Cammy 為正幀（先動）。
  • 踢中位置在膝蓋以上：防守方先動，可立即按拳腳打回去。
  • 立回與破綻捕捉：
  • 若在立回中察覺 Cammy 喜歡空插壓制（常抓對手出 2MK 下中腳的時機跳踢打懲罰），可適度使用 44（後後撤步） 或 原地跳 讓其踢空，趁其落地硬直進行確反。
  • 對空手段：防守方蹲姿看見空插起跳，可直接使用升龍拳或專屬對空拳腳（如 Dee Jay 對空）截擊。

5. 實戰關鍵博弈與確反細節

  1. 解摔後輕螺旋箭（地箭 / Spiral Arrow）突襲： - Cammy 拆投/解摔拉開距離後，常會突然賽一記「輕地箭」。 - 此距離即便未命中也不易被大確反；對策為解摔後適時後後拉開或原地跳應對。
  2. 角落 OD 胖胖拳換邊打背： - Cammy 在角落連段收尾後，可能使用 OD 胖胖拳飛越打背。 - 對策：防對方向防住後我方為 +2F（可搶先動）；亦可練習完美招架（Parry）或直接凹無敵技反擊。
  3. 連段收尾後「不能凹無敵技」的 DI 偷襲時機： - 角落升龍收尾後 Cammy 直接按 DI：此時防守方不能凹無敵技，必須將專注力放在反 DI（Impact）上。 - 場中輕螺旋箭收尾後 Cammy 前前（Dash）接 DI：同樣凹不到，必須集中精神反壓 DI。
  4. SA3 穿波預警： - 當 Cammy 擁有 3 條氣時，具備強大 SA3 穿波能力，防守方切勿在場中或起身隨意發波（如不知火舞集氣扇子絕對不能裸出）。
