    【SF6】瑪麗莎 (Marisa) 完全對策：霸體破壞、負幀確反與立回拆彈指南

    本筆記整理自技術對策神作：
    - 來源頻道：スト6初心者応援チャンネル (主講：ecu1)
    - 影片標題：【スト6】マリーザ対策【最新版】苦手な人必見！立ち回りや攻め方、強みや弱みまで徹底解説 (影片編號: vPdrBCK5P_4 / 104)
    - YouTube 連結：https://www.youtube.com/watch?v=vPdrBCK5P_4
    - 核心目標：徹底剖析瑪麗莎（Marisa）的鋼體霸體機制、中中目標連段派生猜拳、百夫長直拳（Gladius）、格擋架勢（Scutum）、立回垂直跳壓制與防守心態。

    快速導航與核心戰略地圖

    瑪麗莎動作 / 局面 瑪麗莎威脅點 核心破壞對策 備註與進階博弈
    中P中P (中中目標連段) 防禦 -8F 但派生 Gladius 敲碎反擊 Fuzzy 中足 (複合防禦下段踢) / 弱P截擊 Phalanx Gladius 只有上半身霸體，足元為致命破綻
    百夫長直拳 (Gladius 236P) 蓄力可碎 DI、OD 版吃兩段無敵技 下段踢 (2MK/2HK) 擊碎蓄力；無敵 SA 通殺 遇到普通直拳用 Parry 保留鬥氣
    躍空重壓 (Phalanx 214P) 防禦後瑪麗莎有利，陷入壓制循環 看見起跳立即 2LP / 5LP (小手點落) 打落後可接浮空追擊大連段
    中距離立回 突進拳、蓄力重拳、差合陷阱 極高頻率「垂直跳躍」 瑪麗莎難以對空垂直跳，多數突進直接揮空受死
    後強K (4HK 擺腿) 後撤步避開對手出拳，造成自動差合 Punish 切勿盲目地面差合，改以跳入進攻 對手擺腿時有後縮判定
    格擋架勢 (Scutum 236K) 吸收打擊後體撞 +3F 進入指令投二擇 近距離直接普通摔；中距離停步目認出招按 DI 姿勢對摔技無防備；派生出招前搖大，DI 必勝
    倒地起身 (被瑪麗莎壓制) 害怕高傷被指令投與打擊二擇 必須確實按「後受身 (後ろ受け身)」 後受身後非版邊瑪麗莎「根本抓不到普通投」

    防守解圍手段 亂凹無敵技被防吃 7000+ 傷害暴斃 改用鬥氣反擊 (D-Reversal) 被防處罰極輕，安全拒絕打擊與指令投

    一、瑪麗莎角色本質：「拆彈型角色 (爆弾処理タイプ)」

    1. 極致的火力傾瀉：
    2. 瑪麗莎是純粹將數值全點在火力的角色。一旦防守方因恐懼而死守，就會被其兇猛的普通投或指令投（「動くんじゃないよ」）擊潰。
    3. 只要防守方猜錯一次，往往直接損失 50%～70% 體力，導致一局瞬間崩盤。
    4. 本質並非無法解套的無賴，而是「拆彈遊戲」：
    5. 瑪麗莎缺乏穩定的波動拳（無遠程飛行道具），生綠衝速度平庸，對空判定角度存在天然死角。
    6. 她的招式多具有明顯的前搖、長收招硬直以及「霸體僅限上半身」的絕對致命弱點。
    7. 只要理解其機制並冷靜執行標準拆彈程序，就能將其完全封殺。

    二、關鍵連攜破解：中P中P (中中目標連段) 猜拳體系

    瑪麗莎最常見的地面壓制為 5MP -> 5MP (中P中P)。

    1. 表面數據與實戰陷阱

    • 表面幀數：5MP -> 5MP 防禦後，瑪麗莎為 -8F (我方 +8F 確反)。
    • 實戰陷阱：瑪麗莎玩家幾乎絕對不會停在 5MP -> 5MP 發呆，一定會取消必殺技進行逆向猜拳。最常見派生即為 百夫長直拳 (Gladius, 236P)。

    2. 對抗 Gladius 的博弈層級

    • 純防禦 Gladius：
    • 防禦普通 Gladius 後我方雖為 +5F，但因為被擊退距離極遠，大部分角色的 5F 輕技根本搆不到（形同無法確反）。
    • 防禦會被瑪麗莎大幅削去鬥氣量表（Drive Gauge）。
    • 最低底線：至少按下 Parry (鬥氣格擋) 吸收，避免綠條被大量消耗。
    • 猜拳第一層：無敵技 / DI (Drive Impact)
    • 中中防禦後按無敵技或 DI，可以直接中斷擊破「普通 Gladius」。
    • 猜拳第二層：瑪麗莎改出「蓄力 Gladius」或「OD 蓄力 Gladius」
    • 蓄力 Gladius：帶鋼體（Armor），會直接硬扛並粉碎你的 DI（DI 破裂吃 Punish Counter 痛擊）。
    • OD 蓄力 Gladius：擁有 2 段霸體，甚至能直接吃下一部分角色的 OD 無敵升龍拳，在對方下落時打出致死確反！
    • 猜拳第三層（終極對策）：下段踢破壞霸體 (足元攻撃)
    • 核心機制：Gladius（包含普通、蓄力、OD 版）的鋼體霸體判定全部只有上半身！
    • 破解法：只要攻擊足元（下段判定，如 2MK 中足、2HK 重掃腿），就能無視對手的霸體，直接將蓄力中的瑪麗莎踢翻！
    • 神技應用：Fuzzy 中足 (複合防禦中足 / ファジー中足)
    • 操作時機：維持蹲姿防禦，抓準「防住普通 Gladius 的瞬間」之後，立刻輕點 2MK（中足）。
    • 效果：
      • 若對手出的是普通 Gladius，我方剛好處於防禦狀態，穩妥防住；
      • 若對手在蓄力（溜め）普通或 OD Gladius，我方的中足會在時差空檔精準踢中其下半身破防，完成確反起手！
    • 使用超必殺技 (SA) 插動：
    • 帶有無敵的 SA 能打贏 Gladius 的所有衍生變化。
    • 注意：SA 發生需在 8F 以內；若為 9F 以上，瑪麗莎若只出中中停手防禦，可能來得及防住你的 SA。

    3. 中中派生躍空重壓 (Phalanx, 214P) 處理

    • 若瑪麗莎中中取消出 Phalanx，防禦後瑪麗莎處於大有利幀數，我方會被捲入強制壓制循環。
    • 破解法：看到瑪麗莎在中中之後跳起出躍空拳時，立即目認出 2LP / 5LP (弱P輕拳) 進行對空攔截！截落後可直接進行追加連段。

    三、立回（中距離周旋）核心對策

    瑪麗莎在中距離缺乏波，主要依靠突進技與擺拳：

    1. 萬能神解：極高頻率「垂直跳躍 (垂直ジャンプ)」

    • 瑪麗莎在開局～中距離最常使用的行動：
    • 躍空重壓 (Phalanx 214P) 突襲
    • 百夫長直拳 (Gladius 236P) 牽制
    • 生綠衝強P (Rush 5HP) / 綠衝中K (Rush 5MK)
    • 對策機制：上述所有招式在面對垂直跳躍時全部會產生嚴重的揮空判定！
    • 瑪麗莎缺乏能隨時反應處罰垂直跳的手段。在中距離積極進行原地垂直跳躍，只要對手一出突進技，落地就是滿血 Punish Counter 痛擊。
    • 此為歷代版本不變的黃金鐵則。

    2. 警惕地面擺拳陷阱

    • 蹲中拳 (2MP) 截擊：瑪麗莎常在地面預先擺 2MP，若我方貿然衝上前想抓差合，容易直接撞拳被接滿傷害連段。
    • 後強K (4HK / 引き強K) 自動差合陷阱：
    • 瑪麗莎出 4HK 時動作會「先微微向後縮步」，躲過你的牽制攻擊判定後再大腳踢出。
    • 盲目去抓 4HK 的差合極易被打出 Punish Counter。
    • 對策：遇到愛擺 4HK 的對手，不要在地面跟她比腳長，直接利用跳入攻擊直接制裁！

    四、防守與起攻（被壓制時的處理）

    1. 被瑪麗莎擊倒後的壓起身防守

    • 核心心法：務必每一次都輸入「後受身 (後ろ受け身)」！
    • 非版邊普通投「根本壓不到」：
    • 瑪麗莎普通摔、Gladius、Phalanx 命中擊倒後，就算開綠衝過來壓起身，只要我方有按後受身，瑪麗莎的普通摔是絕對抓不到的（只會埋進打擊）！
    • 既然對手沒有普通摔的威脅，我方防守完全不需慌亂猜摔，安心保持防禦即可。
    • 看見大動作重攻擊時按 Parry 補綠條，或練習 Just Parry（精準格擋）。
    • 例外情況：若被打出 Punish Counter 或 Hard Knockdown（不可受身硬倒地）時，瑪麗莎的指令投才會具有威脅，此時需專注讀指令投進行起跳或逆向對策。

    2. 我方壓瑪麗莎起身的重大變更 (原人狩り)

    • 舊版習慣廢止：以前瑪麗莎無 OD 升龍，大家習慣倒地直接壓摔（無腦投）。
    • 最新版危險：瑪麗莎的 SA1 追加了「防禦投擲的當身 (反擊技)」！ 盲目壓摔會被 SA1 當身反吃 2400 傷害並奉送起攻。
    • 目前最強壓起身策略：【原地垂直跳躍 (原人狩り)】
    • 在壓瑪麗莎起身瞬間原地垂直跳：
      • 避開瑪麗莎的起身拆摔 (Throw Tech)
      • 避開瑪麗莎起身的 Scutum (格擋架勢) 與 OD Gladius
      • 完美避開瑪麗莎的 SA1 當身、SA2、SA3 無敵技！
    • 對手無論出當身或無敵 SA 都會揮空，我方下落直接打一套滿額致死連段。
    • 瑪麗莎即便反應過來，最快也只能用 2HP 軟對空，風險回報極度傾向我方。

    五、格擋架勢 (斯庫圖姆 / Scutum, 236K) 徹底破壞

    瑪麗莎常在起身或立回突然擺出羅馬盾架勢 (Scutum)。

    1. 架勢弱點剖析

    • 吸收打擊後瑪麗莎可出體撞派生，密著 +3F，進入打擊與指令投的恐怖二擇。
    • 但 Scutum 完全沒有任何防禦投擲的判定！

    2. 具體應對步驟

    1. 近距離：看見擺架勢，無條件直接按普通摔 (投擲)，必定打出 Punish Counter。
    2. 中距離 (有一段間距)：
    3. 走過去摔會吃對方的中段派生（Enkidu）或指令摔（Hound）。
    4. 黃金對策：看見架勢立刻「停步 (止まる)」，確認對手一動立刻按 DI (Drive Impact)！
    5. 瑪麗莎如果不出派生，就是在白白浪費她自己的綠條；只要她按了中段拳或下段踢派生，動作前搖極長，我方目認到動靜按下 DI，DI 的霸體會吃下攻擊並直接將其砸出大破綻！

    六、對空與跳入博弈 (破解瑪麗莎 3 大對空)

    雖然跳躍對付瑪麗莎非常有效，但成熟的瑪麗莎有三種對空手段，需針對性拆解：

    1. 百夫長直拳對空 (Gladius 對空)

    • 現代模式 (Modern) 瑪麗莎最常見的一鍵霸體對空。
    • 對策 1：空跳 DI (すかし飛びインパクト)
    • 跳起後空中不出任何按鍵（空跳），落地瞬間按下 DI！利用瑪麗莎出普通 Gladius 打擊的硬直打出 DI 痛擊。
    • 對策 2：空跳摔 (すかし飛び投げ)
    • 當瑪麗莎學乖改用「蓄力 Gladius」防禦 DI 時，我方空跳落地直接按「普通摔」，瞬間瓦解蓄力霸體！
    • 警惕：若瑪麗莎持有滿 3 條氣 (SA3)，她可能在 Gladius 命中時預先帶入 SA3，此時空跳 DI 需謹慎。

    2. 通常技對空 (2HP 蹲重拳)

    • 對策：逆向跳入 (めくりジャンプ / Cross-up Jump)
    • 瑪麗莎的 2HP 對空判定對頭頂與身後的逆向判定極為薄弱，極難打到逆向踢。大膽採用逆向跳切入。

    3. 空對空截擊 (J.MP -> J.MP 空中二段)

    • 對策 1：跳入早出招 (早出しジャンプ攻撃)
    • 跳躍後不等下落，在上升頂點提早揮出空中攻擊，在瑪麗莎起跳空對空之前先手將其打落。
    • 對策 2：地面生綠衝切入
    • 當對手全神貫注看著上方準備空對空時，地面完全不設防，直接使用生綠衝進行橫向突破。

    七、大局觀心態與防守脫困原則

    1. 防守時善用 Parry，不要死防到氣竭 (Burnout)：
    2. 瑪麗莎的招式極具大開大闔特徵，前搖明顯，多用 Parry 甚至練習 Just Parry 保持鬥氣計量。
    3. 切忌安易凹無敵技 (無敵ぶっぱは禁物)：
    4. 瑪麗莎對大破綻確反的連段傷害高達 7000+！凹一次被防就直接送掉一整局。
    5. 終極解圍法寶：鬥氣反擊 (D-Reversal / ドライブリバーサル)：
    6. 當陷入瑪麗莎的打擊與指令投二擇時，不要凹升龍，大膽使用 D-Reversal！
    7. 即使 D-Reversal 被瑪麗莎防住，瑪麗莎能打出的確反傷害極低；比起凹無敵技暴斃，D-Reversal 是性價比最高的拒絕猜拳神器！

    八、練習場 (Training Mode) 專屬訓練設定

    特訓 1：中中派生與下段破解練習

    • 錄製 Slot 1：5MP -> 5MP -> 236P (普通 Gladius)
    • 錄製 Slot 2：5MP -> 5MP -> 236P hold (蓄力 Gladius)
    • 錄製 Slot 3：5MP -> 5MP -> 236PP hold (OD 蓄力 Gladius)
    • 錄製 Slot 4：5MP -> 5MP (停住防禦)
    • 訓練目標：練習 Fuzzy 中足。防住普通直拳的瞬間出 2MK，若是普通版則正常防禦，若是蓄力/OD版則成功下段踢碎霸體。

    特訓 2：Scutum (格擋架勢) 動態目認反應練習

    • 錄製 Slot 1：OD Scutum (236KK) -> P 派生 (中段拳)
    • 錄製 Slot 2：OD Scutum (236KK) -> K 派生 (下段踢)
    • 錄製 Slot 3：OD Scutum (236KK) -> 什麼都不出
    • 錄製 Slot 4：OD Scutum (236KK) -> 投擲派生 (指令投)
    • 訓練目標：對手一架盾立即停步，看見對手身體一動（出派生）瞬間按 DI 反擊！若對手不動則不上當。
