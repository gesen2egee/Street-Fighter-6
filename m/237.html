3. 現代拉希德核心連攜大破解：TC 接 Cyclone 飛行派生

現代模式（Modern）拉希德在天梯鑽石至大師段位極其依賴其目標連段（Target Combo: 5MP -> 5HK），並藉由必殺技取消強行開啟空中特權。

5MP (站中拳) ──> 5HK (站重腳) ──> 弱 Cyclone (214LP) ──> 飛行派生 (Wing Stroke)
  (發生 6F)        (目標連段)        (地面旋轉硬直)           (空中滑翔下落)

3.1 為什麼被 Cyclone 命中後還能用 5LP 截落？

許多玩家在實戰中一旦被 Cyclone 刮到，心理上就認為自己「處於受創硬直，必須老實挨打」。 然而，拉希德的招式判定在底層設計中存在浮空時間差： 1. 弱 Cyclone 的受創硬直：弱 Cyclone 命中對手後，給予對手的受創硬直極短； 2. 飛行派生的起跳幀數：拉希德在 Cyclone 結束後轉入飛行派生（Wing Stroke），身體需要先騰空躍起約 14F，隨後才能出空中攻擊； 3. 5LP 搶動窗口：防守方從 Cyclone 的受創硬直恢復後，拉希德正好處於剛剛騰空、打擊判定尚未生成的脆弱期。此時防守方狂按 5LP（4F 發生），拳頭直接命中半空中的拉希德，將其當場擊墜！

3.2 防住 Cyclone 後的 +6F 確反大處決

如果防守方在地面保持站防或蹲防，擋下了弱 Cyclone： - 硬直差：防守方手握高達 +6F 的絕對先手權！ - 拉希德的絕境：拉希德此時停留在防守方臉上，完全無法防禦； - 隆（Ryu）專屬 +6F 處決連段： 2MP（6F 發生） -> 綠衝 5HP -> 4HK -> 236MK -> 623HP
- 傷害：約 3,450 點！直接將試圖偷幀的拉希德打進大失血。

4. 現代模式（Modern）vs 經典模式（Classic）拉希德的行為差異與針對策略

4.1 現代模式（Modern）拉希德的特徵與死穴

  • 特徵： 1. 擁有「一鍵昇龍（Spinning Mixer）」對空，任何起跳都會被最速擊落； 2. 擁有「一鍵 SA3（荒野風暴）」反應截殺，防守方在遠距離出大破綻招式會被秒抓； 3. 連段高度套路化，極度依賴 Assist + 中（5MP -> 5HK） 目標連段。
  • 針對策略：
  • 徹底封印盲目跳躍：面對現代拉希德，絕不無腦前跳，多在地面進行陣地波昇戰；
  • 專門蹲抓 TC 連攜：現代拉希德出 5MP 必定按完 5HK 接弱 Cyclone，防守方只需穩穩蹲防擋住，隨後用 2MP 啟動 +6F 處決連段！

4.2 經典模式（Classic）拉希德的特徵與死穴

  • 特徵： 1. 走位更加靈活，擅長利用各類蹬牆跳（Wall Jump）與阿拉伯天翔（Arabian Skyhigh）打亂動； 2. 具備更強的手動確認能力與多樣化壓起身擇。
  • 針對策略：
  • 保持在 2.3 身位，嚴密監控其起跳與旋風氣流；
  • 當其使用蹬牆跳時，向前前前衝步穿過其落點，反向關版邊！

5. 壓起身飛行派生之神級複合防禦心法（蹲防 + 延遲拆投）

拉希德在擊倒對手後，使用空中飛行派生（Wing Stroke）進行壓起身（Oki），是其最具視覺迷惑性的套路。防守方往往覺得「空中可能是中段踢，落地可能是下段滑踢，落地還能普通投，這根本沒法防」。

格鬥猩猩提出了一套數學期望值 100% 的神級複合防禦公式：

【壓起身面對拉希德飛行派生之複合防禦時間軸】
時間軸：0F ──────────────── 10F ──────────────── 20F ──────────────── 28F
拉希德動作：[ 空中飛行派生啟動 ] ──> [ 選擇 A: 空中踢 (中段) ]
                                    [ 選擇 B: 落地滑踢 (下段) ]
                                    [ 選擇 C: 落地前走抓投 (投擲) ]
                                           │
我方操作：  [ 拉希德身體一動 ] ──────────> [ 保持蹲防 (しゃがみガード) ]
                                           │
                                           ▼ 稍作停頓 (延遲 4~5 幀)
                                           [ 輸入 LP+LK (延遲拆投) ]

5.1 複合防禦對拉希德三擇的全面覆蓋：

  1. 情況 A：拉希德出空中中段踢： 拉希德若在空中提早按鍵出中段，其打點高且動作明顯。防守方在看見其空中出腳的一瞬間站防擋住，隨後反擊；
  2. 情況 B：拉希德落地出下段踢： 拉希德落地最速出 2LK 或 2MK，防守方的蹲下防守姿態正好將其穩穩擋下！
  3. 情況 C：拉希德落地出普通抓投： 防守方在蹲防擋住可能存在的下段打擊後，剛好迎來「延遲拆投」的輸入窗口，系統自動觸發拆投（Tech Throw），雙方彈開拉回均勢！

格鬥猩猩的結論：只要防守方貫徹「動了就蹲防、稍後延遲拆投」，拉希德常規的三擇手段將全部失效！拉希德若想攻破此防守，必須做出非常勉強的延遲大動作（例如長距離空翻後跳或賭命凹無敵技），防守方直接獲得巨大反制空間。

6. 徹底瓦解兩大主流「持續中段（持続中段）」套路

拉希德玩家最引以為傲的技巧之一，就是利用特定的招式後搖製造「持續幀中段」。

6.1 兩大套路動作分解

套路一：中鷹擊突刺套路

  • 流程：中鷹擊（214MK 命中擊倒） -> 原地揮空普通投擲（空投げ） -> 前中拳（6MP 中段）
  • 目的：利用揮空投擲消耗固定幀數，讓 6MP 在最末端的持續幀剛好壓在對手起身的第 1 幀。

套路二：強 Cyclone 著地套路

  • 流程：強 Cyclone（214HP 命中） -> 弱鷹擊（214LK 著地微調） -> 前中拳（6MP 中段）
  • 目的：同樣是校準幀數，企圖偷取防守方的硬直優勢。

6.2 底層硬直差真相：防住後我方依然先動！

很多玩家以為「既然是對手精心校準的持續中段，防住之後肯定是對手有利吧？」 格鬥猩猩明確闢謠：大錯特錯！ - 拉希德的前中拳（6MP，發生 20F，原本被防為 -2F）； - 即使卡進了最極限的持續幀第 3 幀，被防後的硬直差最多也只能達到 -1F 甚至 0F，極端情況下勉強達到 我方 +1F！ - 實戰鐵則：拉希德的持續中段被防後，他絕對無法取得壓倒性有利！ - 處決方式：防守方擋住中段後，毫不猶豫立刻按下 4F 輕攻擊（5LP / 2LP）！拉希德如果自以為有利試圖搶動出招，必被防守方的 4F 輕拳直接打出 Counter Hit，隨後接必殺技打出高額連段！

13. 天梯實戰常見致命誤區與急救指南（FAQ）

Q1：如果對手拉希德在遠距離一直用奔跑（Run）變換節奏，不急著下滑鏟怎麼辦？

  • 急救指南：奔跑狀態下拉希德無法防禦！

Q2：壓起身時拉希德如果不用飛行派生，而是直接原地出前中拳（6MP）中段怎麼辦？

  • 急救指南：6MP 發生長達 20F！
  • 正解操作：人類視覺反應完全可以做到「目視站防」。看見其前傾出拳動作，最速切換為站立防守，擋住後為拉希德 -2F，防守方 4F 輕拳搶動必贏。

Q3：拉希德在版邊開 SA2 龍捲風，如果我方處於 Burnout（鬥氣枯竭）怎麼辦？

  • 急救指南：Burnout 狀態無法使用 Parry！
  • 正解操作：必須貫徹「鋼鐵蹲防」。若拉希德生綠衝貼臉前投，在被投擲的瞬間按下拆投（即使 Burnout 也能拆投）；若拉希德出打擊，咬牙防住等待風暴消散。

Q4：現代模式拉希德在近距離瘋狂連打一鍵昇龍拳（Spinning Mixer）怎麼辦？

  • 急救指南：弱 Mixer 被防 -15F，強 Mixer 被防 -28F！
  • 正解操作：保持 4F 輕拳安全肉壓（Safe Meat），引誘其凹出 Mixer，擋住後手握世紀大破綻，直接滿額處決！

Q5：拉希德在空中使用 Arabian Skyhigh 踩頭變軌，隆地面昇龍拳打空了怎麼辦？

  • 急救指南：嚴防「提早出昇龍」！
  • 正解操作：拉希德踩頭後身體必然向後方或下方飄落。隆在地面不要急躁，等拉希德身體即將落地時再輸入 623HP，或者直接在半空中以跳中拳（J.MP）將其截殺。
