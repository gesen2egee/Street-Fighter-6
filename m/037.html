① 小技起手強昇龍與起攻壓制 (00:59 - 02:23)

1. 連段配方

  • 標準三連輕擊：2LK ➔ 2LP ➔ 2LP ➔ 623HP (強昇龍拳)
  • 簡化兩連輕擊：2LK ➔ 2LP ➔ 623HP (強昇龍拳)

2. YEAR 3 平衡調整影響

  • YEAR 3 對強昇龍拳擊倒後的狀況進行了優化，擊倒對手後的有利幀數大幅增加，使得「前衝 ➔ 微走投」成為可能。

3. 實戰壓制與博弈細節

  1. 微走投 (Dash ➔ Micro Walk Throw)： - 擊倒後立刻 前衝 (前 Dash) ➔ 微微往前走一步 ➔ 投擲。 - 此時投擲剛好壓在對手起身持續幀上（Meaty Throw），能完美壓制對手起身 4F 輕拳搶動。
  2. 小技 3 發的距離盲點與對手「後走」： - 小技打 3 發會將對手推得較遠，強昇龍命中後的距離也相對較遠。 - 如果對手起身選擇「向後拉走 (後ろ歩き)」，我方微走投的時機極為嚴苛，極容易在對手面前「抓空投擲」反遭大確反。 - 解法 A：改用小技 2 發收尾：
    • 若只打 2 發小技就接強昇龍，擊倒後的距離更近，前衝投擲的容錯率大幅提升（缺點是 2 發小技確認難度較高）。
    • 解法 B：前衝接大ゴス (6HP 鳩尾碎) 抓搶動：
    • 面對愛在起身按 4F 搶動或後走的對手，直接 前衝 ➔ 6HP (前重拳)！
    • 6HP 的長前傾判定會精準打中搶動的對手，觸發漂亮的 Counter Hit，直接砸爛對手暴動。
    • 【字幕補充】：ずんだもん（Zundamon）坦承自己在天梯對上隆時，因為知道小技 3 發後對手微走壓投難度極高，所以自己起身「會故意按 4F 輕拳暴動（あえて4フレ暴れ）」！因此隆玩家若能讀懂這種對手心理，果斷前衝大ゴス（6HP）壓起身，就能穩穩打出暴動潰滅（暴れ潰し）重創對手。
  3. 鬥氣充足時的神技：生綠衝自動 Shimmy (Auto-Shimmy)： - 公式：強昇龍擊倒 ➔ 生綠衝 (Raw DR) ➔ 瞬間拉住「蹲防 (しゃがみガード)」 - 機制：隆在綠衝過程中拉住防禦，滑行會剛好停在對手投擲距離之外（投げ間合いの外）！ - 效果：
    • 若對手起身試圖「延遲拆投」或「普通拆投」，對手的投擲動作會直接揮空，我方自動達成 Shimmy (誘騙拆投)，可直接出 5HP 打出大連段 Punish Counter！
    • 同時，因為我方拉住防禦，對手無論是起身 4F 暴動還是凹 OD 無敵技，全部會被我方「全自動防住」！
    • 注意：此自動 Shimmy 僅限對手選擇「後受身 (Back Recovery)」時成立。
  4. 綠衝中段奇襲： - 強昇龍擊倒 ➔ 生綠衝 ➔ 6MP (中段鎖骨割)，在對手專注防下段或防投時極易命中。

② 小技起手弱龍卷與神級弱波掌 (02:24 - 03:12)

1. 連段配方

  • 小技×3 ➔ 214LK (弱龍卷旋風腳)

2. 核心 Setplay 深度拆解

  1. 弱波掌擊肉身壓制 (Meaty)： - 指令：214LK 擊倒 ➔ 前衝 1 次 ➔ 弱波掌擊 (214LP) - 被防禦：弱波掌擊打在對手起身第 3 持續幀上，被防後我方處於 +2F 絕對先手！
    • +2F 後進行二擇：「普通投擲」 vs 「2LK ➔ 2LP (コアコパ 打擊)」！
    • 命中時：命中後享有 +6F 以上有利，可目押接 2MP (蹲中P) 轉入大連段：
    • 2MP ➔ 236MK (中足刀) 或再次接 214LK (弱龍卷) 形成「再來一碗 (おかわり)」無限循環！
  2. 生綠衝後走自動 Shimmy： - 214LK 擊倒 ➔ 生綠衝 ➔ 按住後退走：
    • 同樣能自動停在投擲範圍外誘騙拆投，並防住對手無敵技凹招（後受身限定）。

③ 版邊小技強昇龍：5MK 對幀神級 Setplay (03:13 - 03:48)

1. 戰術背景

  • 當在版邊以小技起手確認接強昇龍時，如何做到不需要靠肉眼目測、100% 精準對幀的致命壓制？

2. 連段與對幀公式

  • 連段：小技×3 ➔ 623HP (強昇龍拳)
  • 版邊對幀動作：擊倒後立刻揮空 5MK (站立中K)！
  • 幀數效果：5MK 揮空後，我方處於 +8F 有利！

3. 後續二擇壓制

  • 立即出 5MP (站立中P)：
  • 由於對手剛好在第 8 幀起身，5MP (發生 6F) 會以最後的持續幀打在對手身上！
  • 被防禦時：形成 +2F 有利！
    • 此時隆可直接「向後微退 (後ろ下がり)」進行 Shimmy 誘騙拆投！對手只要按拆投必定揮空，立刻吃滿血大懲罰！
  • 命中時：享有 +7F 以上有利，可直接帶入版邊最高傷民工連段：
    • 5MP (命中) ➔ 4HP (鳩尾碎) ➔ 236HK (強足刀) ➔ 623MP (中昇龍拳)！

④ 版邊小技弱龍卷：持續中段與破 JP 當身 (03:49 - 04:47)

1. 連段配方

  • 小技×3 ➔ 214LK (弱龍卷旋風腳) (版邊)

2. 方案 A：持續中段 (持続中段 6MP)

  • 對幀公式：214LK 擊倒 ➔ 原地揮空 5LP (站弱P) ➔ 出 6MP (鎖骨割中段)
  • 效果：
  • 被防禦：原本負幀的中段，在此對幀下變為 +1F 有利！
    • 對手在防住中段後通常以為輪到自己進攻，下意識會搶 4F 輕拳；
    • 隆直接按 5LP ➔ 5LK ➔ 214KK (OD 龍卷) ➔ 623HP (強昇龍)，直接打出 Counter 暴動潰滅（暴れ潰し），將對手融化！
  • 命中時：獲得 +5F 巨大有利！可無縫目押接 5LK (站弱K)：
    • 5LK ➔ 214KK ➔ 623HP 造成可觀傷害！

3. 方案 B：持續弱波動拳 (封殺無敵 SA 與 JP 當身)

  • 對幀公式：214LK 擊倒 ➔ 原地揮空 5LP ➔ 出 236LP (弱波動拳)
  • 克制對象： 1. 無升龍角色（僅有 SA1/SA2 無敵技）：如 Kimberly、Manon、Lily 等，波動拳以持續幀壓住起身，對手想起身凹招極為痛苦。 2. 專門對策 JP 的惡夢當身 (Amnesia)：
    • JP 的 OD 當身只能反擊「打擊技」與「投擲技」，無法反擊飛行道具（彈）！
    • 持續弱波動拳壓起身，JP 起身若是凹當身，會直接被波動拳炸中打出 Punish Counter，直接破除 JP 的無敵防守！

⑤ 版邊小技弱足刀：0 氣安全跳與模糊拆投破除 (04:48 - 05:39)

1. 連段配方

  • 小技×3 ➔ 236LK (弱足刀) (版邊)
  • 【字幕補充/校正】：原語音字幕被自動轉錄為「弱島」或「弱速塔」，實為隆的必殺技「弱ソクト（弱足刀蹴 236LK）」。小技接弱足刀在版邊擊倒後，不需花費任何氣槽（ノーゲージ）即可達成無氣 42F 安全跳，是高分段壓制對手凹昇龍的神招。

2. 核心 Setplay：無資源安全跳 (No-Gauge 42F Safe Jump)

  • 操作：弱足刀擊倒後，無須任何對幀，直接向前跳躍 (前跳)！
  • 機制：形成嚴格的 42F 安全跳躍：
  • 若對手起身凹 OD 昇龍或無敵 SA，隆剛好落地拉防，必定防住對手無敵技，隨後送上 5000+ 滿血確反！
  • 若對手正常防禦，吃隆的跳重拳/重腳壓制，落地繼續保持優勢壓制。

3. 心理博弈：空落偷下段 / 偷投 (すかし下段 / すかし投げ)

  • 當對手習慣拉防或嘗試使用 Parry 防安全跳時：
  • 隆前跳時不出任何攻擊，落地瞬間直接出 2LK (偷下段) 或直接按 投擲！

4. 破解對手「模糊拆投 (Fuzzy Mash / 遅らせコパン)」

  • 天梯高階玩家常在防禦安全跳時使用「延遲 4F 輕拳」來防空落偷下段/偷投。
  • 對策：隆前跳時，輸入「延遲空中龍卷腳 (遅らせ空中竜巻)」！
  • 空中滯空微頓挫，正好精準打中對手想起身出 4F 輕拳的判定，直接 Counter 擊潰！

5. 備用方案：持續中段

  • 擊倒後：揮空 5MP (站中P) ➔ 出 6MP (中段)，命中同樣享有 +5F 有利可接連段。

⑥ 版邊小技 OD 龍卷：資源爆發與全 SA 帶入 (05:40 - 06:52)

1. 核心定位

  • 當在版邊由小技（如すかし下段 2LK）命中時，花費 2 格鬥氣使用 OD 龍卷（214KK），是隆在版邊進行傷害最大化與斬殺管理（Kill / Lethal Confirm）的核心途徑。

2. 實用派生路線彙整

  1. 直接帶 SA 路線 (超必殺收尾)： - 小技×3 ➔ 214KK ➔ SA1（傷害 2520） - 小技×3 ➔ 214KK ➔ SA2（傷害 3250） - 小技×3 ➔ 214KK ➔ 623HP ➔ SA3（傷害 4337，小技起手破 4300 斬殺極強！）
  2. 生綠衝 5MP 延伸 (推高白嫖傷害)： - 小技×3 ➔ 214KK ➔ DR 5MP ➔ 214MP (中波掌撃) ➔ 623HP (強昇龍)（傷害 2724，無 SA 最佳版邊輸出）
  3. 安全跳轉化路線： - 小技×3 ➔ 214KK ➔ DR 5MP ➔ 236HK (強足刀)（傷害 1944） - 效果：強足刀擊倒後，立刻前跳形成安全跳 (Safe Jump)！
  4. 極限燃氣連段 (Cancel Drive Rush 延伸)： - 小技×3 ➔ 214KK ➔ DR 5MP ➔ CDR 2HP (蹲強P) ➔ 236HK ➔ 623HP / SA1 / SA3
    • 接 SA1：傷害 3774
    • 接 SA3：傷害 4337

⑦ 版邊旋風腳 (6HK) 的極限壓制 (06:53 - 07:23)

1. 招式價值

  • 隆的 6HK (踵落 / 旋風腳) 在每次遊戲調整中判定都不斷增強，版邊摸獎命中回報極大。

2. 連段配方

  1. 無氣持續中段配方： - 6HK ➔ 空中竜巻 ➔ 原地揮空 2LK (蹲弱K) ➔ 出 6MP (中段) - 效果：命中享有 +5F 有利，可目押接 5LK 轉入後續連段！
  2. 消耗 2 格 OD 氣槽 (大傷害確認)： - 6HK ➔ OD 空中竜巻 ➔ 623HP (強昇龍) ➔ SA3 - 傷害高達 4337，實戰中 6HK 命中確認不可不練！

⑧ 中足生綠衝：YEAR 3 革命性新體系 (07:24 - 10:23)

1. 為什麼棄用 5HP/4HP，改用「2HP ➔ 強波掌擊」？

  • 傳統路線：2MK ➔ DR ➔ 5HP ➔ 4HP ➔ 強昇龍（單純追求即時傷害，但推版與起攻極其平庸）。
  • YEAR 3 推薦核心：2MK ➔ DR ➔ 2HP (蹲強P) ➔ 214HP (強波掌撃)
  • 優點 1：氣槽回充量更大（2HP 的鬥氣回充效率顯著高於 5HP）。
  • 優點 2：推版距離（搬運力）驚人。
  • 優點 3：後續可派生全快打 6 最強的壓起身體系！

2. 強波掌擊後的 4 大分支與 Setplay

分支 A：對抗發波角色（蓄電刃轉強化 SA1）

  • 公式：2MK ➔ DR ➔ 2HP ➔ 214HP ➔ 236MK (中足刀) ➔ 22P (集中 / 蓄力)
  • 戰術意義：
  • 面對 Guile、Ed、Dee Jay 等發波角色，中足刀擊倒後安全完成「集中」蓄力。
  • YEAR 3 調整後，電刃狀態下的 SA1 波動拳彈速提升為 2 倍！在中遠距離穿波確反能力極強（注意：對 AKI 等低姿態招式仍需注意距離避免被逆確反）。

分支 B：中龍卷超遠推版 + 持續中拳壓制

  • 公式：2MK ➔ DR ➔ 2HP ➔ 214HP ➔ 214MK (中龍卷)
  • 特點：一口氣將對手推過半個畫面！
  • 起攻選項：
  • 前衝 ➔ 微走投 或 コアコパ (2LK 2LP) 打擊二擇。
