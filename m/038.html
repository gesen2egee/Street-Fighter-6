    一、打破傳統迷思：中央擊倒起攻的殘酷真相

    1. 強昇龍拳擊倒後的「走投」謊言

    • 天梯迷思：多數玩家習慣在強昇龍拳（623HP）擊倒對手後，直覺性往前走嘗試普通投擲（走投 / 歩き投げ）。
    • Shuto 戳破真相：

      「中央強昇龍擊倒後，其實根本壓不到投（投げ埋まってないんすよ）。大家都在那邊裝腔作勢好像壓得到一樣走過去摔，但只要對手起身按 4F 輕拳搶動，隆是絕對會被打爛的！」

    • Shuto 的應對策略：
    • 手握 3~4 格以上鬥氣時：100% 選擇「生綠衝（生ラッシュ）」起攻！
      • 理由：普通走上前壓制一旦被防，攻勢立刻中斷；生綠衝即使被防依然保有主動幀數優勢，更能隨時帶入綠衝中段（6MP）破下防，壓制厚度完全不同。
    • 對手愛搶動時：前衝出大ゴス（6HP 鳩尾碎）或 5HP：
      • 利用重攻擊的長判定直接覆蓋對手的 4F 搶拳，打出 Counter Hit 進行重創。

    2. 弱龍卷（214LK）擊倒後的「持續肉壓（Meaty）」

    • 中央以 214LK 結尾擊倒後，最速前衝 1 次（前ステ），立刻出 214LP（弱波掌擊）。
    • 此時弱波掌擊會以其「後端持續幀」壓在對手起身第一幀：
    • 被防禦：隆享有優勢有利幀（+2F 以上），實質效果等同生綠衝壓制，無責任近身打摔二擇！
    • 命中時：可目押接 4HP 或大連段。

    二、中央連段庫：安定民工 vs 極限推版

    1. 輕攻擊確認

    • 0 氣安定：2LK ➔ 2LP ➔ 623HP (強昇龍拳)
    • 2 格氣爆發：2LK ➔ 2LP ➔ 214KK (OD 旋風腳) ➔ 623HP
    • 【字幕校正】：原手冊誤寫為「小技接 236KK OD 驢踢」，快打 6 中輕攻擊無法取消足刀（驢踢），小技消耗 2 格氣確認連段必定為 OD 旋風腳（214KK），命中後接強昇龍拳，可推至版邊並追加可觀傷害。

    2. 中攻擊摸獎確認 (5MP / 2MP)

    • 取消 OD 足刀（OD ソクト 236KK）：
    • 5MP / 2MP ➔ 236KK ➔ 6HK ➔ 空中龍卷
    • 【字幕補充】：Shuto 提醒，此連段在版中極為實用，但注意雙方距離不可過近，太近時 6HK 會使對手飛越過頭而打空。

    3. 綠衝取消（Drive Rush Cancel）的分歧選擇

    • 路線 A：Shuto 實戰首選（極致安定）：
    • 摸獎命中 ➔ CDR ➔ 5HP ➔ 4HP ➔ 623HP (強昇龍)
    • Shuto 直言：「雖然理論上有更高傷害路線，但我實戰基本上全部打這套，穩定度第一。」
    • 路線 B：推版搬運與真正壓投（理想追求）：
    • 摸獎命中 ➔ CDR ➔ 2HP (蹲強P) ➔ 214HP (強波掌擊) ➔ 214MK (中龍卷)
    • 核心價值：一口氣將對手推過半場！且擊倒後前衝能真正壓到起身投擲（ちゃんと投げ埋まる），若版中沒有即刻斬殺需求，推薦走此路線一路推至版邊。
    • 路線 C：削氣與安全跳（42F Safe Jump）：
    • 打潰對手暴動 ➔ 236HK (強足刀)
    • 擊倒後享有整整 +42F 有利，直接前跳構成無氣安全跳，前跳重攻擊落地壓制，大幅削扣對手鬥氣槽。

    三、Shuto 親傳：版邊四大終極 Setplay 體系

    當將對手逼入版邊並成功完成一次普通投擲（前投）後，隆處於極度密著且大幅領先的境地。Shuto 整理出四大版邊定式：

    1. 站弱拳對幀安全投（コパ投げ，+4F 超安全投）

    • 操作：版邊投擲成功後，原地打一下 5LP (站弱拳) 對幀，隨後立刻按 投擲！
    • 機制優勢：
    • 5LP 揮空後，隆剛好處於 +4F 有利。
    • 快打 6 機制中，+4F 以上的壓投，即使對手後退也絕對逃不出投擲範圍。
    • 【防空連動神技】：如果對手因為害怕被投而起跳逃跑（前跳），隆因為剛好在 +4F 節奏上，可以直接按 4HK (引き大K) 將空中的對手打落，打出致命防空康特，甚至能直接帶入 SA3！

    2. 2LK ➔ 5LP 壓起身：防禦 9F 無敵 SA 的神級陷阱

    • 操作：版邊投擲後，立刻出 2LK (壊し) ➔ 5LP (コパン)！
    • 驚人機制：
    • 此時 5LP 會以持續幀壓在對手起身第一幀，被防禦後隆為 +1F 有利，可繼續出小技或投擲二擇。
    • 最關鍵特點：如果對手起身凹無敵超必殺（如 Cammy 的 SA1 發生為 9F），隆出完 5LP 竟然剛好來得及拉防防住對手無敵 SA！
    • 面對擁有慢速無敵技的對手，這套 Setplay 兼具壓制與絕對安全性。

    3. 5MP 持續中拳無限循環體系 (+8F 對幀)

    • 連段確認：版邊以中拳打擊命中時：
    • 5MP ➔ 4HP ➔ 236HK (強足刀) ➔ 623MP (中昇龍)
    • 對幀公式：中昇龍擊倒後，原地揮空 2MP (しゃがみ中パン)！
    • 幀數效果：揮空 2MP 後剛好形成 +8F 有利！
    • 後續壓制：
    • 立即出 5MP，剛好以最後持續幀壓在起身對手身上：
      • 被防禦：隆享有 +2F 絕對有利，直接進入投擲範圍進行壓投或 Shimmy！
      • 命中時：享有巨大有利，可再次接 4HP ➔ 236HK ➔ 623MP，形成令人絕望的死循環！

    四、全角色最強神技：延遲 4HK（遅らせ引き大K）徹底解析

    Shuto 在解說中給予最高評價的版邊壓起身招式：「引き大K（4HK 斧踢）」！

    1. 為什麼是「ぶっ壊れ（崩壞級神技）」？

    • 格鬥遊戲常理：在版邊如果想潰滅對手的「延遲拆投（遅らせグラップ）」，出打擊技時必須故意延遲出招；然而一旦延遲出招，對手若選擇「前跳逃跑」，打擊技往往會揮空或被打掉。
    • 4HK 的霸道判定：
    • 隆的 4HK 向上與前方的判定異常巨大。
    • 當隆在版邊稍微延遲出 4HK（遅らせ引き大K）時：
      1. 對手延遲拆投 ➔ 被 4HK 打爛，觸發 Counter Hit！
      2. 對手起跳逃跑 ➔ 4HK 的判定直接把對手在空中撈下來打康！
    • 雙重封殺：一招同時吃死「延遲拆投」與「起跳逃跑」！Shuto 讚嘆：「在全快打 6 所有角色裡，隆的這招是真正的最強，甚至超越了豪鬼的 4HK！」

    2. 被防禦時的安全度

    • 4HK 被防禦僅負 -4F。
    • 在版邊最遠距離命中時，對手根本沒有任何招式能確反；隆甚至可以在被防後直接取消 OD 波掌擊 進行大額削氣！

    五、版邊誘騙拆投 (Shimmy) 與極限爆發連段

    當在版邊成功誘騙對手拆投（Shimmy 達成 Punish Counter）時：

    1. 0 氣高傷民工

    • 5HP (PC) ➔ 214HP (強波掌) ➔ 6HK ➔ 214HK (強龍卷)
    • 無需任何資源，推版與傷害兼備。

    2. 極致性價比連段：維持 45% 補正帶 SA1

    • 公式：5HP (PC) ➔ 214HP (強波掌) ➔ 6HK ➔ 214KK (OD 龍卷) ➔ SA1
    • 傷害與補正分析：
    • 此連段在帶入 SA1 時，連段修正僅停留在 45%（極為輕微的修正），單套連段能瞬間蒸發對手大半管血量！
    • Shuto 極力推薦：「這套連段的氣槽轉換效率高得不可思議，是版邊 Shimmy 最優先考慮的斬殺利器。」

    六、大破綻確反、DI反擊搬運與氣絕處決

    1. 防禦對手無敵技後的最大確反 (PC 確反)

    • 無敵技大空振時：
    • 始動使用 5HK (PC) ➔ 2HP ➔ OD 波掌 ➔ 4HP ➔ 236HK ➔ 623HP ➔ SA3。
    • 全資源灌入極限傷害可突破 6500+！

    2. 中央 DI 反擊（Impact 返）的超遠搬運

    • 在版中央成功以 Drive Impact 反擊打崩對手時：
    • 公式：DI 反擊 (PC) ➔ 前衝生綠衝 ➔ 2HP ➔ 214HP (強波掌) ➔ 214MK (中龍卷)
    • 一口氣橫跨全場直接將對手從中央送進版邊地獄，隨後立即展開 Shuto 親傳的版邊四大 Setplay！

    3. 對手氣絕處決 (Burnout Stun)

    • 將對手打至版邊昏迷時：
    • 第一件事：立刻執行 22P (集中 / 蓄電刃)！
    • 隨後接跳強打擊或 SA2 / SA3 進行斬殺，確保以最大資源效率收下對局。

    七、總結：Shuto 的天梯登頂心法

    1. 不要盲信中央走投：小技昇龍擊倒後，對手搶動必定揍扁走投；要麼前衝出重攻擊抓暴亂，要麼花氣生綠衝壓制。
    2. 掌握版邊「延遲 4HK」：熟練掌握延遲 4HK 的節奏，同時扼殺對手的延遲拆投與前跳逃脫。
    3. 重視 2HP 強波掌中龍卷的搬運力：將對手推入版邊才是隆發揮統治力（+4F 安全投、+1F 慢速無敵技誘騙、+2F 持續中拳死循環）的真正起點！
