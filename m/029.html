    一、 官方試煉整體難度概覽與核心心法

    階段 題數 官方難易度標籤 核心考察重點 創作者評價
    初級 7 題 易しい (簡易) 基本通常技取消、目標連段、輕技連打、DI 確反與撞牆 SF6 初學者也能迅速全通，建立基礎手感
    中級 9 題 易しめ (稍易～中等) 骨折/大戈斯目押、足刀浮空跳追擊、DRC 綠衝取消接 SA1/2/3 出招時機非常重要！部分招式最速出會空振

    [!TIP]
    試煉通關的核心心法：
    初級連段多為「輸入越快越好（Buffer 取消）」；但到了中級與上級，Capcom 大量加入了「浮空追擊（Juggle）」機制。浮空追擊講求的是『對手的高度』，如果習慣無腦連打最速出招，極容易因為對手位置過高而空振揮空！

    二、 【初級篇 1～7】基礎必殺技確認與迸發對策

    初級主要建立通常技取消必殺技的肌肉記憶，以及鬥氣迸發（Drive Impact）擊中時的最基礎應對。

    初級 1：站中拳取消波動拳

    • 連段指令：5MP (站中拳) ➔ 236HP (強波動拳)
    • 全段傷害：1520
    • 機制說明：隆最標誌性的中距離牽制與摸獎確認，利用預先輸入（Buffer）將站中拳的硬直取消為氣功。

    初級 2：站強拳取消強昇龍拳

    • 連段指令：5HP (站強拳) ➔ 623HP (強昇龍拳)
    • 全段傷害：1800
    • 機制說明：重攻擊近距離命中的基本取消，可直接扣下對手跳入或破綻確反。

    初級 3：跳強腳落地接掃腿

    • 連段指令：(跳躍中) 強K (跳HK) ➔ 2HK (蹲強腳/掃腿)
    • 全段傷害：1700
    • 機制說明：基本的跳入打擊，落地後利用打擊有利目押接 2HK，造成對手完全擊倒（Hard Knockdown）。

    初級 4：輕拳三連打

    • 連段指令：2LP ➔ 2LP ➔ 2LP (蹲輕拳 3 連擊)
    • 全段傷害：950
    • 機制說明：4F 輕攻擊連打取消連段，近身防暴躁搶動與快速確認的基礎。

    初級 5：三連目標連段 (不破連擊)

    • 連段指令：5LP ➔ 5MP ➔ 5HK (目標連段 Target Combo)
    • 全段傷害：1800
    • 機制說明：隆的核心民工目標連段。近身 5LP 摸到後可無腦快速按出 5MP > 5HK 擊倒對手。

    初級 6：鬥氣迸發確反 ➔ 中段打擊

    • 條件環境：鬥氣迸發 (Drive Impact) [Punish Counter 確反]
    • 連段指令：DI (PC) ➔ 6MP (鎖骨割) ➔ 2MP (蹲中拳) ➔ 214HK (重龍卷旋風腳)
    • 全段傷害：2500
    • 機制說明：DI 成功確反對手後，對手陷入長時間跪地崩防狀態。此時有充裕時間往前走一步打出 6MP 鎖骨割，命中後帶有 +6F 有利，目押接 2MP 並取消重龍卷將對手推至版邊。

    初級 7：版邊撞牆迸發追擊

    • 條件環境：鬥氣迸發 (Drive Impact) [對手防禦中撞牆 (Guard / Wall Splat)]
    • 連段指令：DI 撞牆 ➔ 5HP (站強拳) ➔ 623HP (強昇龍拳)
    • 全段傷害：1960
    • 機制說明：在版邊將對手打至撞牆硬直後，直接上前使用 5HP 取消強昇龍拳打出穩定確反傷害。

    三、 【中級篇 1～9】目押時機、浮空追擊與超必殺確認

    中級開始引進目押節奏、空中追加攻擊、綠衝取消（DRC）與必殺技接超必殺（Super Cancel）。

    中級 1：跳強拳起手大傷害連段

    • 連段指令：(跳躍中) 強P (跳HP) ➔ 5HP (站強拳) ➔ 623HP (強昇龍拳)
    • 全段傷害：2720
    • 機制說明：最經典的跳入大傷害起手。跳重拳壓低打點，落地銜接 5HP 取消強昇龍拳。

    中級 2：大戈斯接站輕腳

    • 連段指令：6HP (鳩尾碎 / 大戈斯) ➔ 5LK (站輕腳) ➔ 214HK (重龍卷旋風腳)
    • 全段傷害：1980
    • 難點與技巧：

      [!WARNING]
      そーだらいと 提示：「中級2の弱Kのような目押しは連打するとガードされる事があるので連打はオススメしないです」
      6HP 命中後自帶有利幀，但 5LK 屬於嚴格的目押（Link）。如果慌張瘋狂連打輕腳，很容易被系統吞鍵或時機過早導致招式出不來，從而被對手防禦住。請看清 6HP 拳頭收回的硬直節奏精準按一次 5LK。

    中級 3：引強拳足刀浮空 ➔ 空中追擊

    • 連段指令：4HP (引強P) ➔ 236MK (中上段足刀蹴) ➔ [前跳躍] 空中 214HK (空中龍卷旋風腳)
    • 全段傷害：2300
    • 難點與技巧：中足刀命中後會將對手踢向版邊高空反彈。足刀硬直結束後立即拉前跳（9 方向），在空中頂點附近迅速轉出空中重旋風腳完成追擊。

    中級 4：下中腳確認接 OD 龍卷

    • 連段指令：2MK (蹲中腳) ➔ 214KK (OD 龍卷旋風腳) ➔ 623HP (強昇龍拳)
    • 全段傷害：2480
    • 難點與技巧：經典立回牽制 2MK 命中後接 2 氣 OD 龍卷。對手在原地垂直旋轉浮空，待對手下落至胸口高度時輸入 623HP 強昇龍截擊。

    中級 5：踵落接 OD 足刀反彈

    • 連段指令：3HK (回旋踢 / 踵落) ➔ 236KK (OD 足刀蹴) ➔ 623HP (強昇龍拳)
    • 全段傷害：2720
    • 難點與技巧：3HK 命中時手部帶有可取消幀，直接取消 OD 足刀踹飛撞牆，反彈後迎面打出強昇龍拳。

    中級 6：電刃波掌擊 ➔ 頂點中龍卷

    • 條件環境：電刃練氣狀態 (已預先集好電刃波)
    • 連段指令：4HP (引強P) ➔ 214P (電刃波掌擊) ➔ 214MK (中龍卷旋風腳)
    • 全段傷害：2400
    • 難點與技巧：

      [!IMPORTANT]
      そーだらいと 提示：「中級6の中竜巻は吹っ飛んだ相手が頂点あたりで出しています」
      電刃狀態的波掌擊具備浮空打擊效果。中龍卷不能落地立刻踢，而是要等被擊飛的對手升到拋物線最高點（頂點）時才出招，這樣中龍卷的多段判定才能全數吃滿。

    中級 7：輕技偷摸綠衝接 SA1

    • 連段指令：2LK (蹲輕腳) ➔ 2LP (蹲輕拳) ➔ 5HP [打擊綠衝 / DRC] ➔ 236236P (SA1 真空波動拳)
    • 全段傷害：2400
    • 難點與技巧：

      [!TIP]
      そーだらいと 提示：「中級7のSA1は強Pのキャンセル受付時間がやや長めで難しくないです」
      雖然是下段 4F 偷摸起手，但綠衝出來的 5HP 取消判定窗口相當寬裕，只要在 5HP 擊中時順暢滾出 236236P 即可成功，不用過度緊張。

    中級 8：站強拳中足刀 ➔ 延遲 SA2

    • 連段指令：5HP (站強拳) ➔ 236MK (中足刀) [DRC] ➔ 214214P (SA2 真・昇龍拳)
    • 全段傷害：3720
    • 難點與技巧：

      [!WARNING]
      そーだらいと 提示：「中級8のSA2は当てやすいと思います 最速で出すとスカって当たりません」
      5HP 綠衝中足刀踢飛對手後，「如果用最速指令輸入 SA2 會完全空振打空」！必須稍微沉住氣，等被踢飛的對手下墜到正常受擊高度時再啟動 SA2，才能吃到完全鎖定動畫打出 3720 高傷。

    中級 9：生綠衝進攻 ➔ 中波掌擊確認 SA3

    • 連段指令：生綠衝 (Raw Drive Rush) ➔ 5MP (站中拳) ➔ 4HP (引強P) ➔ 214MP (中波掌擊) ➔ 236236K (SA3 滅・波動拳)
    • 全段傷害：4240
    • 難點與技巧：

      [!TIP]
      そーだらいと 提示：「中級9のSA3は中波掌撃のキャンセル受付時間が長いので難しくないと思います」
      中波掌擊命中時有很長的打擊定格與取消輸入時間，在看到中波掌擊命中的瞬間，雙 236K 可以非常從容地輸入完畢。

    四、 【上級篇 1～4】微延遲下落、蓄力爆裂與極限追擊

    上級 4 題是整個試煉的精華所在，也是考驗玩家對隆招式幀數、受擊高度與浮空重力理解的最高殿堂。

    上級 1：PC 重腳膝崩延遲 ➔ 空中雙中拳

    • 條件環境：Punish Counter (PC 確反狀態)
    • 連段指令：5HK (PC) ➔ 2HP (蹲強拳) ➔ 214KK (OD 龍卷旋風腳) ➔ [前跳躍] 空中 MP ➔ 空中 MP (目標連段)
    • 全段傷害：3459
    • 核心難點拆解：

      [!IMPORTANT]
      そーだらいと 提示：「上級1は相手が膝を着いたところで下強Pを当てるとジャンプ中Pが2発当たります」
      1. 膝崩打點：5HK PC 會讓對手慢慢跪下（Crumple 膝崩）。千萬不能在剛打到時就最速出 2HP！過早出招會讓對手浮空高度偏低。
      2. 最佳時機：必須目視對手的「膝蓋即將貼近地面（膝を着いたところ）」的瞬間才按 2HP。
      3. 空中追擊：此時取消 OD 龍卷，對手會被高高擊飛並帶有足夠的空中受擊時間，自身往前起跳，才能順利連打兩下空中 MP 完成目標連段。

    上級 2：下中腳 OD 足刀 ➔ 生綠衝接昇龍

    • 連段指令：2MK (蹲中腳) ➔ 236KK (OD 足刀蹴) ➔ 66 (生綠衝 PDR) ➔ 5MP (站中拳) ➔ 623HP (強昇龍拳)
    • 全段傷害：2566
    • 核心難點拆解：

      [!TIP]
      そーだらいと 提示：「上級2はPDR中Pを当てるタイミングを覚えると難しくないです」
      2MK 取消 OD 足刀將對手踢向版邊回彈，自身要立刻輸入生綠衝（按住招架連點前前）。關鍵在於生綠衝滑行過程「何時按 5MP」：等對手從版邊彈回到約一人高時出 5MP 墊刀，隨後最速取消 623HP 強昇龍。只要抓到生綠衝 5MP 的碰撞時機，本題十分穩定。

    上級 3：大傷害撞牆反彈 ➔ 微延遲引強拳接波掌 SA1

    • 連段指令：5HP (站強拳) ➔ 236KK (OD 足刀蹴) ➔ 66 (生綠衝 PDR) ➔ 4HP (引強P) ➔ 214MP (中波掌擊) ➔ 236236P (SA1 真空波動拳)
    • 全段傷害：3464
    • 全試煉最大魔王！ 詳細解析請見第五章節。

    上級 4：重龍卷倒地 ➔ SA2 電刃極限蓄力爆發

    • 條件環境：電刃練氣狀態 (已預先集好電刃波)
    • 連段指令：5HP (站強拳) ➔ 214HK (重龍卷旋風腳) ➔ 214214P (SA2 蓄力版，按住 P 不放) ➔ 623HP (強昇龍拳)
    • 全段傷害：3240
    • 核心難點拆解：

      [!IMPORTANT]
      そーだらいと 提示：「上級4は相手が膝を着く直前までホールドして転がっているところに強昇龍拳」
      1. 蓄力控制：5HP 接重龍卷後，對手會向前旋轉飛出並摔在地上翻滾。在重龍卷收招瞬間輸入 214214P 並長按拳鍵（Hold）進入蓄力狀態。
      2. 釋放時機：一直蓄力直到看到對手「雙膝即將跪地翻滾」的前一剎那放開拳鍵！
      3. 電刃炸飛：蓄滿的電刃 SA2 會將地面翻滾中的對手再度炸向高空，此時立刻補上一發最速 623HP 強昇龍拳完成擊倒！

    五、 【難所專題】上級 3 徹底破解：為什麼最速會空振？實戰偷懶替代技

    「上級 3」是所有練習 Ryu 連段試煉的玩家最常抱怨「為什麼中波掌擊總是接不到？」的關卡。そーだらいと 在影片後半段特別開闢【難所 上級3】專題進行深度解密：

    [OD足刀蹴] ➔ 對手撞牆高高彈起 ➔ 隆生綠衝 (PDR) 追擊 ➔ 4HP (引強P) ➔ 214MP (中波掌擊) ➔ SA1

    1. 失敗原因剖析：為什麼最速會空振？

    • 失敗現象：如果對手剛撞牆反彈，你立刻以「最速」綠衝衝上去按 4HP，雖然 4HP 打得到，但後續的「214MP 中波掌擊」會 100% 揮空！
    • 原理機制：中波掌擊的打擊判定偏向下前方。最速 4HP 會把對手定在太高的高度，導致中波掌擊出招時對手還飄在隆的頭頂上方，判定直接穿過對手身體而揮空。

    2. 官方試煉的標準成功解法：學會「延遲等待」

    • 操作訣竅：
    • OD 足刀踢出後，不要慌張。
    • 目視對手撞牆並開始『下降（下降中）』。
    • 等對手開始下落時，才啟動綠衝並按下 4HP 打擊！
    • 此時對手的高度剛好落在隆胸部正前方，中波掌擊便能穩穩全部吃中，隨後順利 Super 取消 SA1。

    3. そーだらいと 傳授：實戰偷懶替代神技！

    • 偷懶打法：「將 4HP（引強P）直接換成 5HP（站強拳）」！
    • 路線：... OD足刀 ➔ 最速 PDR 5HP ➔ 214MP ➔ SA1
    • 優勢對比：
    • 站強拳（5HP）的受擊判定判定箱與擊飛角度與 4HP 不同，就算你用「最速」綠衝打出 5HP，後續的中波掌擊也絕對能 100% 命中，完全不需要冒險算延遲時間！
    • 傷害完全相同：兩者最終造成的總傷害都是 3464，沒有任何縮水！
    • 特別注意：
    • ⚠️ 在 Capcom 官方 Combo Trial 模式中，系統會嚴格檢查招式指令，所以換成 5HP 系統判定不會算你通過。
    • ✅ 但在天梯實戰中，請務必使用 5HP 替代！ 容錯率大幅提升，再也不會在激烈對戰中發生中波掌擊揮空的低級失誤。
