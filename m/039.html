初級試煉全面展示了現代模式的內建自動連段、目標連段以及基礎立回確認。

三、 【中級篇 1～9】目押時機、浮空高度與超必殺確認

中級試煉開始引入嚴格的目押時間差、浮空高度判定以及綠衝取消（DRC）。

中級 1：跳入重拳三連擊

  • 連段指令：[跳躍中] 強 ➔ 強 (5HP) ➔ 前 + SP (6SP 昇龍拳)

  • 機制說明：經典跳入對空破綻打擊，落地 5HP 銜接一鍵昇龍拳。

中級 2：大戈斯目押站弱腳

  • 連段指令：前 + 強 (6HP 大戈斯) ➔ 弱 (5LK 站輕腳) ➔ 後 + SP (4SP 龍卷旋風腳)
  • 全段傷害：2160
  • 難點與技巧：6HP 命中後帶有 +4F 命中有利，必須看準收招幀目押按一次「弱」，切忌胡亂連打。

中級 3：引強拳浮空 ➔ 前跳空中追擊

  • 連段指令：Assist + 強 (4HP) ➔ Assist + 下 + SP (OD 足刀蹴) ➔ [前跳躍中] 後 + SP (空中龍卷)
  • 全段傷害：2000
  • 難點與技巧：按住 Assist 打出 4HP 與 OD 足刀踢飛對手撞牆，隨後立即放開 Assist、向前起跳，在空中頂點使用 後 + SP 截擊。

中級 4：下中腳確認 OD 龍卷 ➔ 深打昇龍拳

  • 連段指令：下 + 中 (2MK) ➔ Assist + 後 + SP (OD 龍卷旋風腳) ➔ 前 + SP (6SP 昇龍拳)
  • 全段傷害：1740
  • 創作者關鍵提示：

    [!IMPORTANT] そーだらいと 提示：「中級4は最後の昇龍拳(→SP)を引き付けて当てるとダメージが大きい」
    OD 龍卷將對手吹飛後，昇龍拳（6SP）越晚出（等待對手落到接近胸口腹部高度時才出）傷害越高！太早最速按只會打到浮空邊緣，傷害會大幅縮水（早出僅約 400 傷害，深打可達 720 傷害）。

中級 5：踵落接 OD 足刀反彈

  • 連段指令：下前 + 強 (3HK 踵落) ➔ Assist + 下 + SP (OD 足刀蹴) ➔ 前 + SP (6SP 昇龍拳)
  • 全段傷害：1672
  • 難點與技巧：3HK 命中瞬間按住 Assist 輸入 下 + SP 觸發 OD 足刀，撞牆反彈後前進一步補上 6SP 昇龍拳。

中級 6：電刃波掌擊 ➔ 浮空龍卷旋風腳

  • 條件環境：強 + SP (先開電刃練氣)
  • 連段指令：Assist + 強 (4HP) ➔ 下 + SP (電刃波掌擊) ➔ 後 + SP (4SP 龍卷旋風腳)
  • 全段傷害：2240
  • 創作者關鍵提示：

    [!TIP] そーだらいと 提示：「中級6の最後の竜巻旋風脚(←SP)はタイミングを覚えると簡単です(連打でも当たります)」
    4HP 取消電刃波掌擊後，對手被炸向空中。等對手升到拋物線頂點附近輸入 後 + SP 即可完整吃滿段數，作者強調此處就算連打 SP 也能順利命中。

中級 7：輕技起手 DRC 接 SA1

  • 連段指令：下 + 弱 (2LK) ➔ 下 + 弱 (2LP) ➔ 強 (5HP) ➔ [DRC 打擊綠衝] ➔ 強 (5HP) ➔ N + 強 + SP (SA1 真空波動拳)
  • 全段傷害：3160
  • 難點與技巧：下段 2LK 摸到確認接 2LP > 5HP 取消綠衝。綠衝後的 5HP 命中後直接以手搓 236236+P 或一鍵快捷鍵釋放 SA1。

中級 8：綠衝波掌擊接 SA2 疾風迅雷腳

  • 連段指令：強 (5HP) ➔ [DRC 打擊綠衝] ➔ 下 + 強 (2HP) ➔ 下 + SP (2SP 波掌擊) ➔ 後 + 強 + SP (SA2 疾風迅雷腳)
  • 全段傷害：3220
  • 創作者致命陷阱警告：

    [!WARNING] そーだらいと 警告：「中級8は最速だとSA2が当たらないのでホールドするか間を置いて出します」
    中級 8 如果無腦預先輸入最速出 SA2，SA2 會完全打空揮空！
    解決方法有兩種： 1. 輸入 SA2 指令時按住按鍵進行微蓄力（Hold）； 2. 在波掌擊打出後稍微停頓片刻（間を置く）再啟動 SA2。

中級 9：生綠衝中段破防帶走 SA3

  • 連段指令：(鬥氣招架中) ➔➔ (生綠衝) ➔ 前 + 中 (6MP 鎖骨割) ➔ 下 + 中 (2MP) ➔ Assist + 強 (Assist+5HP) ➔ 下前 + 強 + SP (SA3 滅・昇龍拳)

五、 【難所專題深度解密】上級 1～4 關鍵卡關點破譯

そーだらいと 在影片後半段特別針對玩家卡關率最高的「上級 1～4」進行幀數與系統機制的深度剖析：

難所 1：上級 1 —— Assist 鍵「按住與放開」的指法邏輯

創作者說明：「上級1はアシストボタンを押す・離すを使うので、コマンド技、追い撃ち、と一通りやる事があってモダンの操作の練習にも良いと思います」

為什麼上級 1 是所有現代玩家的「基本功大考」？

現代模式中，同一個方向與按鍵，會因為 Assist 鍵是否按著而變成完全不同的招式：

[DRC 綠衝] ➔ 放開 Assist 按 6HP (大戈斯)
                 │
                 ▼
          按住 Assist 按 強攻擊 (引強拳 4HP)
                 │
                 ▼
          放開 Assist 按 下+SP (電刃波掌擊)  <-- 若按住 Assist 會變成 OD 足刀！
                 │
                 ▼
          維持放開 Assist 按 下+SP (上段足刀蹴追擊) <-- 連打即可命中！
  • 核心心法：打完 4HP 的瞬間，手指立刻放開 Assist 鍵，專注以 下 + SP 先出電刃波掌，等對手浮空落下時再按一次 下 + SP 足刀踢飛。

難所 2：上級 2 —— 綠衝中攻擊打點與昇龍拳提前出招

創作者說明：「上級2はバリィラッシュ中攻撃と昇龍拳(→SP)のタイミングが大事ですかね。失敗例：バリィラッシュ中攻撃が当たらない／昇龍拳が当たらない／パリィで止まる」

失敗例剖析

  1. 生綠衝按太慢：OD 足刀踢飛對手後，如果猶豫未及時雙擊前衝，對手反彈落地，綠衝 5MP 就接不到。
  2. 5MP 打點太高：若 5MP 擊中時對手位置過高，後續的昇龍拳容易從對手襠下穿過揮空。
  3. 昇龍拳出太慢：5MP 命中後如果猶豫看確認，對手落到地面判定消失。

通關訣竅：

  • 「昇龍拳は気持ち早めに出しています」：5MP 擊中後不要等收招視覺效果，以近乎取消的節奏「稍稍提前（気持ち早め）」輸入 6SP，昇龍拳判定就能在對手落地前完美截擊！

難所 3：上級 3 —— 訓練模式 50% 慢速驗證：最速能否連上？

創作者說明：「上級3は最速で繋がると思うので後で検証します ➔ トレモで最速で繋がるか検証します ➔ ゲームスピード50%でやります ➔ やっぱり最速で繋がりますね」

經典模式 (Classic) vs 現代模式 (Modern) 的關鍵差異

  • 在經典模式的連段試煉中，OD 足刀撞牆反彈後接綠衝 5HP，通常需要「微延遲（Micro-delay）」以防止 5HP 打點過高導致後續 SA1 揮空。
  • 現代模式深度驗證： そーだらいと 特別在訓練模式開啟 50% 減速慢動作：
  • OD 足刀踹飛撞牆 ➔ 立即最速生綠衝 ➔ 最速按 5HP ➔ 最速輸入 SA1 (N+強+SP)。
  • 驗證結果：現代模式完全可以「最速輸入」無腦連上！ 不需要刻意延遲，11 段全部吃滿，打出 3124 傷害。

難所 4：上級 4 —— SA2 蓄力放開重按密技與膝著地釋放時機

創作者說明：「ホールドするタイプのSAはボタンを離しても また押せばホールドされる仕様です。押すボタンは弱でも中でも強でもSPでもOKです」

這是 Street Fighter 6 現代模式極其關鍵、鮮為人知的底層系統機制！

1. 任意鍵重新蓄力（Hold Re-press）機制

  • 正常輸入 SA2 指令為 後 + 強 + SP。
  • 新手常因為手忙腳亂，發動後手指立刻放開，導致無法維持蓄力。
  • 底層密技： 發動 SA2 後，即使按鍵已經放開，只要在隆做出波動拳蓄力架式（台詞『この拳で』講完前）再次按住「弱、中、強、SP」任一按鈕，系統都會判定為繼續蓄力（Hold）！

2. 蓄力放開的視覺信號（Release Timing）

  • 蓄力不能蓄到底（蓄滿自動發射無法追擊）。
  • 解除蓄力時機：看準對手的動作，「相手が膝を着くところ」（對手膝蓋著地的瞬間）立刻放開按鍵！
  • 此時波掌擊會以最佳時機爆發，將對手震飛並在地上翻滾。

3. 追擊時機（Follow-up Timing）

  • 「相手がゴロゴロ転がった後に昇龍拳(→SP)を当てます」： 看見對手在地面咕嚕咕嚕翻滾彈起的一瞬間，輸入 前 + SP 昇龍拳完成整套試煉。
