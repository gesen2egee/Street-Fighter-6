三、 第一單元：飛仙腳 (6HK 中段踢) 之站防大確反

金柏莉在地面立回中最常用的中段偷襲武器就是【武神飛仙腳 (6HK)】。金柏莉向前高高躍起在空中翻滾，隨後單腿呈戰斧狀自上而下猛烈劈下。

1. 物理屬性與微觀幀數

  • 招式指令：6HK (前前重腳 / 方向前 + 重腳)
  • 發生幀數 (Startup)：22 幀（足夠人類眼睛辨識起跳翻滾動作）；
  • 判定屬性：中段打擊（Overhead）——防守方如果處於蹲下防禦（拉 1 或 2 方向），會被直接砸破防禦並造成大硬直；
  • 被防硬直 (On Block)：整整 -6 幀 (-6F)！
  • 著地身位：金柏莉下劈後，雙腳著地精準停留在防守方正臉貼身處（0.8 身位）！

2. 傑斯特速效破解心法：

「金柏莉向前空翻高踢下劈！動作非常明顯！ 看見她身體翻滾騰空，搖桿立刻拉向後方切換為站立防禦！ 站防擋住這一腳後，金柏莉手握整整 -6 幀破綻！防守方最速出 5LK 或 2MP，100% 穩穩吃下打康確反！」

隆（Ryu）專屬確反處決：

  • 最簡速效處決：
  • 站防擋住 6HK -> 最速 5LK (5F) -> 623HP (強昇龍拳)
  • 傷害：約 1,650 點，擊倒金柏莉並奪回主動權！
  • 進階綠衝爆血處決：
  • 站防擋住 6HK -> 2MP (6F Punish Counter) -> 生綠衝 5HP -> 4HK -> 214MK -> 623HP
  • 傷害：高達 3,350+ 點！一擊讓金柏莉不敢再隨意出 6HK！

四、 第二單元：彩煙瞬移 (彩煙遁術) 之空中擊墜大法

金柏莉最具欺騙性的招牌忍術就是【彩煙瞬移】。金柏莉往地上摔出一顆煙霧彈，伴隨著粉紅或青色的濃烈彩煙爆發，金柏莉瞬間消失，隨後從半空中或對手背後高速現身撲下！

1. 機制解密：華麗特效掩蓋下的漫長前搖

  • 煙霧彈摔在地上爆開有長達 20+ 幀的啟動前搖特效；
  • 金柏莉在空中重新現身下落時，全身完全沒有任何打擊無敵與霸體；
  • 許多玩家之所以被打中，是因為被彩色煙霧嚇到，試圖轉身防守或盲目按地面的大招，結果被金柏莉從空中抓投（武神空神手）或被空中下踢打中。

2. 傑斯特速效破法：

「金柏莉彩煙瞬移！看見地上彩色煙霧爆開，防守方千萬不要在地上傻站著！ 最簡單有效的破法：原地垂直起跳 (拉 8 方向)，在空中按跳中拳 (8MP) 或跳重拳 (8HP)！ 金柏莉一從空中煙霧現身，正好撞在你的跳拳上，直接在半空中把她打爆墜地！」

地面反應極速破法（名將 saisak 推薦兼修）：

  • 如果你沒有及時起跳，傑斯特與名將 saisak 同時指出：

    「用立輕拳 (5LP) 原地拍落解決不少麻煩！」

  • 隆的 5LP (站立輕拳) 發生僅 4 幀，判定向上微傾；
  • 金柏莉從空中撲下來時，只要看準她現身的輪廓，原地狂按 5LP，就能直接將其在空中打斷！

  • 傷害直奔 5,880 點！金柏莉只要無腦滑鏟一次，半條血直接被蒸發！

3. 傑斯特進階破法：在中途將金柏莉「迎面點停」！

  • 隆在中距離（約 2~2.5 身位）看到金柏莉俯身向前衝，不要等她出派生！
  • 原地直接按 2MP (下中拳，發生 6F) 或 5LK (立輕腳，發生 5F)！

  • 隆 2MP 點中後順勢取消綠衝：2MP (PC) -> 生綠衝 5HP -> 4HK -> 236HK，直接在中場截殺金柏莉！

六、 第四單元：噴漆炸彈陷阱 (Spray Can Trap) 版邊壓制之破解

金柏莉在 SF6 中享有專屬的「噴漆罐資源（最多攜帶 2 罐）」。當她將防守方逼入版邊並擊倒時，常會使用【荒天走・罐設置 (22KK)】在防守方腳下扔下一顆定時炸彈。

1. 噴漆罐機制剖析

  • 噴漆罐扔下後約 2 秒（120 幀） 後會自動爆炸；
  • 爆炸判定為全段多段打擊，防守方若被炸中會陷入浮空，被金柏莉接上超高傷害版邊連續技；
  • 金柏莉最常見的套路：扔下炸彈 -> 壓起身出下輕拳打擊 -> 逼你防禦直到炸彈爆炸破防；或者扔下炸彈 -> 前走偷投，讓你拆投被炸、不拆被投。

2. 實戰三大解套神技：

(1) 神技一：拍出 Drive Reversal (D反 6HP+HK) 強行破局！

  • 當金柏莉在炸彈旁邊對你進行連續拳腳壓迫時，防守方在防住第一下拳腳的一瞬間，直接輸入 6HP+HK 拍出 D反！
  • 隆的 D反具備全身無敵，會一腳將金柏莉踢飛大半個螢幕，同時無敵判定會完全抵消即將爆炸的噴漆判定！
  • 消耗 2 格 Drive，換取 100% 安全脫離版邊死局！

(2) 神技二：延遲招架 (Delay Drive Parry) 完全吸收！

  • 如果你沒有足夠氣量出 D反，拉住後防禦並延遲按住 MP+MK (Drive Parry)；
  • Drive Parry 能夠同時防禦打擊與噴漆爆炸，並且每次格擋爆炸判定都會為你回復大量 Drive 動力槽，將金柏莉精心設計的陷阱轉化為你的回氣工具！

(3) 神技三：無敵 SA3 / CA 迎面轟殺！

  • 金柏莉在扔罐子和壓起身的瞬間，動作極其貪心；
  • 隆在倒地起身的一瞬間，若手握 SA3，直接輸入 236236P 真・昇龍拳！
  • 真・昇龍拳的 1~10 幀完全無敵時間會穿透炸彈與金柏莉的拳腳，一拳將金柏莉連人帶罐轟上天頂！

七、 第五單元：空中變軌（流星蹴）與指令投（荒天走）之物理破解

金柏莉除了煙霧和疾驅，在空中與近身還有兩大極具迷惑性的招式：

1. 空中流星蹴 (Divekick / 空中 2HK)

  • 招式機制：金柏莉在空中跳躍時突然單腿斜向下猛刺，急劇改變下落軌跡；
  • 防守要領：
  • 高點刺擊被防：金柏莉若在較高位置刺中你的防禦，落地硬直長達 -6F ~ -8F！隆落地最速出 2MP 綠衝必確反！
  • 低點腳尖刺擊：若金柏莉在極限貼地處刺中腳踝，硬直為 0F ~ +2F。此時防守方不可盲目搶招，拉好防禦等待其下一擊。
  • 根本解法：在金柏莉起跳剛剛發動流星蹴的抬腿前搖時，隆在地面直接拉出 623HP 強昇龍拳，利用昇龍的完全對空無敵將其刺殺！

2. 荒天走 (Command Grab / 623K) 地面撲投

  • 招式機制：金柏莉雙手前撲抓取對手肩膀翻身砸地，屬於不可防禦的指令投；
  • 破綻分析：發生時間較慢（18 幀），且一旦撲空，著地硬直長達整整 35 幀！
  • 反制心法：
  • 看見金柏莉前撲，防守方原地垂直起跳 (8)！
  • 金柏莉從隆腳下撲空穿過，在地上露出長達半秒的巨大僵直；
  • 隆從空中落下時，按跳重拳打出 Punish Counter，落地接滿額大連段！

八、 第六單元：武神流全目標連段（Target Combos）完全拆解與中斷插招點

金柏莉非常依賴系統預設的 Target Combo 進行地面壓制，但這些連段並非無懈可擊：

1. 武神豪腳 TC (5HP -> 6HK)

  • 破綻機制：第二下 6HK 為空中翻身下劈中段，被防手握 -6 幀！
  • 處決方法：站防擋住第二下，最速按 5LK 或 2MP 確反！

2. 武神虎爪 TC (5MP -> 5HP)

  • 破綻機制：若金柏莉未確認命中強行出完 5HP，被防為 -10 幀！
  • 處決方法：擋住第二拳，直接出 5HP 綠衝打滿額連段！

3. 武神天昇腳 TC (2HP -> 2HK)

  • 破綻機制：第二下為掃堂下段踢，被防手握整整 -12 幀！
  • 處決方法：蹲防擋住第二腳，隆走上前出 5HK 或 5HP 綠衝痛打！
