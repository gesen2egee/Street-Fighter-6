    一、 滿資源民工連段與鬥氣節流體系 (6480+ 斬殺) (00:00 - 00:45)

    隆在抓到對手大破綻（如無敵技揮空 PC 確反）時，擁有全遊戲數一數二的恐怖爆發力。塘沽傳奇在此傳授了隆最招牌的重拳重腳綠衝循環架構。

    1. 滿資源三循環極限斬殺 (6,480+ 傷害)

    • 連段配方：
      5HK (PC 破招) ➔ DRC ➔ 5HP ➔ 5HK ➔ DRC ➔ 5HP ➔ 5HK ➔ DRC ➔ 5HP ➔ 623HP ➔ SA3/CA
    • 傷害數值：6,480（若血量進入黃血 CA 狀態，傷害直接突破 6,485 ~ 6,500+）。
    • 特點與手感：
    • 此連段節奏感極強，核心即為「重腳 ➔ 綠衝 ➔ 重拳」的反覆循環。
    • 對手只要被抓到一次大破綻，直接帶走大半條血量。
    • 跳入起手同樣適用：j.HK ➔ 5HK ➔ DRC ➔ 5HP ➔ 5HK ➔ DRC ➔ ...。

    2. 鬥氣節流與回氣版本（少一個循環）

    • 連段配方：
      5HK (PC) ➔ DRC ➔ 5HP ➔ 5HK ➔ DRC ➔ 5HP ➔ 623HP ➔ SA3
    • 核心意識（資源管理）：
    • 若你的鬥氣槽不健康（剩餘 3~4 格），不要強行打滿三循環，少打一個 DRC 循環。
    • 鬥氣回復機制：在打出 623HP ➔ SA3 時，SA3 的冗長特寫動畫中，隆會自然恢復 2 格左右的鬥氣！
    • 這樣斬殺未果時，也不會讓自己陷入枯竭（Burnout）的危險絕境。

    3. 完全零氣耗 SA3 斬殺路線

    • 連段配方：
      5HK (PC) ➔ 5HP ➔ 623HP ➔ SA3
    • 適用場景：自身處於枯竭（Burnout）狀態，或是鬥氣完全耗盡時，單純依賴普通技目押直接接超必殺，依然能打出 4,400+ 的可觀傷害。

    二、 確反一氣 SA1 體系與電刃波掌推進 (00:46 - 01:12)

    當手上只有 1 格 SA 氣量時，隆可以利用弱/中波掌擊（Hashogeki）的受創硬直無縫取消 SA1。

    1. 中央重腳確反一氣 SA1

    • 連段配方：
      5HK (PC) ➔ 前衝 (Dash) ➔ 2HP ➔ 214LP (弱波掌擊) ➔ 236236P (SA1 真空波動拳)
    • 傷害：3,540。
    • 技術細節：5HK 破招後對手陷入大硬直，隆前衝一步以 2HP 目押，隨後取消 214LP 造成推波受創，最後秒接 SA1 擊飛對手。

    2. 版邊一氣 SA1（中波掌擊替換）

    • 連段配方：
      5HK (PC) ➔ 前衝 ➔ 2HP ➔ 214MP (中波掌擊) ➔ SA1
    • 傷害：3,920（比中央版直接提升近 400 傷害）。
    • 關鍵要點：在版邊對手不會被推遠，中波掌擊擊中後的浮空判定更好，傷害更高。

    3. 版邊帶電刃波掌一氣極限爆發 (4,200 傷害)

    • 連段配方：
      預先蓄電 ➔ 5HK (PC) ➔ 前衝 ➔ 2HP ➔ 電刃 214MP ➔ 狂暴推波 SA1
    • 傷害：4,200！
    • 評價：僅耗 1 格 SA 氣量就能打出超過 4,200 的核彈傷害，性價比高到極致。

    三、 二氣 SA2 爆發路線與版邊極限彈牆 (5230 傷害) (01:13 - 01:36)

    二氣 SA2（暴風龍卷旋風腳 / 真・昇龍拳）具備特殊的蓄力與彈牆機制，搭配現代與經典模式都極為泛用的大戈斯（6HP）起手。

    1. 常規大戈斯接 SA2

    • 連段配方：
      6HP (大戈斯) ➔ 2MP ➔ SA2
    • 傷害：4,120。
    • 解析：6HP 打中後帶有充分有利幀，可穩定目押 2MP 並直接取消 SA2，適合中距離突襲與破防。

    2. 版邊帶電刃 SA2 蓄力二段彈牆連段 (5,230 傷害)

    • 連段配方：
      預先蓄電 ➔ 6HP ➔ 2MP ➔ 電刃 SA2 (長按蓄力，默數「一、二」鬆手) ➔ 4MK (或 6MK) ➔ 214HK (重旋風腿)
    • 傷害：5,230！
    • 操作要訣：
    • SA2 在電刃狀態下蓄力到第二段鬆手，對手會被高高打飛並產生版邊彈牆效果。
    • 對手反彈落下時，向前墊步以 4MK ➔ 214HK（或重昇龍）完成追擊。
    • 視覺效果極具衝擊力，兩氣換取 5,230 傷害。

    四、 重驢踢 (236HK) PC 單發無修正 3560 暴力斬殺 (01:37 - 01:50)

    • 連段配方：
      236HK (重足刀 Punish Counter) ➔ 236236P (SA1)
    • 傷害：3,560。
    • 底層機制剖析：
    • SF6 的傷害修正機制中，第一擊 PC 的基礎傷害為 100% 無修正（重足刀單發打出 1,560 滿額傷害）。
    • 對手在地面大硬直或揮空時，單發重足刀 PC 落地直接猛搓一氣 SA1，兩招直接蒸發對手 3,560 血量！
    • 簡單無腦，零失誤率，確反遠距離揮空技能時的神器。

    五、 隆三大收尾招式戰術哲學：昇龍 vs 驢踢 vs 旋風腿 (01:51 - 03:30)

    塘沽傳奇強調：隆抓人不容易，若一套不能把對方打死，後續戰略跟進（Oki / 蓄電 / 推版）就是勝負分水嶺！ 隆的連段收尾主要有三種選擇：

    收尾招式 傷害 擊倒距離與優勢 核心戰術目的
    623HP (重昇龍拳) 1,680 (最高) 中等距離 純傷害最大化、斬殺收尾。若血量確定可帶走或追求單發極限，唯一首選。
    236HK (重足刀/重驢踢) 1,560 (次高) 極遠距離推開 安全蓄電（電刃練氣）。將對手踹飛至版底，為隆創造充裕且絕對安全的時間蓄電。
    214LK (輕旋風腿) 1,400 (略低) 近身擊倒 維持貼身壓制與持續壓起身。打完後前衝 +2F 有利，可展開打投二擇。

    關鍵戰術套路：輕旋風 +2F 有利壓制

    • 連段執行：任何中技/輕技 ➔ 214LK (輕旋風)
    • 後續壓制：前衝 (Dash) ➔ 214LP (弱波掌擊)
    • 幀數效果：剛好達到 +2F 有利！
    • 後續博弈：+2F 下對手如果敢點 4F 搶動，隆的 5LP/2LP 會直接發生打康（Counter Hit）；對手若防守，則可直接墊步投技或展開壓制。

    下段起手 (2MK) 的收尾取捨 (03:31 - 04:07)

    • 蹲中腳（2MK）因下段起手修正較大，全套傷害通常落在 2,000 左右。
    • 換成昇龍收尾僅僅比旋風腿多出約 100 傷害。
    • 大師思路：下段起手時，優先選擇推版邊（重旋風/中足刀）或輕旋風維持 +2F 黏人壓制，亦或是重足刀踢飛安全蓄電，而不是盲目追求昇龍多出的 100 傷害。

    六、 鬥氣迸發 (DI) 確認與防串招指令技巧 (04:08 - 04:41)

    1. DI 命中無消耗壓制路線

    • 連段配方：
      DI (地面命中崩防) ➔ 5HK ➔ 2MK ➔ 214LK (輕旋風) ➔ 前衝 ➔ 214LP (+2F 有利)
    • 傷害約 2,570，完全不耗費額外鬥氣，且直接把對手推入壓起身猜拳。

    2. 致命防串招指令細節：為什麼 2MK 接昇龍會變成出波？

    • 實戰痛點：許多玩家在 DI ➔ 5HK ➔ 2MK 後想接 623HP (重昇龍)，卻經常誤出成波動拳（236P）甚至走火爆出一氣 SA1（236236P），白白浪費氣量且被確反。
    • 指令底層解析：輸入 2MK 時搖桿通常有前推或下推的殘留指令，接昇龍容易觸發優先級極高的 236 指令。
    • 塘沽傳奇獨門修正手法：
    • 蹲中腳時，嚴禁按正下方 2MK！
    • 必須輸入 1MK (後斜下中腳)！
    • 按下 1MK 鎖住後斜下後，再拉 623HP (前、下、前下重拳)。
    • 此輸入法能完美過濾掉 236 判定，100% 乾淨出昇龍拳！

    3. DI 耗氣高傷連段 (3,000+ 傷害)

    • DI ➔ 5HP ➔ DRC ➔ 5HK ➔ 623HP (消耗 3 格鬥氣換取 3,127 傷害)。

    七、 版邊撞牆與 OD 驢踢彈牆高傷路線 (04:42 - 05:09)

    1. 版邊撞牆零消耗穩定民工

    • 連段配方：
      DI 撞牆 (Wall Splat) ➔ 5HP ➔ 214MP (中波掌擊) ➔ 623HP (重昇龍)
    • 傷害：2,170（0 鬥氣消耗，版邊標準穩妥連段）。

    2. OD 足刀彈牆花式連段

    • 連段配方：
      5HP ➔ 236KK (OD足刀彈牆) ➔ 4HK (後重腳) ➔ 623HP
    • 傷害：2,910。
    • 變形應用：
    • 下段起手亦可：2MK ➔ 236KK ➔ 4HK ➔ 623HP。
    • 若已蓄電，OD 足刀彈牆後可直接接電刃 SA2 蓄力二段打出巨額傷害。

    3. 綠衝中段破防連段 (05:10 - 05:17)

    • 連段配方：
      DR ➔ 6MP (中段長拳) ➔ 2MP ➔ 214LK (輕旋風) ➔ 前前 (Dash) ➔ 214LP
    • 破蹲防專用，命中後直接帶入輕旋風 +2F 壓制體系。

    八、 版邊帶電極限大確反 (6600 傷害 + 留 4 格氣) (05:18 - 05:42)

    這是一套操作難度低、傷害極度爆炸、且資源循環非常健康的「計算器級」大確反殺招！

    • 連段配方：
      預先蓄電 ➔ 5HK (PC) ➔ 5HP ➔ 214PP (電刃 OD 波掌擊) ➔ 5HP ➔ 214KK (OD 旋風腿) ➔ 623HP ➔ SA3/CA
    • 傷害數值：6,600！
    • 極大戰術優勢：
    • 雖然使用了兩次 OD 技（共耗 4 格鬥氣），但在整套連段中完全不需要綠衝取消（零 DRC 消耗）。
    • 連段過程中自然回復鬥氣，加上 SA3 動畫的鬥氣回充，打完這套毀滅性的 6,600 傷害後，身上竟然還剩下將近 4 格鬥氣！
    • 不會因爆發傷害而導致自身陷入綠條空虛，是天梯排位中最理想的高傷確反模型。

    九、 波掌擊 (Hashogeki) 打康隱藏浮空連段機制 (06:01 - 06:49)

    普通波掌擊（Hashogeki）打在常規命中上通常無法接後續連段，但塘沽傳奇特別指出了許多新手忽視的機制：打康（Counter Hit / 破招）時的浮空受創！

    1. 打康浮空判定

    • 當波掌擊擊中對手的出招前搖或搶動動作觸發 打康 (CH) 時，對手會被高高打向空中，進入特殊的受創擊飛硬直！

    2. 打康後的追擊路線庫

    1. 重足刀追擊：波掌擊 (CH) ➔ 236HK (重驢踢)（推遠並安全蓄電）。
    2. 重旋風追擊：波掌擊 (CH) ➔ 214HK (重旋風)（搬運版邊）。
    3. 生昇龍追擊：波掌擊 (CH) ➔ 623HP（版邊或近距離直接防空攔截）。
    4. 綠衝前進追擊：波掌擊 (CH) ➔ DR ➔ 623HP 或 DR ➔ 214HK（遠距離浮空滑行追打）。
    5. 超必殺斬殺：波掌擊 (CH) ➔ SA1 (真空波動拳)（直接推波，穩定接上）。

    3. 初學者常見困境與改善

    • 新手在立回中使用波掌擊時，心裡往往只預期「只是打對手一下摸個血」，當突然跳出打康將對手擊飛時，大腦往往反應不及而眼睜睜看著對手摔在地上。
    • 大師意識養成：在立回壓制與波掌牽制時，眼睛必須專注盯著畫面上的「Counter」紅字，一旦出現打康，立刻輸入重驢踢或前衝昇龍追擊！

    十、 新手到大師致命壞習慣與心態避坑指南 (06:50 - 08:07)

    塘沽傳奇在影片末尾以個人上分經驗進行真情告白。他提到自己其他角色（如本田等）通常 4 天到 10 天就順利晉升大師，但玩隆卻整整花了半個多月。原因正是因為染上了兩大「非常不科學」的浪漫執念：

    致命壞習慣一：病態執念蓄電（電刃成癮）

    • 症狀表現：只要一將對手擊倒或推開，無論場面優勢多大，第一反應永遠是「我要蓄電」！
    • 實戰代價：
    • 放棄了寶貴的壓起身（Oki）機會。
    • 對手趁機後撤調整節奏或回滿鬥氣，將原本屬於隆的主動進攻權雙手奉還。
    • 正確原則：只有在對手距離過遠、或使用重足刀將其打飛到對版底時，才在絕對安全的情況下蓄電；中近距離擊倒必須堅定壓制。

    致命壞習慣二：波掌被防「硬凹昇龍」賭徒心態

    • 症狀表現：
    • 波掌擊被對手防住後處於不利幀，但心裡總覺得「對方一定會搶動」，於是原地無腦凹 OD 昇龍。
    • 甚至凹了三次被防後，第四次想「騙對方凹」，結果反被對手無情打滿確反。
    • 實戰代價：在白金與鑽石段位，這種賭徒打法會導致勝率極度不穩定，防禦崩盤。
    • 正確原則：波掌被防後乖乖拉後防守或拆投，確立穩健的立回防守意識，才是穩定邁向大師的正道。
