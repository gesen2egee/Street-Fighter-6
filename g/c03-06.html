    進退走位與步行速度

    在立回階段，為什麼高手總是左右小碎步晃個不停、看起來像在散步，結果突然就衝上來摔你或讓你拳腳揮空？這篇把「進退走位與步行速度」的核心觀念講清楚，包含怎麼安全往前走、為什麼不能一直退、什麼是「步行幀」與「退康」，以及各角色的移動特性。適合已經會基本招式、想搞懂「何時該走、何時該退、怎麼靠近才不會白白挨打」的玩家。

    ⚡ 一分鐘懶人包
    1. 小步微調勝過大步亂晃：高手都用「小幅前後移動」讓對手看不透意圖；大步亂晃只會暴露破綻。
    2. 前走比後退快，別一直退到角落：無意義的後退會把空間白白送給對手，還容易被蹲中腳掃倒；沒有明確目的（如喝酒、蓄風）不要隨便後退。
    3. 邊走邊防（步行防禦）：直接往前走時沒有防禦判定，正確靠近方式是「走幾步 → 蹲防一下」交替推進。
    4. 減少「步行幀」：你走越久才按出招，出招前沒有防禦的時間就越長，越容易撞上對手的招。先小步貼近停穩再出招最安全。
    5. 善用「退康（Shimmy）」：走進投技距離假裝要摔，最後一瞬間退後一步，對手一按解投就會直接揮空送你大連段。

    一、走位的基本觀念：為什麼要前後移動？

    • 移動要有目的：走位是為了試探對手會不會退、切換安全區域、或做「預備輸入（Buffer）」，絕對不是無意識亂晃。
    • 小幅移動威脅最大：大步前進或後退會讓對手一眼看穿你的意圖；在原地小幅來回微調，就算只是往前挪一小步，都會逼對手做出反應（按招、後退或防禦）。
    • 進攻與後退的代價：前走是為了搶空間，風險是走路期間沒有防禦（但隨時可以停下來擋）；後退是為了緩解壓力、誘使對手揮空，但會消耗後方空間。
    • 抓起身與站立的時機移動：對手剛起身或站著靠近時，就是調整距離（例如拉開防被投）的好時機。

    二、前進與逼近：怎麼走進去才不會被打？

    • 前走速度比後退快（且前走大幅加速回氣）：這遊戲全角色幾乎都是前走比後退快，而且改版後大幅提高了「往前走（前歩き）」時的動力量表回復速度（影片說法，官方卡未列；講者稱就算在 Burnout 狀態下同樣有效）。只要對手一直往後退，你穩穩往前走就能一步步把對手逼進牆角並更快回氣。
    • 用「步行防禦（走防）」一步步壓進去：這招特別用於「手短打手長」的對局。訣竅是分區執行：在對手最長招式射程外可以大膽一直往前走，不要浪費時間按防禦；一旦踏入對手射程邊緣，才改用「小碎步走一下立刻拉下後蹲防（小刻み歩きガード）」，把按「前」的時間壓到最短。若被逼到版邊（自己不能退而對手可以退），往前走防的距離更要壓到最小限度，並確保出招不揮空。
    • 別等到貼死牆角才搶空間：在快被逼進角落、還保有後退與差合空間時，就該提早積極往前搶回場地控制權。
    • 抓住對手出招後的空檔前進：看到對手出蹲中腳後可以立刻往前走——如果距離夠近你只是防下來，如果對手摸不到，你就能以最快速度貼上去搶攻或摔他！被逼壓時也能偶爾小步往前再蹲防，把對手的有利距離打亂。

    三、後退、拉開距離與「退康（Shimmy）」

    • 別當「無腦後退俠」：一味後退或龜縮很快就會撞到牆角，而且走路後退時蹲防不了下段，極容易被蹲中腳踢中送大連段！只有在有明確戰術目的（例如傑米喝酒、莉莉蓄風、引誘對方揮空或重整距離）時才後退。退到角落時，想辦法找機會換邊把對手關進去。
    • 後退的風險與替代方案：按了負幀招式後直接往後走，有時還是會被對手的近距離防禦判定或前踏打中；想確定脫離戰場時，後墊步（快速點兩下後）或後跳（特別在對手起身時，拉開後對方很難直接追擊）往往比單純走路後退更穩，但也要記住哪些招式被防後擊退夠遠能安全後退、哪些不行。
    • 經典假動作「退康（Shimmy）」：走進對手的投技範圍內，假裝要貼身摔他，在最後一刻往後退一步離開投技距離；對手只要以為你要摔而按出破投，就會直接在你面前抓空氣，送你一套最大傷害懲罰！

    四、進階地上戰核心：「步行幀」與觀察對手

    • 什麼是「步行幀」？：你在往前走的時候是沒有防禦狀態的，所以「你被對手打到的危險時間 ＝ 出招前的走路時間 ＋ 招式發生幀數」。走路走太久才按招，很容易半路被對手的置招撞飛。
    • 怎麼降低風險？：先靠「步行防禦」小步小步把距離修到剛好（理想是走到定位停穩後再出招，讓出招前的步行幀趨近於 0），出招就更不容易被打斷，命中率也更高。
    • 觀察對手的步行節奏：地上戰強的高手，眼睛都在盯著對手什麼時候前走、什麼時候停步，並配合對手的步調調整「前間距」。練「踏入（Step in）」可以分三步走：先走進中腳前方 → 停在中腳前方觀察決定要做什麼 → 最後才是大膽「走著摔」。
    • 墊步、綠衝與動力撥擋前衝：
    • 雙擊前／後可快速墊步或後墊步（注意《快打 6》沒有空中墊步）。
    • 在按住動力撥擋（Parry）的狀態下快速點兩下前，就是動力箭步（生綠衝），衝刺速度遠勝走路且能立刻出招。當對手一直往前走逼近時，他大腦負擔很重，這時候突然發動綠衝貼身往往讓對手反應不及！

    五、各角色移動與走位補充

    • 隆：前進與走路速度偏慢，因此遠距離靠近主要靠「步行防禦」慢慢壓進去（按前時不會被輕易防禦，剛好邊走邊閃或擋招），或是完美撥擋火球後立刻往前走搶回空間、偶爾用生綠衝主動接觸。站立時才能前後微調距離，不要死蹲在原地；也可邊後退邊出中腳、放置龍捲旋風腳調位。
    • 肯：對撞或立回時千萬別做無意義的後退步行，這是常見失誤。
    • 豪鬼：擁有全遊戲並列最快的前進步行速度（但注意改版後後退步速有變慢）！靠極快的前後進出就能輕鬆逼對手揮空，蹲中腳也因為走速快而比許多手長的角色更早摸到人。核心觀念是「隨時保持靠近畫面端（把對手推向牆角）」，不要過度後退讓自己打不出火力或接不到角落連段；近距離走位時別一直死按前，要用前後微調搭配輕拳（注意輕拳距離較難抓）。
    • 泰瑞：前走速度很快，很適合丟出輕能量波後緊跟在波動後面安全搶空間；但後退速度較慢，所以泰瑞不適合在後退之後硬做退康。在畫面中央對抗泰瑞時，用後跳或後退拉開往往比延遲解投更有效（但一直後退很容易吃輕攻以外的下段）。
    • 達爾西姆：自身走路速度極慢、被貼身吃虧，靠遠距攻擊＋浮游／空中停留（地面或空中按 ↓＋雙攻擊鍵 可滯空並左右移動出招）＋瞬移到背後＋各種花式退康（後退／後墊步／浮游退康）拉扯對手。對戰達爾西姆的鐵則：千萬不要怕他手長或火球就一直後退，那只會讓他免費回到最舒服的全螢幕！正確打法是「小步往前走 → 蹲防」交替逼近（多數角色前走速度都能追上他後退，只追不上瞬移），逼他出招風險變大後再抓機會跳或綠衝進去。
    • 桑吉爾夫：走路雖不快但「前衝」速度甚至能跟上達爾西姆的後衝！玩老桑遇到對手後退想誘你站重攻揮空時，切忌急著追擊而吃下段中腳，應花 20～30 秒耐心地「一步步慢慢前走（じりじり近づく）」壓縮空間。對付老桑別一直後退以免把戰線讓給他，在起攻距離可預先設好後退步或混用後跳、前跳（注意對手若常打跳躍後下段追擊，改用垂直跳或前跳比後退步安全，因為後退步地上受擊會吃完整連段）；沒有在讀他指令投時，用後跳應對他的壓力也是好選擇（代價是讓出一點空間）。老桑自己則可用「跑步抓（後＋重攻／三角鍵）」突然近身。
    • 艾德：靠極長射程就能逼對手自己不斷往後退，艾德只要穩步往前走推線，很快就能把對手壓到牆角（據口述約 56 秒左右走位壓制即可推進到底）。脫離壓制時可嘗試跳過對手頭頂往畫面中央移動；對手（如隆）一放棄空間就立刻上前佔領。
    • 傑米：走路與後衝速度都屬於頂尖梯隊（後衝並列最快），非常適合抓對手空過摔技打懲罰，也能靠迂迴走位觀察對手再出中腳複合。因為沒有飛行道具，只能靠前衝出掌／戳／跳／俯衝踢拉距離（沒抓準就會送進壓制距離）。在牆角用後撤步防摔回報極高，平時後退走也能躲過衝刺後的步行摔。
    • 春麗：移動速度屬遊戲上位（前走速度前三、後走速度全遊戲最快），踏入難度低，能輕鬆維持自己最舒服的中腳間距與高潛力差合。另外可用三角跳輕鬆換邊脫離牆角。記住對戰時別因為怕中腳連段就盲目後退，忍耐防住比「後退結果被打」划算得多。
    • 迪傑：標準移動型角色！別死蹲著蓄力，要多靠快速步行結合「搖擺（向後移動）」取消來迷惑對手，靠正面移動拖垮對手而非交叉跳。「爽酷」與前衝必殺都能穿過飛行道具快速貼近，摔技後常接「步伐後生衝刺」，有利幀時往前走一小步是最安全的強壓選擇。
    • 金伯莉：後走速度極快（開大變身後更快），能用走速把對手拖著跑、逼對手必須交綠衝或突進；對手往前追太多時就用下滑（滑鏟）反擊，對手後退也可用滑鏟逼他蹲防。另外 ↓↙←＋拳 可瞬移換位。
    • 嘉米：對付嘉米的關鍵在於「走位移動」，光靠原地按鍵反應很難應付她。
    • 韓蛛俐：沒有飛行道具，不能靠拉遠打，建議利用她極快的衝刺速度主動貼近施壓；下特殊技風破刃（尖塔）就算沒中也能快速貼身接摔或連段。對付愛出前重拳的對手可混入後墊步。
    • 不知火舞：移動速度輕快不拖泥帶水；面對她丟花蝶扇變慢的落點或防禦第三段時，可用後退或後撤步避開。
    • 艾蓮娜：她的架勢可前後移動（像第一季的迪傑晃身），連結之歌（↓↘→＋拳）則是帶無彈道無敵的翻滾移動。對付有長距離滑鏟的角色時，走位記得混入蹲下，別傻傻站著來回走。
    • 維加／拜森：維加不建議無腦退太多，否則正好落入他雙膝壓的舒適圈（守住雙重後可用後跳或後撤步拉開）；現代版維加少了滑鏟，多用綠衝配輕腳／重拳重腳貼近。拜森不太需要長時間後退（招式本身都在往前壓），對付拜森時往後走能直接消掉他很多壓制力（尤其看到綠衝接輕拳／站輕腳時後退很有效）。
    • 拉希德：因為通常技偏短、主動貼身手段有限，推進要耐心一步一步走，防守則用「後退 → 防守 → 後退 → 防守」的節奏逼對手承擔風險；被逼到牆角時可用蹬牆三角跳直接飛越對手頭頂換邊。
    • JP / 瑪濃 / 瑪麗莎 / 阿鬼 / 蓋爾 / 沙加特 / 埃德蒙本田 / 布蘭卡 / 亞斯敏 / 阿爾俊 / 英格麗：
    • JP：別一直待在全螢幕，利用中距離強勢牽制＋傳送門從中立安全推進把對手壓進角落；對付 JP 時要習慣「防住他出招後立刻小步往前走、邊走邊蹲防、對飛行道具用動力撥擋（Parry）」，抓準每次射擊間的空隙推進。
    • 瑪濃：步行速度快，先守備貼近再出蹲中拳（減少步行幀）才不易被截擊，近身輕攻好確認。
    • 瑪麗莎：靠 OD 超人飛拳與墊步重腳接近，再用短劍封鎖對手的走位。
    • 阿鬼：輕蛇輕功可在原地躲避飛行道具。
    • 蓋爾：本身走路速度較慢，一直蹲守原地會讓對手以固定速度安全逼近，因此要適時主動往前走一步打破對手的等速節奏，並用膝頭砲或前中腳搶空間；相反地，若被貼身在不利距離硬撐，不如直接主動後退（或先後撤步再放 Sonic Blade）拉回安全音速波距離，常能讓對手的摔技揮空並逼對手主動走近或跳入。
    • 沙加特：起動力與步行速度不算快，被壓制時走路較慢。
    • 埃德蒙本田：地面步行慢，靠慢慢走入配合中立跳重拳前後微調位移、按鈕與頭突壓制火球角。針對「一直往後走想空振懲罰本田」的對手，可用遠距離下段前重腳懲罰；量表偏少時則主動退後誘敵，等對手急著前走或開綠衝再用頭槌反制。
    • 布蘭卡：後跳覆蓋範圍極廣，就算對手用假動作也很容易脫離危險區。
    • 亞斯敏：後退距離偏短；立回靠 ↓↘→＋腳（惡魔翻，強度越大距離越遠）縮短距離與打交叉跳擇。
    • 阿爾俊：移動慢且後墊步較差（後墊步總長 25 幀，1–15 幀對投無敵，官方數據），想後退解投容易吃虧；對手拉遠時小步前進到岩石前站位較佳。
    • 英格麗：步行速度快（中距離有利），可組合後方瞬移與下方瞬移讓對手鎖定不到位置。

    六、實戰情境與流派差異提醒

    1. 退到對手最遠距離外到底安不安全？：一派認為退到最遠距離外對手很難用一般技摸到；另一派指出如果你自己按了負幀招式，走路後退仍可能被對手的近距離防禦判定或快招打中，改用「跳退／後跳」才算確定離場。
    2. 誰的後退步行最快？：影片講者之間對於誰的後退速度最快（如春麗、傑米等）以及某次改版後是否變慢意見不一，尚無定論。
    3. 單一影片數據與字幕存疑：
    4. 艾德「靠走路約 56 秒到畫面端」為口述時間（非幀數）；豪鬼步行「超快」、桑吉爾夫／達爾西姆前後走衝比較、金伯莉瞬移可躲重拳後招式（講者亦標待驗證）、達爾西姆空中停留操作、維加／拜森後跳回報等，皆來自單一影片或未經交叉實測。
    5. 字幕辨識存疑詞彙：包含「後退需消耗的資源（未明言，應指空間）」、「漏洞百出」、「鬥牛犬（疑指走近防禦）」、「中盤」、「走路摔」、春麗踏入難度原因、豪鬼「夠不到橋／橋上火力」、桑吉爾夫「反牽制招式名」、隆「放置龍捲旋風腳」、傑米「起身打斷輕腳」、金伯莉「衝刺自動攻擊」、不知火舞「舞／捨棄判定」、艾蓮娜「圓月弧踢／初卷拳」、莉莉「前錢（跳房子比喻）」、以及「轉身昇流」「繞到背後」等段落。
