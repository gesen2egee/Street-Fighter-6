    隆（Ryu）角色招式幀數數據

    隆（Ryu）是《快打旋風 6》的基本功教科書，他的特色是「電刃練氣」強化必殺技、「波掌擊」的正幀壓制，以及各種強力的中遠距離拳腳。這篇已對照 Capcom 官方幀數表（2026 年 11 月抓取版本）與正式中文招式譯名，幫你把實戰必背的數字整理清楚：到底他哪些招式被防住是正幀陷阱？哪些破綻擋到可以直接確反（懲罰反擊 / Punish Counter）？

    ⚡ 一分鐘懶人包
    1. 小心隆的「波掌擊（214P）」與正幀陷阱：
    * 重波掌擊被防 +2 幀（電刃強化後 +3 幀）。
    * 極限技（OD）波掌擊被防 +3 幀（電刃強化後 +4 幀）。
    * 輕波掌擊貼身被防 -3 幀（若在遠距用持續幀後段壓制，最高可到 +2 幀，算法見第四章）；但中波掌擊被防高達 -6 幀（可用 6 幀內快速招式直接確反！）。
    * 鳩尾碎擊（俗稱大ゴス／大仏，前重拳 6HP）：發生 20 幀、被防 +3 幀（唯一被防正幀的特殊技；若隆接 8 幀蹲中腳（2MK），中間有 5 幀空隙，4 幀技可打斷、5 幀技會互相對撞）。
    * 站重腳（5HK）：被防 +1 幀（影片提醒對蹲姿會揮空，詳見文末；懲罰反擊命中會觸發 36 幀崩潰）。
    2. 必抓的破綻招式與足刀：
    * 上段足刀（俗稱驢踢，236K）：輕版被防 -11 幀、中版被防 -8 幀、OD 版被防 -18 幀（皆有大確反）；重上段足刀被防為 -3 幀（沒有確反空間，影片另稱被防會削動力量表，官方表未載，詳見文末）。
    * 龍捲旋風腳（214K）：輕 -15、中 -13、重 -13、OD -14 幀，貼身被防皆是大確反，站防擋完可直接打最大懲罰連段。
    * 波動拳（236P）：貼身被防為輕 -5／中 -7／重 -9 幀（但距離拉遠時因飛行時間抵銷硬直，會變安全甚至正幀）；蹲中腳（2MK）取消一般波動拳若太近且未連段，存在被搶招或確反的風險。
    3. 隆的最速起手與無敵大招：
    * 站輕拳（5LP）／蹲輕拳（2LP）為隆地面上唯二的 4 幀最速起手；站輕腳（5LK）／蹲輕腳（2LK）皆為 5 幀。
    * 三級超必殺：真・昇龍拳（SA3 / CA，236236K）發生僅 5 幀（第 1～16 幀完全無敵，被防 -52 幀，硬直 71 幀），殘血時千萬別亂揮大招。

    三、共通移動與投技／起身壓制（Oki）參考

    • 共通墊步與投技：前墊步（Forward Dash）總長 19 幀；後墊步（Backward Dash）總長 23 幀（第 1～15 幀對投無敵）；前摔「過肩摔」與後摔「巴摔」皆為 5 幀發生，懲罰反擊摔傷害為 2040 並轉為強制倒地。
    • 動力系統共通招式：動力衝擊（Drive Impact）發生 26 幀、被防 -3 幀；動力反攻（Drive Reversal）防禦中 20 幀、起身 18 幀發生，被防皆為 -6 幀。
    • 實戰常見壓起身與安全跳（Safe Jump）路線（以下為影片實測路線，場中與角落起身距離不同，建議角落使用，場中視距離調整）：
    • 前摔後壓制：前摔命中後優勢約 +17 幀（依版本與距離有微調，接動力箭步（綠衝）壓起身，影片常見為壓站輕拳（5LP）+4 或壓站中拳（5MP）+7，兩者數字等同官方基礎命中幀）。
    • 版邊安全跳：版邊擊倒取得 +41 ～ +42 幀（如版邊重波掌擊後延遲接「旋風腳（6HK）→ 空中龍捲旋風腳」）即可構成安全跳，騙取對手用無敵昇龍反擊並自己落地防禦；動力衝擊（DI）撞牆擊倒後亦可搭配消幀做安全跳。

    四、衍生情境幀數速查（官方基礎幀數＋系統加值）

    以下數字都是用第一章的官方基礎幀數，加上系統公式算出來的。每次都要寫清楚前提，例如「一般被防 -1，綠衝後被防 +3」。

    1. 動力箭步（綠衝）：地面一般技／特殊技命中與被防都固定 +4

    招式 一般被防 → 綠衝後被防 一般命中 → 綠衝後命中
    站輕拳（5LP）／蹲輕拳（2LP） -1 → +3 +4 → +8
    站輕腳（5LK） -4 → 0 +2 → +6
    蹲輕腳（2LK） -1 → +3 +3 → +7
    站中拳（5MP） -1 → +3 +7 → +11
    蹲中拳（2MP） 0 → +4 +5 → +9
    站中腳（5MK） -4 → 0 +4 → +8
    蹲中腳（2MK） -6 → -2 +1 → +5
    站重拳（5HP） -2 → +2 +4 → +8
    蹲重拳（2HP） -7 → -3 +1 → +5
    站重腳（5HK） +1 → +5 +9 → +13
    鳩尾碎擊（6HP） +3 → +7 +6 → +10

    2. 截擊（Counter Hit）命中 +2、懲罰反擊（Punish Counter，確反）一般命中 +4

    • 站重拳（5HP）：命中 +4 → 截擊 +6、懲罰反擊 +8。
    • 站中拳（5MP）：命中 +7 → 截擊 +9、懲罰反擊 +11。
    • 蹲中腳（2MK）：命中 +1 → 截擊 +3、懲罰反擊 +5。
    • 站重腳（5HK）懲罰反擊另有 36 幀崩潰效果，以崩潰為準。

    3. 燒盡（Burnout）：對手被防幀數全部再 +4

    • 對手燒盡時：站輕拳 -1 → +3、站中拳 -1 → +3、站重拳 -2 → +2、蹲中拳 0 → +4、站重腳 +1 → +5、鳩尾碎擊 +3 → +7。
    • 重波掌擊 +2 → +6（電刃 +3 → +7）、OD 波掌擊 +3 → +7（電刃 +4 → +8）、中波掌擊 -6 → -2、重上段足刀 -3 → +1。

    4. 壓持續（Meaty）：最多再加「持續幀數 - 1」

    用持續幀的最後一幀命中或被防，是最大加值，實際加多少要看對手起身時機。

    招式（持續幀） 最多加成 一般被防 → 壓持續後被防 一般命中 → 壓持續後命中
    站輕拳（4-6） +2 -1 → +1 +4 → +6
    站中拳（6-9） +3 -1 → +2 +7 → +10
    蹲中拳（6-9） +3 0 → +3 +5 → +8
    站重拳（10-14） +4 -2 → +2 +4 → +8
    鳩尾碎擊（20-24） +4 +3 → +7 +6 → +10
    輕波掌擊（12-17） +5 -3 → +2 +2 → +7

    實戰情境與流派差異提醒

    1. 波動拳／輕波掌擊的實戰安全性取決於距離：
    2. 官方表給的是「貼身（0 距離）立刻擋到第一持續幀」的數字（輕波動拳貼身 -5、輕波掌擊貼身 -3）。實際對戰中，波動拳在中遠距離發射時，飛行時間會抵銷一部分收招硬直，所以影片常說「被防有利」；輕波掌擊在極限距離用持續幀末端（第 17 幀）命中時，被防可從 -3 變成最高 +2。判斷安全性必須同時看距離與持續幀。
    3. 版本演進說明：
    4. 舊影片中曾提到「蹲輕腳被防 -3 調為 -2」、「鳩尾碎擊（6HP）原本 22 幀 / 被防 +1」等數據，屬於早期季度的數字。依 2026 年 11 月抓取之 Capcom 官方幀數表，目前數值為：蹲輕腳（2LK）被防 -1 幀、鳩尾碎擊（6HP）發生 20 幀且被防 +3 幀，看到舊影片的數字請以本篇為準。

    7. 站重腳（5HK）對蹲姿會揮空：官方備註沒有提到此判定，是影片的實戰觀察。
    8. 前摔後約 +17 幀、版邊擊倒 +41 ～ +42 幀：屬於系統與位置相關的實測值，官方表沒有收錄。壓起身與安全跳路線在場中與角落的起身距離不同，建議角落使用，場中視距離調整。
    9. 鳩尾碎擊接蹲中腳的 5 幀空隙：由官方 +3 與蹲中腳 8 幀發生推算，實戰仍要看對手輸入與延遲。
