    壓制連攜與壓起身

    好不容易在立回摸到對手一次，打完一套連段或把人壓進防守後，卻不知道接下來該按什麼、結果對手隨便跳一下或按一下輕拳就跑掉了？這篇就是教你「怎麼把對手牢牢鎖在你的進攻節奏裡」，包含壓制節奏、角落威力、預先擺招（置技／壓起身）、綠衝取消連段與幀數陷阱，適合已經會基本連段、想把「進攻滾雪球」與「版邊壓制」練起來的玩家。

    ⚡ 一分鐘懶人包
    1. 打完連段不是結束，而是壓起身的開始：立回摸到人、對空打下來後，立刻跟上去壓起身，別又退回中立讓對手喘息。
    2. 把人推進角落你就贏了一半：《快打 6》待在角落極度危險（撞牆暈眩、無法後退），用推板能力強的連段把人送進版邊，再開始瘋狂二擇。
    3. 壓制要「緊密」：多段輕攻擊壓制後接防禦觀察，不要留太長空檔；中段＋下段交替能讓對手根本不敢亂跳。
    4. 找出你的「有利幀按鈕」：幾乎每個角色都有至少一招被防後是正幀（有利）的招，多按它就能讓對手不敢亂搶招，再用三個輕攻擊串成幀數陷阱抓亂動。
    5. 中腳／蹲中腳取消綠衝：是最萬用的連攜起手，命中接大連段、被防直接進無縫壓制與投／打擊二擇。

    一、壓制的基本思路：把對手關進你的節奏

    壓制的核心目的，就是讓對手只能被動防禦或被迫猜拳，進而犯錯送出更多傷害。

    • 進攻流程：從中立距離用手上技能命中 → 立刻貼上去「壓起身」；就算原本在防守，只要對空打落對手，也是立刻轉守為攻壓起身。面對愛後退保守打的對手，更要用壓制逼他重新面對你的節奏。
    • 壓制節奏要緊密：輕攻擊連續壓制時，命中就繼續接招、沒命中（被防）就停下來觀察對手會不會反搶或拉開安全距離，千萬別留下太大破綻。
    • 中下段交替＋抓不按動力反攻的對手：中段與下段輪流壓制會讓對手極難起跳；當你發現對手不太會用「動力反攻（Drive Reversal）」時，可以更放心地狂用中腳或輕點按持續施壓。

    二、角落與版邊的恐怖威力

    • 為什麼大家拼命把人推向角落？：在場中防禦攻擊只會被推開，但在角落被防禦／撞牆會觸發暈眩（吃滿套大連段）！更重要的是，在角落的對手沒有後退空間，你只要站在能來回走動、又能用最遠按鈕騷擾的位置，就能不斷誘出對方失誤、施壓或抓投。
    • 版邊最高原則：關住他，別讓他走出來：靠近角落後對手常會急著按招或亂跳，反而更容易撞上你的置招。盡量別隨便用「後投」把對手摔出角落（後投通常只拿到位置優勢，沒辦法做強壓起身，除非是自己被關在角落要換邊）。
    • 中場安全跳要注意：中場用安全跳時因為要看對手原地起身還是後退起身，效果不如角落穩定；角落才是安全跳與壓起身最穩的戰場。

    三、預先擺招（置技）、中腳壓制與綠衝連攜

    1. 預先擺出的技（置技／壓起身）

    • 擺在對手出招前：當對手往前走或起身想動時，提前在路線上擺出判定突出的招式（如蹲中拳、中腳），或「蹲輕拳／蹲輕腳 → 站中腳」的設置，讓對手自己撞上來並接連段。
    • 被對手預先擺招煩到怎麼辦？：別直接硬開綠衝撞上去！目標是站在外側打懲罰反擊，或是改用更長的距離攻擊對抗（沒飛道具的角色這時只能靠跳躍或反制技硬破）。
    • 被中腳刺到的對策：常被對手用中腳刺到，代表你可能太常無腦擺同一招了；可改用預先蹲防，或用站中拳、站中腳、縱向重拳去覆蓋他。反過來，如果對手一直蹲防你的中腳，就多踢幾腳給足壓力，等他開始想後退時再定下來連攻。

    2. 中腳壓制與綠衝取消

    • 中腳壓制的威力：連續中腳施壓會讓對手害怕而不敢亂動，這時就能趁機切入其他連攜（注意先端被壓入時可用站輕腳對應，中拳連攜在特定距離則要小心對手強行反擊）。
    • 動力箭步（綠衝）取消接連段：原本接不到連段的普通技，取消綠衝後就能直接接蹲中拳 → 角落搬運必殺技把人送去版邊。尤其「蹲中腳取消綠衝」後接無縫連續攻擊，能封死對手在綠衝中插招反搶，安全進入打擊／投技／退康三擇。
    • 火球掩護綠衝：丟出慢速火球後緊跟在後面開綠衝（或步行接綠衝），對手的視線與反應都會被遮擋，極難應付。

    四、幀數陷阱、有利按鈕與防禦提醒

    • 三個輕攻擊串成幀數陷阱：連續按三個輕攻擊（中間刻意留 1～2 幀小縫隙），對手只要想搶招或按解投就會直接被截擊；多做幾次對手怕了，就會乖乖站著讓你摔。往前墊步後接壓制也能覆蓋對手 4 幀的搶招。
    • 善用「被防後有利」的按鈕：幾乎每個角色都有至少一顆被防住依然正幀（有利）的普通技或必殺技，拿它當作壓制核心，對手就不敢隨便在你之後按鍵。
    • 緩衝與延遲進攻：在對手防禦的時機多等一點點再按鍵（延遲打擊），有時能一邊防住對手的無敵凹招、一邊把壓制重疊上去；被貼身壓起身時，也可以在能防住對方打擊壓制的時機稍微延遲按蹲中腳，防下打擊之餘順便踢中想後退防拆投的對手（可取消綠衝的角色回報極高）。
    • 對手 Burnout 時的高 CP 值壓制：對手 Burnout 時若狂用 3 格「取消綠衝」，反而會害自己氣槽見底被逆轉；改用只要 1 格氣的「生綠衝攻擊（打在遠距離先端）」最划算！因為 Burnout 期間防禦硬直增加，多數角色都能取得有利幀直接進打擊／投技二擇。此外平時被防必確反的「大足（2HK）」，在對手 Burnout 期間靠先端命中也很難被反擊，命中後還能在起身時再壓大足誘發亂動或無敵技。
    • 千萬別只會死防：只靠原地防禦會一直被削血、耗光動力量表並被推回角落。適時配合撥擋（Parry，能減緩被逼進角落的速度）或找空隙反打才是長久之計。

    五、各角色壓制與連攜補充

    • 隆：一邊後退一邊擺技並混入綠衝取消，命中或被防都能延續攻勢，中腳綠衝後推薦用輕龍捲旋風腳收尾（現代隆在場中一律優先用龍捲或 OD 足刀 → 前強龍捲把人搬往版邊搶起身，已經靠近版邊時才選「集中」強化壓迫力）。站中拳是主要壓制工具（改版後被打判定變大但依然核心）；波掌擊後段雖慢但命中有利可接摔（第二季更強化為蹲中腳可直接接電刃練氣波掌擊，就算被防隆依然有利可打打擊／摔二擇）。角落 OD 波動後可接前重腳 → 龍捲（注意太近會空振）。集中狀態時也可用目標連段混衝擊做初見殺變化。
    • 肯：極強的角落搬運能力！場中一個基本連段（如中腳命中接生綠衝 → 輕拳，或中央偏後方的後摔）就能把人一口氣送到角落，接著靠角落的摔與打擊二擇收割。現代肯當對手死防蹲中腳綠衝時，可改用「生綠衝 → 弱攻擊」偷襲或「奮迅前蹴り」（Counter 可接輔助弱）分散注意力。面對愛後退防禦的對手用蹲腳接輕拳擊破；蹲中拳與特定掃倒壓起身讓肯在防禦後有很多選擇，善用中腳送距離壓制。
    • 豪鬼：壓制的終點永遠是把人推到角落！站輕拳快又安全適合近距慢慢磨；新手也可用站中腳接站重腳（中段且安全）。對付蹲下的對手時記得先用蹲中攻接站立中攻「鎖成站立」再接龍捲斬空腳；兩次輕拳接輕龍捲不在近身會距離不夠（對蹲姿也會空振），需改用掃堂或重龍捲／重昇龍收尾（輕金剛灼火延伸對蹲姿也會空振）。連段太長離太遠安全跳打不到時，改用雙重衝刺覆蓋。注意別一直只靠蹲中拳壓起身以免被反打，且單鍵取消百鬼動作固定容易被對空；對戰豪鬼時只要能止住他的百鬼就不會陷入無限削血循環。
    • 泰瑞：沒有本田頭槌或布蘭卡滾動那種無腦單方面壓制技，必須靠地上站中拳／蹲中拳搶在對手出招前壓起身並確認接綠衝。在蹲中腳範圍內可用 蹲中腳 → 綠衝 → 蹲輕拳 做有利壓制再打退康與摔的二擇（或直接用 2MK > 2HK 省 3 格氣接重燃燒指節推角起攻，被防才取消綠衝保命）；距離遠時可接 綠衝 → 站中拳 → 目標連段（現代版「中→強」命中可用生綠衝＋輔助重起攻，先端被防無確反）拿有利起身。燃燒指節擊中防禦時「畫面出現震動」代表泰瑞有利幀。泰瑞最大強項同樣是「超強搬運」，崩裂噴射輕／中版則適合連段串接防打斷。
    • 盧克：先用強勢的綠衝（中腳／蹲下）壓制，拿到傷害後回合交出去時再用牽制與噴沙拉開。膝擊命中後的接續看距離（最遠接蹲中拳或輕目標連段，太近只剩輕拳）；沒時間綠衝重腳時直接用綠衝蹲中拳。
    • 拉希德：逼到版邊就是拉希德的主場！用輕旋風出強化旋風，不管防沒防住都能繼續加幀壓制（接摔或輕拳打亂動，對手一拆摔就吃大連段）。中距離連段推薦 蹲中拳 → 綠衝取消 → 站重拳 → 重阿拉伯旋風派生滾動 → 蹲輕拳 → ↓↘→＋輕拳（或接中鷹襲推牆），或重拳接中鷹襲再接旋風彈逼防推角。近身確認鏈則是連點蹲輕拳接輕旋風擊推開；另外他還有多種利用二級超必殺在中距離／版邊「強制裁」接摔或收尾的壓制套路。
    • 嘉米：中腳被防後可以直接走摔（對手拆摔就後退退康狩掉）；前衝反手拳是重要壓制循環（中拳或輕拳接重版前衝反手拳壓制對方 DI）；角落時可用重版流氓組合交叉接跳下踢換邊繼續壓。地面靠站輕腳、蹲中腳、站重腳接螺旋飛箭控制。
    • 韓蛛俐：站中拳壓制極強，最穩健組合是 站中拳 → 蹲中拳 → 中風波漣（並一定要拿到中腳上挑的擊倒確定，讓對手無法後退）。對戰韓蛛俐時，被她的壓制打一般防禦很快就會被推到角落，建議按住撥擋（Parry）拖慢被推角的速度（她自己也會被推開）。
    • 傑米：站中（5MP）是極難反制的主力壓起身技，對戰他要站在站中打不到的位置；重拳近距打 3 段接 DI 會被斷，稍遠只打 2 段時接 DI 才可行；重拳掌被防後接站中拳常剛好超出對方輕拳反擊距離，而遠距離輕／中推掌先端讓對手防禦時僅 -1～-3 幀，對手想搶反反而容易被我方 Parry 抓出 Perfect Parry 確反（EX 推掌被防更達 +2 幀）。壓制中也常在三輕攻擊後接 4HP 利用後縮受擊框誘騙對手 2MK 揮空吃懲罰康；天晴腳後則有 MK 天晴腳 → DR → 6MK（被防 +3）或 HK 天晴腳 → 揮空 2MP → DR 2MP（被防 +6）等高有利幀套路。另有一套實用的「開局喝醉壓制路線」（含 DR 5HP 打幀數陷阱／投技、OD 掌拿 2 醉意等）。
    • 春麗：常用中追突拳接重拳與中腳連攻 → 中拳 → 架式超必殺壓制；蓄力後可用 中腳 → 中波掌擊 確認接三級超必殺，或在對手擋下有空隙時走到身後點兩下輕攻再後退放波。站輕腳距離夠時可直接取消超必殺。
    • 迪傑：結合搖擺與退康製造持續壓力，站重腳命中後因為有利幀不多要立刻接著按拉近距離（站立時可用 3 下輕拳＋2 下上段腳，對蹲姿需改接中段迴旋後踢或花綠衝讓對手站起）。對付迪傑的壓制要注意他常從外側用中腳、蹲中拳把人關在角落。
    • 艾德：輕拳連段很吃距離（蹲輕腳不能特殊取消，必須接回站輕腳，稍微後退一點連段就會斷）；蹲中腳打中後近距接重拳、中距打兩次蹲中腳、太遠直接 OD 拉繩拉回來。壓制後接後退相當紮實；對付艾德時，他在遠距離連攻容易止住對手，但對「近距離連攻」反而較難應付。
    • 阿鬼：利用地面火球後打二選一（撞擊中腳或較慢的中段攻擊，兩者都能進完整連段），或接動力箭步貼身變「高段／下段／投技」三選一；中距離連段後可用雙衝接 ↓↘→＋前重拳 收尾打摔或自動時機投。前重腳被防後接站中拳就算跟對手輕拳相消也還是有利，可繼續壓。
    • 艾蓮娜：站中腳被防可形成真連防壓制；核心是在中距離立回確認命中後切入擇，並靠高搬運性能的連段把人送去角落再快速連攻（面對防禦中的對手可混入站中拳、蹲中等安全繼續壓）。現代版「輔助中 → 後＋SP」被防無確反，確認命中接前＋SP 後可用「弱版翻滾×2 → 前輕攻擊」壓起身（被防仍貼身有利且在摔技距離內）。她比較怕遇到會努力「走動防禦」的對手。
    • 瑪濃 / 拜森 / 維加 / 不知火舞 / 金伯莉 / 瑪麗莎 / 蓋爾 / 達爾西姆 / 沙加特 / 埃德蒙本田 / 布蘭卡 / 桑吉爾夫 / 深紅毒蛇 / 雅絲敏 / 阿周那 / JP：
    • 瑪濃：後重拳被防後改為正幀，給了她常規的壓制正幀來源（連段可接 OD 旋踢）。
    • 拜森：兩個主力正幀壓制普攻是站重拳與後踢重腳。
    • 維加：連攜不算特別強、多靠火力硬壓（沒資源時站中拳連攜難成立）；缺乏無敵切返，被貼身壓起身非常難受（對戰需控好距離別落入被動）。
    • 不知火舞：站中拳為主力壓起身（可搭配綠衝取消）；下中腳取消綠衝後主力兩路線為接後重腳（強制站立保重版 214P 不揮空且帶進角落，被防仍有利在投技範圍）或接下輕攻擊（真連防）；中蓄力火球適合打上下段二擇（接綠衝下段），遠距也可用前墊步／前走接延遲綠衝做二擇；4 幀輕攻截擊後可接下中腳送人去版邊。
    • 金伯莉：空中進攻無效時改側面衝刺，尤其綠衝站中拳很好確認命中、被防就接摔；前重腳被防後多數角色可用輕攻擊落。
    • 瑪麗莎：近身時走動接向前重腳再接後重腳，選項與角落連段幾乎一樣。
    • 蓋爾：把他逼到牆邊千萬別停手，一停就會讓他放音速爆擊。場中央用「Sonic → 綠衝膝撞」進攻時，需先發波讓對手不敢亂揮；膝撞被防後最穩是用「蹲輕拳 → Sonic」觀察（對手想抓空隙常會撞上 Reverse Spin Kick）。
    • 達爾西姆：連攜後接「火焰鳥」系可立刻後退拉開兼防禦對策；缺傷害可用特定踢技在立回補傷害。
    • 沙加特：發生慢有空隙，近距離硬壓難度高，需靠理解猛虎波後的節奏來建立壓制。現代沙加特在版邊不花氣的「鳥籠」壓制，可交替用生中段、中 Tiger Nexus（被防無確反）、站中／重與「Assist 中 → 氣功」持續施壓。

    • 布蘭卡：後中系為壓起身主力，普通短判定反擊打不到，要換長判定技打。下中拳取消綠衝後最穩的懶人接法是一律接「後中腳（引き中K）」（不輸 4F 小招、命中可連段、被防可接摔或再按後中腳抓搶招）。

    • 深紅毒蛇：壓起身極強，近距離少跟她硬拼，專心打好地上戰。
    • 雅絲敏：站重拳懲罰反擊可接蹲中拳；後重腳像盧克／傑米的後退技可接必殺或綠衝壓制。
