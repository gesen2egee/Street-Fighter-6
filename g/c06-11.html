    後退防守與距離管理

    常覺得自己明明一直按住防禦，還是動不動就被對手「走過來摔」、被下段踢倒，或是被關進版邊角落跳不出來嗎？這篇專門講《快打旋風 6》最細膩也最實戰的「距離管理與後退防守」——什麼距離該蹲防、什麼時候該小退一步讓對手的摔技揮空、怎麼用「邊走邊防」逼近對手，以及被關進版邊時該怎麼冷靜逃脫！

    ⚡ 一分鐘懶人包
    - 想不被摔？不要站在「投技距離內」猜拳！ 蹲下也會被摔（投技會強制把你抓起來）。中距離時善用「小後退一步再立刻蹲防」，既能讓對手的摔技直接摸空，又能擋住後續的 蹲中腳 下段！
    - 紅區鐵則（對手拳腳直接摸得到的距離）：在紅區內預設蹲防或出招反制，千萬別在紅區裡一直站著往後退，雙腳會瞬間被對手的 蹲中腳 踢翻！
    - 後退防守的神效：連續壓制中多數招式都是負幀，只要適度後退拉開距離，對手的短手輕拳跟投技都會自己摸空（而且還能誘出對手的揮空做反打），逼對手必須冒險出大空隙或下段！
    - 被關進角落怎麼辦？ 別一倒地就瘋狂按解摔或亂凹昇龍（凹中一次噴半條血，影片說法、官方卡未列！）——先穩穩按住後下蹲防等對手回合結束，或抓準對手前走想摔的空檔「前跳換邊」／用輕攻擊推開，偶爾配合後墊步與完美撥擋（Perfect Parry）打破對手的柔道循環。

    一、距離管理：站在哪裡才安全？

    1. 投技距離外 vs「紅區」

    • 投技距離：普通摔起手極快、人類無法靠反應解開，最好的防禦就是「用空間戰讓對手進不了你的投技距離」。只要判斷出對手離你夠遠、不可能摔到你，你就可以安心排除投技選項，專心防打擊！
    • 紅區（對手普通技直接摸得到的距離）：
    • 在對手回合的紅區內，基本原則是「拉住蹲防」或「出招對抗」，千萬別站著往後走，因為往後走無法防下段，馬上就會被踢中。
    • 自己想踏入紅區前要先想好對策（小心對手隨時會取消生衝貼臉）。如果對手只是一直龜著防禦待機，代表他沒有起攻意圖，你可以小步試探再決定要不要踏進去。

    2. 「小退一步 → 立刻蹲防」的中距離萬用步法

    • 情境：中距離你身後還有空間，但一直原地死防很容易被對手走過來摔，或者被他用輕拳偷摸。
    • 怎麼做：當對手進攻出現短暫停頓，或你想躲開可能的走動摔時，輕輕往後退一小步，然後馬上拉回後下（蹲防）。
    • 為什麼：後退一小步就能走出對手的投技範圍，馬上切回蹲防則能穩穩擋住想抓你後退的 蹲中腳！
    • 常見踩雷：
    • 在對手連續點輕拳或使用超長距離招式時只後退一步，一樣會被打中。
    • 剛吃完 蹲中腳 或被壓在近距離負幀時硬往後退：無論跳攻後、不利招被防後（如 -3 幀）或版邊後跳落地，只要處於對手先動的時機直接後退就會吃中足！正確做法是先蹲防一小瞬間，確認擋過最快中足反擊且對手沒出手後，再往後走或後跳拉開距離（或直接用後墊步離場）。
    • 「蹲著等退康（しゃがんで待つシミー）」防下段逆擇：一般走路退康時下段不設防，容易被進階對手用 2MK 取消生衝逆擇踢死；高階做法是退到投距外後立刻「蹲下防禦等待」，既能防住下段確反，看到對手前跳換邊還能空對空擊落。

    二、後退、後墊步與跳躍的防守選擇

    1. 「後退走路」為什麼這麼強？

    • 讓對手的輕拳＋摔全部落空：對手常用「單發輕拳 → 摔」或連續輕拳取消壓制。只要對手沒有足夠空隙，後退就能拉開距離，讓對手的第二發輕拳和摔技雙雙揮空，順便讓你在中間找到反擊或抓揮空（差し返し，即差合）的機會！
    • 搭配「三段防守節奏」：下段防守連續擋下對手 3 下普通技後，對手的推開距離通常已經出來了，這時立刻改為後退離開壓制，把局勢重新整理回中立。

    2. 「後墊步（44）」與「後跳／垂直跳」怎麼選？

    • 後墊步（Backdash / 後後）：開頭第 1–15 幀具備投技無敵，能閃開對手的摔並在中距離抓到確定反擊；但沒有打擊無敵，對手出打擊一樣會被打中，所以應對無敵技（如昇龍）時不能靠後墊步，且面對指令投若用後跳有時抓不到確反。
    • 後跳（4 方向跳）：可以安全逃離連續壓制與暴起誘招（在版中風險很低）；但切記不要因為怕被摔就無腦一直後跳，如果後跳落地沒招反擊，對手一樣會追上來繼續摔你，甚至被對手讀到直接對空或進角落。
    • 垂直跳（中立跳）：在對手面前垂直跳起，可以同時躲過無敵技（部分情況）、強化截擊與對手的投技／解摔嘗試，成功躲過無敵技時還能落下打滿整套！

    3. 「前進防禦（走防 / 邊走邊防）」—— 追近對手的安全步法

    • 情境：招式攻擊距離（リーチ）輸給對手（例如隆對上艾德），或對手一直往後逃／發波拉距離，你想貼近他又怕在走路瞬間被打中。
    • 怎麼做：
    • 安全距離外大膽走，踏入射程才點防：先摸清對手長距離招式（如艾德蹲重腳）的極限射程。在打不到的安全距離外持續往前走，不用浪費時間按防禦；一旦踏入對手射程瞬間，改用「小碎步走一下立刻拉蹲防（小刻み歩きガード，即碎步走防）」，把按「前」的無防禦時間壓到最低，等確定對方沒出手再踏下一步直到進入自己射程出招。
    • 背靠版邊的走防限制：被逼到版邊時自己無法後退但對手可以後退，亂按極易揮空，因此版邊往前走防的距離必須壓到最小限度。
    • 依對手有沒有「中足取消生衝」調整緊繃度：面對有中足取消動力箭步（綠衝）的角色，立回亂晃中招就是半條血進版邊（影片說法，官方卡未列），必須極度重視蹲防與謹慎走防；面對沒有中足取消動力箭步（綠衝）的角色（如 JP、瑪麗莎），移動時就可以稍微大膽一點。

    三、被關進「角落／版邊」的逃生指南

    1. 角落第一原則：冷靜！別亂凹也別急著按解摔

    • 情境：背靠牆壁被對手壓制，緊張到一直亂按解摔或無敵昇龍。
    • 怎麼做：優先選擇「按住後下蹲防，撐過對手的回合」，同時算清楚自己目前的血量還能扛幾次摔或幾次打擊。若腦容量不夠想簡化起身防守，可先採用「約 6 成純蹲防（讓對方誘投無效並結束壓制）＋約 4 成預判對手要摔時用跳躍／跳中拳反制」的簡單配置（影片說法，官方卡未列）。
    • 為什麼：在版邊亂凹昇龍被防住，一次就會噴掉將近半條血（約等於被對手連續摔 4～5 次才有的傷害，影片說法，官方卡未列！）；被退康抓到揮空摔同樣會直接蒸發半條血（影片說法，官方卡未列）！穩穩擋住、等對手的招式結束輪到你動（或是先用輕攻擊把對手推開／找機會出下中腳控距），比賭命划算得多。
    • 注意角落的動力衝擊（DI）：角落被動死防也要提防對手的 DI 上牆，選項中要適度保留跳躍或撥擋。

    2. 角落打破柔道循環的「主動逃脫」

    • 前跳換邊：當你讀到對手習慣在版邊壓起身「前走摔」或後退防禦時，果斷按住前跳（跳過對手頭頂交換位置，起身跳本身有投技無敵！）。雖然可能被對手反應回身對空昇龍，但對大多數玩家來說「回身對空」非常難按，只要換邊成功你就瞬間翻身成為把對手關進版邊的人！
    • 後墊步與完美撥擋：版邊面對對手持續柔道摔時，偶爾用後墊步躲摔接 4 幀確反（影片說法，官方卡未列），或是抓準完美撥擋（Perfect Parry）反摔換邊，才能打破對手的節奏，不讓對手無腦爽壓到底。

    四、各角色距離管理與後退補充

    • 達爾西姆 / 不知火舞：
    • 花蝶扇應對：第一段被防住、第二段從上方落下時，距離夠遠可直接後退躲開，距離近則必須用後墊步（注意每個角色後退走路速度不同，像達爾西姆走得慢，近距離絕對走不開，要依自己角色速度判斷）。
    • 面對不太會讀招的現代舞，後退是非常強的防禦（因為部分情況下段較難立刻打出），但若走太慢被踢到仍會掉血（影片說法，官方卡未列：約 1000 傷害）。
    • 對達爾西姆推薦用「前墊步＋蹲防」縮短距離；注意達爾西姆遠距離反攻判定較窄，近身壓制時可多利用。
    • 豪鬼（Akuma）：
    • 被豪鬼壓起身輕拳壓制時，先蹲防再小退一小步回到下段防禦，這小步就足以走出豪鬼的摔距離讓他摔空接反擊（但千萬別退太久，會被中段和下段打中！）。
    • 起身後墊步／後跳可躲摔並觀察反應；2MK 可取消必殺技（有氣取消生衝、沒氣取消氣功）來中斷對手退康。中央被龍捲後對手想詐欺跳時，建議「原地防守」而非向後受身，完美撥擋成功就能反摔。
    • 肯（Ken）：
    • 後跳與後墊步有投無敵，可同時破摔與解摔誘導；面對肯的壓制可主動展示後退讓他的摔難以確定命中，或是用「微前進後退」的退康步法安全試探。若自己連打兩下剛好把自己推到對手輕攻範圍外，就能等對方延遲輕拳揮空再反打！
    • 艾德（Ed）：
    • 拉住「後下（蹲防）」時，除了摔技以外幾乎很難被艾德的打擊打開；加上他普通技推開距離大，很多生衝後動作其實接不到真摔。
    • 被蓄力／OD 念力閃刺拳防住會被拉近，看到準備動作記得配合撥擋縮短被拉近的距離；艾德的後跳能同時躲掉摔與退康。
    • 韓蛛俐（Juri）：
    • 版邊「摔 → 前墊步 → 摔」循環可用垂直跳或後墊步應對（注意起身太早按 4 幀技可能被起身判定打贏；版邊摔後要看到她前墊步再判斷 DI 與起身選擇，別只無腦後墊步）。在特定距離下後退步行仍會被摔到，此時無敵技反而較穩。
    • 傑米（Jamie）：
    • 防住連打重拳後立刻用後退步，可以同時讓傑米的摔揮空＋閃過後續蹲輕拳並反擊（對上他改壓 2MK 則要用快速技對應）；防住 站重拳 時他不在摔範圍內，直接後退拉開即可。面對壓制時抓他出中腳的時機「後退＋蹲防」很有效。
    • 拜森（M. Bison，日版名維加）：
    • 站在他會出膝壓的距離「微前進再急停防禦（微防）」可誘他出招；反擊前一定要確認「打不打得到」，前端防住後用夠長的中／重攻擊才不會揮空反被確反。
    • 自己被他壓時若用後跳能躲普通摔（躲過最佳可接 2LP → 5MP），但遇壓起身摔時無法反擊。拜森的起身防禦偏弱，他在角落很難逃脫連續輕拳壓制。
    • 桑吉爾夫（Zangief）：
    • 「後墊步 → 螺旋打樁機（SPD）」是躲摔反殺的重要選項（回報最高但最難；後跳最簡單但高段位容易被讀到吃 SA1 或空投！）。角落跳出接後退或飛身壓可搶回回合，但小心對手近距跳摔。
    • 泰瑞（Terry）：
    • 泰瑞沒有當身／指令摔，對手前進時可用後墊步躲；在版邊警戒順序為「傷害最高的起身三擇 ＞ 摔技 ＞ 打擊」，減少被解摔次數並適時跳出。另走路誘騙的距離太短會讓對手看穿而不防。
    • 嘉米 / 艾蓮娜 / 隆 / 布蘭卡 / 沙加特 / JP / 瑪濃 / 金伯莉 / 瑪麗莎 / 拉希德 / 阿鬼 / 盧克 / 蓋爾 / 埃德蒙本田 / 春麗 / 英格麗特 / 亞思閔：
    • 嘉米：角落首選完美撥擋逃脫；注意她角落連段後可能用 OD 拳換邊打背，記得換邊防禦或完美撥擋。
    • 艾蓮娜：後退對她很有效（後退時她想追打連蹲輕攻也接不到連段），但重派生被防仍有利不可亂退。
    • 隆：版邊讀到摔可用後墊步拿到確定（視對方有利幀數而定）；走路一定要邊走邊防。
    • 布蘭卡：中央摔後可「後退＋4 幀反攻（影片說法，官方卡未列）」拆掉大部分選項（小心中腳下段）；角落被壓蹲防成功一次就能穩住，防完百貫／壓制別原地呆站。
    • 沙加特：建議偶爾拉開約十步距離（影片說法，官方卡未列）讓他的 中拳 → 前走摔 承擔風險；JP：千萬別站在鴿子（傳送門）跟 JP 中間被前後夾擊，角落多用垂直跳；瑪濃：+3（影片說法，官方卡未列）後的摔無法用 4 幀搶掉，改用後跳比垂直跳更安全！
    • 阿鬼：跳後退躲摔常可接 2LP 確反，也可多用 站中拳 打斷距離陷阱；拉希德：用「後退、防守、後退、防守」節奏讓對方承擔風險；盧克：可用向後重攻躲開對手的重技反搶；埃德蒙本田：只靠原地防禦會被削光氣條逼退，必須適度結合前進或撥擋。

    五、實戰情境與流派差異提醒

    • 後退走路能否應對無敵技：官方卡只列後墊步的投技無敵，沒有打擊無敵，因此後墊步不能應對無敵技（見正文第二節第 2 點）。但有一支影片說後退走路可擋住無敵技且回報高，另一支說垂直跳才是最穩的應對，兩者差別在於動作不同（後退走路 vs 後墊步）。「後退走路能防住無敵技」之說法未經官方卡核對，請以訓練模式確認。
    • 角落前跳到底安不安全：一派強調持續按住前跳就能跳過頭頂換邊脫離角落；另一派提醒在版邊前跳依然有被對空或位置卡住的風險，需挑對手前走摔或後退時再跳。
    • 達爾西姆亂按投技／花蝶扇的後退躲摔：不同影片（甚至同一部影片前後段）對於「投技到底能不能單純靠後退躲開並確反」條件描述不完整（實際取決於雙方距離、有利幀與角色走路速度）。
    • 韓蛛俐的兩種後退：一段指「後退走路」會被摔，另一段指「後墊步」可拿回報，屬不同操作情境。
    • 單一影片數據：
    • 文中提及的「角落凹昇龍／退康約損一半血量（約 4–5 次投）」「版邊下中拳／下中腳 8 幀」「達爾西姆被踢約 1000 傷害」「布蘭卡 4 幀反攻」「瑪濃 +3 後 4 幀無法割開」「444 防守」「隆後墊步有利幀門檻」「拜森防禦全遊戲最弱（個人意見）」等皆為單一影片說法，請依實戰與訓練模式確認。
