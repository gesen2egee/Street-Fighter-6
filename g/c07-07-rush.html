    動力箭步（Rush）連段與追擊

    學會「裸綠衝」跟「取消綠衝」怎麼按之後，下一關就是把它真正接進連段和壓制裡！綠衝最可怕的地方，在於它能把原本「接不到、浮空掉下來、被防會虧」的拳腳全部變活。這篇指南會告訴你綠衝連段的通用公式、怎麼抓雙重取消上限、資源該怎麼取捨才不會把自己燒乾，以及全角色的綠衝連段實戰思路。

    ⚡ 一分鐘懶人包（直接照做版）
    1. 萬用連段公式：「拳腳起手 → 取消綠衝 → 拳腳 → 可接浮空或必殺的招式 → 超必殺收尾」，光靠這套結構就能多打好幾百點傷害！
    2. 綠衝賦予「浮空追擊」特性：平常打浮空對手接不到的重攻擊或蹲中腳，只要透過綠衝衝過去按，就能像必殺技一樣把對手重新撈起來繼續連。
    3. 一般連段上限「兩次取消綠衝」：大多數情況最多取消兩次就好（除非確定能直接收掉對手，才拼極限收尾），否則傷害遞減太嚴重、還不如留資源進角落壓制或配 SA3。
    4. 別只會無腦接「無空檔連防」或「只接摔」：綠衝後如果一直出安全連防會少很多傷害，如果每次都只摔又容易被看破，記得混用「打擊／投技／退康（誘摔）」。

    一、綠衝連段的四大實戰核心

    1. 為什麼綠衝能延長連段？

    • 動作快 +4 幀：綠衝後按出的第一下拳腳，不論命中或被防都比平時快 4 幀。原本連不上的招式會變真連段，原本被防不安全的招會變有利，安全的招會變幀數陷阱。
    • 疊加截擊／確反獎勵：抓到「懲罰反擊（Punish Counter）」原本就多 +4 幀、傷害多 20% 還會扣對手綠條；搭配綠衝起手或確反，能疊出超大有利幀（例如 +8 甚至 +13 以上），打出整場最痛的懲罰大連段！
    • 賦予一般拳腳「浮空追擊」性質（限第一下）：對手被打到浮空快落地時，平常按普通拳腳是撈不到的；但只要透過綠衝衝過去按（輕中重皆可），該拳腳就會暫時獲得「追擊浮空」的性質，讓你把連段一路搬到角落！但注意：此提升效果僅限綠衝後的第一下攻擊，且必殺技本身不會因此變強，同時綠衝會進一步加重後續連段的傷害補正（有時較短的連段反而比硬加綠衝總傷害更高）。

    2. 什麼時候該用「綠衝追擊」與「進階擇」？

    • 對空轉大連段：用普通技對空打中後，部分角色可以接綠衝衝過去撈起來打一套，而不是只看對手飛走。
    • 長距離招式擊倒後「遠距離壓摔」：很多長距離必殺技擊倒對手後走過去是摔不到的，這時花 1 格裸綠衝貼臉就能直接建立「打擊／投技／退康」三擇（記得第一次取消綠衝可以先試著退康，順便測試對手的防守習慣）。
    • 取消綠衝「兩次抽獎（2 回抽選）」：被防後除了接輕攻擊連防再擇一次外，進階也可接「延遲蹲中拳」，就算被防也因帶有大幅有利幀而能再做一次「摔／退康」二擇，相當於一次取消綠衝做兩次抽獎！
    • 「綠衝延遲中段」與「可取消輕攻擊保險」：壓起身時「生綠衝延遲中段」與「正常綠衝打擊／綠衝投」構成高回報三擇，專抓高段位習慣延遲拆投的對手；此外用綠衝進攻時若搭配「可取消的輕攻擊（如 2LP／5LP）」做保險，打在對手 DI 霸體上會產生停頓，讓你來得及立刻取消自己的 DI 反擊（可在訓練模式開 Cancel Timing Display 確認哪些招可取消 DI）。
    • 完美撥擋／DI 反擊後接綠衝：成功抓到完美撥擋或反擊對手 DI 後，可接綠衝衝上去確反；小訣竅：反擊對手 DI 後接連段前先「微前走一步」（或前衝＋微走）再打浮空，能讓對手浮更高不易掉招，同時多回復一點動力並大幅推進戰線！

    3. 常見踩雷與安全性提醒

    • 綠衝期間「無法防禦也無法撥擋」：衝出去後只能按攻擊、摔技或 DI。如果在連段或壓制中間留下空檔，對手是有機會用無敵技或超必殺插進來的。
    • 不要在「取消綠衝」後立刻接 OD 技（除非確定斬殺）：3 格＋2 格直接噴 5 格，非常容易一不小心就燒盡；另外連段中稍微微步前進可以順便偷回一點點量表。

    二、動力量表與取消次數取捨

    • 兩次取消是黃金上限：一般連段最多做兩次取消綠衝就夠了（除非阿鬼、肯等少數靠微步回條的特例，或這多出來的一下能直接收頭）。做完兩次取消把人推到角落、留一點量表或直接接 SA3 收尾，遠比花光 6 格把自己搞進燒盡來得划算。
    • 被對手「綠衝蹲重拳」壓制怎麼辦？：部分角色綠衝蹲重拳進大招防禦連段會狂削你綠條（可能扣到一半以上甚至再少兩格），這時如果用動力反攻硬斷一樣會花 2 格。平時看到普通飛行道具就先穩穩防住，抓到空隙或對應的綠衝時再反制。

    三、各角色綠衝連段與追擊補充

    以下是各角色常見的綠衝連段接法、收尾選擇與實戰眉角（請依自己使用的角色挑選閱讀）：

    • 豪鬼（Akuma）：
    • 基本與立回：中立裸綠衝對應很直觀（中段接站中拳、低中腳接站輕腳、蹲輕腳接蹲／站中拳）；波動拳打到對手倒地後可用綠衝重腳拾取。練習場建議把假人設成隨機防禦，練「蹲中腳 → 取消綠衝 → 打中接蹲中拳／被防接蹲輕拳」的確認。場中央 2MK 取消綠衝連段可推進約半個畫面並保有壓制有利時間，將結尾的兩次前衝改為前跳攻擊即可形成「安全跳」（離角落近則改接重旋風腳拉高傷害）。
    • 高傷與搬運：「中腳 → 取消綠衝 → 蹲中拳 → 站重拳 → 重龍捲」可穩穩搬到角落；站中腳可強制蹲下對手站立。抓到對手大破綻確反時，長按火球接綠衝重拳、中龍捲、輕昇龍可接 SA3；綠衝接背後重腳也能把人打浮空再接 SA2 牆壁彈飛。
    • 阿鬼（A.K.I.）：
    • 微步 3 次取消特例：阿鬼靠「綠衝站中腳 → 短暫前走幾幀 → 站中拳」偷回一點量表，能達成罕見的單連段 3 次取消綠衝（站重腳版難度極高不建議帶進比賽）。
    • 實戰路線：施毒後「綠衝 → 重腳」可接各種必殺或超必殺，簡單又痛；站輕腳、站中拳、蹲中腳都能接綠衝抓後退對手。綠衝後期還能取消防禦或後退來釣反擊／退康。
    • 隆（Ryu）：
    • 第二季新路線：裸綠衝或取消後多接「後重腳」（取代早期只接蹲中拳），打浮空接上勾拳可再接 SA3；對手蹲下時也可改接「後心拳（辨識存疑）」傷害更高。
    • 實戰起手：中距離打中前重腳後接綠衝蹲中拳，把對手挑高、搬運到角落且落地後仍貼身；抓到「退康」重拳命中可接綠衝重拳再接昇龍與 SA1。有集中（電刃練氣）時火力更恐怖，沒量表時則用重腳收尾維持集中。
    • 角落與資源：角落用「OD 上段足刀 → 綠衝」壓起身極強；資源足夠時「OD 龍捲 → 綠衝」可再追擊，或用安全跳路線只犧牲極少傷害換穩穩壓制。
    • 肯（Ken）：
    • 肯同樣能靠綠衝中往前小步打出最多 3 次取消。實戰常在站輕腳截擊或跑步中段後接蹲中拳／蹲中腳取消綠衝確認連段（各影片對輕腳確反後接站中拳或直接接輕腳→重昇龍有不同習慣）。
    • 嘉米（Cammy）：
    • 常見高傷路線為「蹲重拳 → 站重拳 → 取消綠衝（重複兩次）→ 蹲重拳 → 站重拳 → 取消重腳 → 昇龍蓄力 → SA3」；求穩的話「蹲中腳 → 綠衝 → 蹲輕拳×2 → 中螺旋飛箭」就算被防也很安全。
    • 角落關鍵：後重腳（對蹲下對手會揮空，站立或浮空可用）在角落綠衝連段中極度重要，搭配蹲重拳接綠衝可打出雙浮空。中距離開綠衝前要評估能不能直接把人搬進角落。
    • 春麗（Chun-Li）：
    • 國民連段「蹲中腳 → 取消綠衝」接站中拳或架式衍生，被防住時接後重拳也是極強的幀數陷阱！
    • 壓制與安全跳：裸綠衝接「蹲輕拳 → 中拳 → 蹲中拳」可依需求轉各種強化必殺或飛行道具；「前重腳懲罰反擊 → 綠衝」是春麗在版中唯一能穩穩打出的安全跳路線（只花 1 格，但角落時有更痛的連段通常不建議用安全跳）。
    • 迪傑（Dee Jay）：
    • 投技命中後推太遠，必須靠綠衝才能壓起身；站重拳平時不利，但在綠衝後抓對時機按下會變有利。
    • 資源效率警告：迪傑使用裸綠衝連段會大幅延遲綠條回復，有時改走「不開裸綠衝」的路線雖然傷害差一點點，但能多回收約 1 格綠條！角落最大連段約消耗 5 格，SA1 後也能接「綠衝蹲中拳 → ↓↙←＋重拳」。
    • 艾蓮娜（Elena）：
    • 不一定要每次都花取消綠衝，因為旋轉鐮刀第一段命中按前拳進連結翻滾就能免費拿強化效果；取消綠衝常用「輔助重 → 蹲重 → 強旋風腿 → 中波（版邊改弱波接強昇龍）」，起攻接「弱翻滾×2 → 前輕」。
    • 想打高傷確反時，「重拳目標連段 → 裸綠衝下中拳（只花 1 格）」或「生綠衝蹲中攻擊 → 取消技」回饋極高；若滿動力起手，綠衝後的下中拳甚至能再取消綠衝一到兩次。
    • 盧克（Luke）：
    • 極度依賴綠衝：盧克沒有取消綠衝時中系連段偏弱，綠衝的最終目標就是為了接到高傷的「蓄力閃光拳」；中段摔後也要靠綠衝壓起身。
    • 裸綠衝輕拳／綠衝蹲中拳後有「摔／後走站重拳打解摔／繼續蹲中拳」的強力多擇；站重拳取消後接「後重腳 → 蹲重拳」或「綠衝蹲中踢 → 蹲中拳」都是自然連段。
    • 泰瑞（Terry）：
    • 摔後綠衝被評為泰瑞最強的進攻選項之一；輕攻擊綠衝接能量衝鋒路線甚至有機會累積綠條。但注意若用輕蓄力起手補正會變重、傷害變低，建議用站輕系或重攻擊延伸。
    • 泰瑞用「中腳 → 火焰踢」做確認時不用先花量表，打中才接連段、被防改用崩裂噴射或波拉開（注意有說法指出網傳泰瑞目標連段被防無腦取消綠衝其實不成立，需視情況接）。
    • 沙加特（Sagat）：
    • 「綠衝站中腳」是目前地面打 SA3 最痛的起手之一；另後重拳取消中版虎波浮空後接「DR 下中拳 → 重拳 TC → 重猛虎膝」，推進極長且停在安全跳距離！
    • 沙加特的資源規劃非常清晰：不花資源走「前重腳 → 後重拳 → 重猛虎膝 → 輕昇龍」；把對手推入版邊後就積極用「DR 下中（抓亂動且防後不退投距）、DR 中段、DR 下弱（騙部分無敵技）」三擇壓起身；背對角落打 DI 反擊甚至能花 3 格直接「角落搬到另一邊角落」。
    • 拜森（M. Bison）／維加（Vega）：
    • 對手吃到炸彈（地雷）時，用綠衝接重拳打在最後活動幀上，被防後能接退康摔；截擊蹲中拳取消綠衝一律建議接站重腳打最大傷，或延遲後重腳抓大量延遲解摔。
    • 若要接重炸彈，有時用「往前走接蹲重拳」比直接綠衝更能偷回一點動力槽。維加踩頭後沒接招的長硬直也是綠衝懲罰的好機會。
    • 瑪濃（Manon）：
    • 靠綠衝吃飯的指令投角色：旋轉型綠衝是瑪濃唯一能在輕攻擊確認後升「金屬等級」的方法；近距離綠衝蹲中拳接後重拳也能自然連段並升階。如果不擅長確認命中，綠衝貼上去直接接「指令投」是最簡單粗暴的解法！
    • 不知火舞（Mai）：
    • 花蝶扇＋綠衝是核心戰術：蓄力花蝶扇打中或被防都能立刻綠衝跟進打「中段／下段（蹲輕腳）／摔技」三擇；中距離「DR → 後重腳（強制對手站立）→ 下中拳 → 重龍炎舞」可確保不因蹲姿揮空。取消綠衝被防時最推薦接「站弱腳」而非輕拳，因為更容易拉開做退康；忍蜂擊倒後「DR 中段」就算跟對手最速技相殺也能接「站重拳 → 龍炎舞 → 忍蜂」。
    • 其他角色速查：
    • 傑米（Jamie）：前重腳後接綠衝有很大有利幀可再接中拳或拉起接指令投（甚至有綠衝＋DI 接指令投的奇襲）；輕攻擊起手開綠衝接 DR 2LP（+9 幀）可目押接 2HP 大幅降低連段補正（34% vs 50%），而 Lv3 目標連段從 DR 2HP 取消接出也不會鑽底（接 SA1 僅花 1 條 DR + 1 格氣打近 4,000 傷）。版中 SA3 後可接 DR 天晴腳浮空 → 5LK 取消 DR，接 2LP 留在前方壓 Meaty、接 5LK 換邊；角落則可用 DR 天晴腳 → 2HP 取消 DR 接中段技 做落地重置。搭配微步與目標連段綠衝，極限殘血時靠 SA3 逆轉能力極強。
    • 桑吉爾夫（Zangief）：蹲中拳判定極佳，接綠衝可打高傷也能反 DI；開 SA2 後想接 3 中拳必須先用綠衝導引。防禦老桑站重拳時可按住撥擋，看到他放空立刻接中立綠衝懲罰。
    • 阿爾俊：格擋後綠衝接「站中腳拳＋昇龍」是可造約 2000 灰傷的真連防；抓到重腳確反接綠衝下重拳可打出超長派生或指令投收尾。
    • 艾德（Ed）：較難純靠走路連投，必須用綠衝補足距離；完全蓄力念力飛拳後接綠衝，防禦優勢暴增（+4 變 +8）；面對對手看到綠光想搶招時，艾德還能用「綠衝急停」接閃刺拳反打。
    • 蓋爾（Guile）：撥擋後立刻接綠衝能懲罰平常摸不到的超必殺；「下中腳取消 DR」直接接「蹲中拳」（比蹲輕拳距離長且更痛），發波掩護下用 Sonic Blade > DR 或 Sonic Cross > DR 站輕腳 能形成連防貼身有利。
    • 瑪麗莎（Marisa）：蓄力重拳／重腳搭配多段綠衝（特別是綠衝後重手接 OD 墊步重腳或超必殺）能打出毀滅性傷害並一路推到角落。

    說法不一與待驗證提醒

    1. 綠衝後第一招到底加幾幀？：通用教學多說「一律 +4 幀」（截擊／確反可再疊加到 +8 或 +13）；但有隆的教學提到綠衝中拳被防後是 +3 幀，可能因招式本身起始負幀或版本差異所致。
    2. 三格取消綠衝到底值不值得？：通用觀念認為連段中花 3 格做取消綠衝有時傷害不划算；但沙加特角落搬運等特定高回報情境下，影片認為有資源就該花。同理，一般連段取消上限為 2 次，阿鬼與肯則是靠微步偷回條的 3 次特例。

    4. 泰瑞目標連段確認：網傳泰瑞可用目標連段被防時取消綠衝拿有利幀，但主講者實測認為「不是真的」且接 4 幀輕拳並不安全。
    5. 達爾西姆綠衝連段：一說達爾西姆綠衝拿不到什麼連段只能拿擊倒後續；另一說跳入後用綠衝比較容易打進去。
