延遲防守與防守選項

每次倒地起身，不是被對手打死、就是被對手摔死，感覺怎麼猜都猜錯嗎？其實高手防守根本不是靠「100% 猜對」或「人類超神反應」，而是靠一套能一次防住多種進攻的「延遲防守」！這篇從新手必學的「延遲解摔」講起，帶你搞懂延遲點、延遲跳、完全不動，以及怎麼把防守選項配得讓對手完全摸不透。

⚡ 一分鐘懶人包 - 新手救星：延遲解摔（Delay Tech）：原理超級簡單——「先按住蹲防，慢個約 0.1 秒（4～6 幀）再按摔」。 - 如果對手出打擊，你在防禦硬直裡按摔不會有任何動作，會穩穩防住！ - 如果對手出摔，你正好處於可以解摔的時機，直接安全解開！ - 單靠這一招就能幫你在銅～黃金甚至白金分段擋掉 80% 以上的打／摔猜拳！ - 延遲解摔的唯一天敵：「退康（Shimmy／假動作後退）」與「垂直跳」。只要對手看穿你愛延遲解摔，他往前走一步假裝要摔卻突然往後退（或原地垂直跳），你的解摔就會揮空，直接吃一套大連段！ - 對付退康的反制：「延遲點（下輕腳／輕拳）」或「完全不動（純蹲防）」！ - 看他愛後退？一樣先防住第一瞬間，再延遲點一下蹲輕腳（2LK）或輕拳，打斷他後退！ - 或者乾脆完全不動（純蹲防）：連退康都不會中招，對手如果一直退康自己還會拉開距離把優勢送給你（只怕真摔和跳）。 - 高手防守的黃金比例：別整場只用同一招！把「不動／延遲點／延遲解摔／無敵技或後跳」像發牌一樣散開輪流用，才能讓對手猜不到你下一秒要幹嘛。

一、別再靠猜拳：先建立你的「防守選項盤」

1. 一次配置好這 4 類工具，輪流打牌

  • 情境：血量落後或被關進角落時，很多人會一慌就瘋狂亂按輕拳或無腦凹昇龍。
  • 怎麼做：把你的防守收斂成 3～4 個低風險＋高威脅選項並交替使用： 1. 完全不動（純蹲防）：最安全、最不容易吃大傷害（血量領先時尤其推薦，被摔一次頂多掉一點血，還能順便重置局勢）。 2. 延遲防守（延遲解摔 / 延遲點）：核心主力，用來同時蓋掉對手的打擊與普通摔。 3. 跳躍 / 後墊步（後後） / Parry：用來逃出投技或應付難以判斷的高低擇（另記住普通跳躍只要在空中「未出招」，落地硬直期間仍可正常防禦與拆摔；一旦空中出招，落地會失去防禦與拆摔能力並帶 Punish Counter 判定）。 4. 無敵技（OD 昇龍 / 超必殺）：有氣時一定要偶爾交一次，逼對手不敢無腦壓到底（沒有無敵昇龍的角色就用 SA 超必殺代替）。高段位進階訣竅：「先防住第 1 發小技後，再打 OD 無敵技」——因為起身直接凹太容易被防住或被延遲摔應對，而進攻方單發小技無法確認通常會連點 2～3 下，防完第 1 下立刻交無敵技剛好 Counter 打中對方第 2 下小技，命中率極高！
  • 為什麼：單純用同一種防守（就算再穩）一定會被對手看穿並針對破招；把選項散開使用，對手的進攻就會變得綁手綁腳。

二、核心神技：延遲防守的原理與三大招

「延遲防守」的核心邏輯只有一句話：「第一時間先交給防禦系統，第二時間才讓你想做的動作跑出來。」

1. 延遲解摔（Delay Tech）—— 同時防「打擊」跟「投」

  • 怎麼做： 1. 對手壓你起身或打近身時，先死死拉住「後下（蹲防）」（不需要站起來解摔，蹲防也能按摔！）。 2. 比你平常感覺「會被打到的時間」再刻意晚一點點（約 4～6 幀／0.1 秒左右）按下解摔鍵。
  • 為什麼有效：如果對手出打擊，你的角色會先進入「防禦硬直」，系統會直接忽略你在硬直中按的摔技；只有當對手沒打你、而是想摔你時，你的角色不在防禦硬直中，解摔才會準時跑出來！這套做法完全不用「看動作猜」，只要每次都按在固定節奏上就好（還可以連續延遲解摔好幾次直到把人推開）。
  • 進階注意：
  • 面對對手「超有利」或生衝／慢速動作時，需要用更晚的「超延遲」才不會早按被打中。
  • 如果你一直按延遲解摔，對手一定會開始用退康（Shimmy）或垂直跳來釣你揮空摔——這時候就要切換成下面兩種做法！

2. 延遲點（Delay Button / 模糊打擊）—— 專抓愛「退康」的對手

  • 情境：對手發現你都不被摔，開始在你面前往前踏一步又馬上往後退（退康），或想走動摔。
  • 怎麼做：
  • 一樣第一時間先拉住防禦擋住對方可能的快打擊，慢一拍再按出「蹲輕腳（2LK）」、「站／蹲輕拳」或部分角色的「5 幀蹲中拳（2MP）」（先拉一小段防禦再點，命中即可確認接重拳）。
  • 高階「模糊蹲中腳（ファジー中足）」：在貼身能防住對方暴れ潰し打擊的時機稍微延遲按下 2MK，成功時可防下打擊壓制並直接踢倒想後退防拆投的對手（具備 2MK 取消衝刺的角色回報極高；缺點是怕延遲打擊與垂直跳，需先給對手想後退的心理壓力）。
  • 為什麼：如果對手真的出拳打你，你已經先擋住了；如果對手往後退想釣你揮空摔，你的延遲輕腳／中腳就會剛好出來點掉他的後退，直接搶回你的進攻回合（甚至確認接連段）！

3. 延遲前跳／延遲後跳／起身前走摔

  • 延遲前跳（破解安全跳與角落壓制）：面對對手安全跳（詐欺飛び）時，維持防禦到極限確認擋下跳攻，在對手落地瞬間往前跳，即可兼顧擋跳攻並用前跳躲掉落地投換邊逃出角落（缺點是若對手直接壓摔會打中預跳幀）；面對「對手有利但不在投距內」的情境（如被春麗角落摔後），也可用模糊跳同時蓋掉打擊與前走摔。
  • 延遲後跳：第一時間先防住，確定對手沒出打擊才往後跳走，可以安全逃離退康與投技（前提是對手沒提前打擊抓你的起跳瞬間）。
  • 延遲打擊（慢一拍中攻擊／重攻擊）：專抓愛做「延遲解摔」或「延遲點」的進攻方或防守方——抓準對手剛過防禦瞬間出手的節奏慢半拍砸下去，直接打成反擊（Counter Hit）。
  • 高階反 Shimmy 趨勢：「起身前走摔（歩き投げ）」：面對精準到連 2MK 都踢不到的退康（Shimmy）時，在能防住下中腳的時機假裝蹲防並突然「前走按摔」。對手直接摔會變正常拆摔，對手退康則會被我方前走摔反抓！就算撞到對手直接打擊，起手多半也是輕攻擊，傷害遠比「普通拆摔被退康釣出 Punish Counter 大連段」便宜得多。
  • 進階前摔輸入訣竅（防對空 Parry 著地延遲摔）：前摔並不需要刻意輸入「前」，只要「沒有輸入後方向」即會判定為前摔！從蹲防（1）出發時，只需瞬間放開「後」變成「正下（2）」並按摔，再立刻拉回 1 方向防禦（否則若對手正在連打輕拳，延遲期間就會被第二發打中）。

三、如何應對「跳入」與「進階二擇」？

1. 擋跳入後的複合防守

  • 情境：對手跳起來踢你，落地後隨時可能再點下段、或直接摔你。
  • 怎麼做：先「站防」擋住空中跳入攻擊，接著馬上切「蹲防」短暫保護下盤，再抓節奏做「延遲解摔」或「擋兩下輕攻擊後再延遲點」。這樣能同時防住跳入、落地偷下段與落地摔。

2. 「什麼都不做（純蹲防）」的威力

  • 情境：你血量領先，或者對手最近一直做假動作後退（退康）。
  • 怎麼做：雙手安分拉住後下，什麼按鈕都不要按！
  • 為什麼：純蹲防可以免疫一切普通打擊跟所有退康假動作！就算對手真的沒做假動作而是走過來摔你，吃一次普通摔也才一千出頭傷害，遠比你手癢按解摔被退康吃掉 4000～5000 血划算太多。但要注意盯緊對手的「垂直跳」跟「DI」，隨時準備對空或反撞！

3. 訓練模式怎麼練延遲解摔？

  • 在訓練模式設定假人錄製兩個槽位隨機播放：
  • 槽位 1：壓起身直接打「打擊連段」。
  • 槽位 2：壓起身直接「走近摔你」。
  • 開啟隨機播放後，不要用眼睛看，練習用「每次完全相同的慢一拍節奏」在蹲防中按下解摔。看著畫面上的按鍵顯示（或等藍色/防禦瞬間過去一點點）抓準時機，做到不管假人出哪一組你都能無傷擋住或解開就算過關！

四、各角色延遲防守與對應補充

  • 泰瑞（Terry）：對戰泰瑞（或用泰瑞）時，「兩幀的延遲差距」就可能決定誰打中誰。面對泰瑞在壓制中故意假動作晃你時，適度「立即反擊摔」有時比延遲摔更意外有效；若對手總是在輕拳後亂按中攻擊，刻意延遲等待就能誘出對方的揮空並大確反。
  • 傑米（Jamie）：面對傑米的連摔循環（柔道），狂按輕拳常常會被他的壓制打成截擊，這時一定要用「延遲解摔」來破解；面對傑米跳入後的壓制，先防好再接延遲蹲輕拳也是低風險解法。另外他取消流醉拳時，用 2HP 取消是真連防，用 2MP 取消中間才有空隙可插招／Parry。
  • 肯（Ken）：面對肯的迅雷腳與重版龍尾腳，第一段擋住後別馬上亂按（會被輕派生壓死）也別無腦一直蹲防（會被中派生砸頭），可先觀察或用延遲解摔涵蓋他落地後的「打擊／摔」二擇。
  • 盧克（Luke）：面對盧克佔優（+1）的壓制與他的中拳節奏，需要用比平常更晚一點的「超級延遲」來抓節奏，才不會在第一時間被打中。
  • 桑吉爾夫（Zangief）：
  • 面對桑吉爾夫的頭槌擋下後，因為你大幅不利，幾乎只能靠「猜垂直跳／後跳躲指令投」或「硬擋普通技」二擇。
  • 桑吉爾夫自己被壓制時，沒有無敵技（除 SA2/SA3 外）可用，除了多利用完美 Parry、各種跳躍逃生與 Jump Cancel SPD（跳躍取消螺旋打樁機，在防守時反破對手墊步與摔技）外，偶爾必須乖乖防禦並接受吃一發普通摔來脫離版邊。
  • 嘉米（Cammy）：練習時可測試「擋住假人 2LP 並同時解掉摔＋對空反應」，才算真正掌握對嘉米的複合防守；除了延遲輕拳／中拳／中腳外，也別一直只死防被她無腦摔到死。
  • 豪鬼（Akuma）：防守時用「蹲輕拳（2LP）」可同時防住下段並確認接輕腳龍捲；面對假連防接 2MK 時有時可用 2MP 反打（若距離合適，用 2MP 比輕拳更不容易摸空）。
  • 阿鬼（A.K.I.）：防禦選項整體偏弱，務必把一般防禦、完美 Parry、延遲解摔與起身 Drive Reversal 全套都派上用場；可用較晚的防禦接 2LK 與重腳的姿勢取消複合應對雙踢與摔。
  • 沙加特（Sagat）：面對肘擊後的第二下防禦時可嘗試插輕拳壓制；面對大坐反應夠快就後跳反擊。
  • 埃德蒙本田 / 布蘭卡 / 迪傑 / 達爾西姆 / 艾德 / 艾蓮娜 / 蓋爾 / 韓蛛俐 / 隆 / 不知火舞 / 瑪麗莎 / 拉希德 / 維加 / 艾力克斯 / 阿爾俊 / 金伯莉 / 英格麗特 / JP：
  • 布蘭卡：OD 放電接中段屬於「真連防」，擋下瞬間按不出 Parry，只能手動擋；在角落被浮空連壓時要交替用解摔、完美 Parry 與 Drive Reversal。
  • 艾德：面對蓄力閃刺拳，若防住被拉近可用 Parry 或防禦對應。
  • 蓋爾：麥格農重拳（中段）發生快，配合生衝＋下段＋投極難防，不能只靠死防，要混用 Parry、解摔與無敵技。
  • 隆：後重腳壓制可用延遲解摔涵蓋；退康接延遲 2MK / 2MP 也是很穩的折衷進攻法。
  • 金伯莉：看到急停時機按投有時可直接抓掉她停下來的動作。
  • 瑪麗莎：小心長按蓄力的站重腳，未命中破綻大但防禦時壓力高。
  • 拉希德：中立跳或 Parry／Drive Reversal 應對突進，不要在他的連段途中太早亂按。
  • JP：失憶（當身技）出現後可用後墊步與 Parry 應對；自己玩 JP 在版邊用當身擋住對手摔技時，除後摔換邊外，推薦「最速前重腳 → 稍微延遲強炸彈（ストロボ）」或全最速「前重腳 → 弱地刺 → 前步 → 中／強波動」逃生與反打。多傳送門夾擊時要先擋第一個再處理第二個。

五、說法不一與待驗證提醒

  • 原筆記存在的說法衝突： 1. 防守配置的「必備選項」：同一部教學影片前後略有差異——一處強調防守時一定要有「凹與 Parry」，另一處則說「凹、Parry、後退（後後）三者之一即可」。 2. 延遲解摔到底破不破得了退康／後退？ 多數教學明確指出「延遲解摔就是怕後退退康與垂直跳」；但也有影片強調對於基礎「打／摔二擇」的對手，延遲解摔幾乎穩解（實務上並不衝突：純打／摔二擇確實穩解，但只要對手加入退康就會被破）。 3. 沙加特「藍防（Parry）」時機：同一部影片前段說不確定時別亂按藍防，後段對特定招式又說不確定時先按藍防。
  • 單一影片數據與辨識存疑詞彙：
  • 文中提及的「約 25% 選項分配」「降一半以上受傷機會」「高手 90% 用延遲投」「連續延遲投可達 18 次」「延遲 0.1 秒／4～6 幀」「防禦後摔 +4 最強」「沙加特 7 幀放開指令」「一幀投技遊戲概念」等，皆來自單一影片口述或舊作延伸，請以實戰手感為準。
