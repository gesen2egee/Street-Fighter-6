    C05-01

    固定連段與起身流程

    很多玩家練好了一套大連段，實戰打中卻「打完就停在原地」，把好不容易搶到的優勢拱手讓人。這篇指南教你怎麼把連段收尾和起身壓制（壓起身）串成一套固定流程，特別適合剛學會基本連段、想從中低段位穩定往上爬，或是想讓進攻節奏不再斷掉的玩家。

    ⚡ 一分鐘懶人包（直接照做版）
    1. 連段跟壓起身要一起學：挑連段不是只看傷害最高，而是要挑「打完剛好能貼上去壓起身」的收尾。
    2. 打不死就別硬拚最高傷：如果這套連段打完會讓對手飛太遠、而且剛好打不死，寧願少一點傷害，換取能繼續壓起身的優勢位置。
    3. 把最常用的收尾固定下來：在訓練場先把「最常打中的連段 → 起身打擊／投技／防無敵技」這三條路線練成肌肉記憶，實戰就不必臨場亂猜。
    4. 練習假人記得開「第 2 段以後防禦」：因為起身壓制通常接在連段之後，這樣才能測試你的壓制有沒有真的重疊到對手起身瞬間。

    一、為什麼要練「固定連段＋起身流程」？

    1. 打完連段不是結束，而是進攻的開始

    在《快打旋風 6》裡，進攻回報最高的時候就是對手倒地起身的瞬間。 * 常見踩雷：新手常花很多時間背「最大傷害連段」，結果打完對手飛到半個畫面外，雙方回到立回重新搶距離，剛才累積的氣勢直接歸零。 * 正確做法：連段與起身壓制要一起學。從最基礎的循環開始：「立回用牽制技或飛道具試探 → 命中後接上連段並製造倒地 → 立刻貼近壓起身 → 逼出破綻或再打倒 → 回到牽制」。

    2. 什麼是「固定連段（套路）」？

    固定連段不是指打在身上的連續技，而是針對對手倒地後，預先設計好時間差的起身壓制套路（例如收尾後前衝一次＋揮空一個輕攻擊消耗幀數，下一招就會剛好重疊在對手起身的第 1 幀）。 * 為什麼高手也用？ 因為靠「體感」抓對手起身時機很容易早 1 幀揮空、或晚 1 幀被對手 4 幀輕拳搶贏；用固定連段消耗幀數，能大幅降低重疊失誤。 * 新手入門順序：初期先練好兩件事就好——「打倒對手後的起身壓制」以及「起身壓制打中後能接出的連段」。至於主動搶招或精準反制對手，可以等穩定壓得住人再慢慢補。

    3. 進場前先整理好自己的「標準菜單」

    檢查你最常打中的 1～2 個連段，在訓練場把結尾後的 4 種應對整理好：
    1. 打擊重疊：對手起身亂按會直接吃一套。
    2. 起身投技：對手一直蹲防就摔他。
    3. 退康（稍微後退引誘解摔）：對手習慣延遲解摔就退一步反打大連段。
    4. 防無敵技：對手愛起身凹昇龍或超必殺，就先防住再反打懲罰。

    二、通用連段收尾與起身壓制套路

    1. 命中後的貼近與壓制

    • 取消綠衝（動力箭步）後一定要貼上去：重拳取消綠衝後別往後退，直接用綠衝接重拳或後中腳貼近施壓；若在爆炸／擊倒類招式後接墊步再接綠衝，對會往後退的對手也很有效。
    • 中場基本擊倒：輕攻擊 2～3 下接「前四分之一圓＋中腳」是最常見的中場擊倒收尾；打中下中腳後接綠衝，可接站重拳、插重拳再接昇龍拳。
    • 強制站姿路線：部分角色的站重拳（反擊時）或蹲重拳取消會強制對手站起，讓你可以自己決定連段結尾要讓對手維持站姿還是蹲姿，避免後續招式因為對手蹲下而揮空。

    2. 連段後的壓制選擇與變化

    • 延遲蹲中拳：固定接延遲蹲中拳，無論對手後跳或延遲投，都有機會拿到保證連段（是否採用視角色與習慣而定）。
    • 有優勢時用步法延續：取得幀數優勢後，如果能搭配微步前進調整距離再出招，往往比死板地接單一輕拳重疊更有威脅。
    • 中毒與強吹飛結尾：部分招式（如中毒效果、或強化版上勾拳／極限技招式）命中後會拉長對手倒地時間或減少橫向吹飛距離，讓你不用耗氣就能用雙前衝（66）貼上去繼續壓制。
    • 動力衝擊撞倒後：對手被動力衝擊撞倒後，可前墊步接蹲重拳、輕波掌擊或掃倒，藉此回復能量並搶佔好位置。

    3. 角落與畫面端的特殊壓制

    • 角落自動時間序列：只要是在角落以「地面前四分之一圓＋中腳」結尾的連段，接「蹲輕腳揮空 → 站輕腳」，就能剛好調整好幀數形成有利局面，接著可以接投擲或退康；如果對手想按招搶攻，用蹲中拳回應即可。
    • 角落投技假動作：在畫面端投擲後，可以用蹲輕系或輕拳做假動作重疊當作固定連段。
    • 畫面端擺位：部分角色在畫面端踏步調整位置後可拿到明顯有利幀（影片曾提及 +6，待驗證），稍微往前走動一點就能直接埋摔。

    4. 對手起身反擊怎麼辦？

    如果對手倒地後想用「起身反擊」或無敵技脫離壓制，不要每次都硬按打擊技對撞，適時用防禦或快速下落／後退把對手的反擊騙出來再懲罰。

    5. 大足（掃倒）與懲罰反擊投的受身規則

    • 普通大足／截擊大足現在都能「後受身」：版本調整後，蹲重腳（大足）在普通命中或截擊命中時，被擊倒方都可以按後受身拉開距離；只有在 懲罰反擊（Punish Counter）大足 命中時才是無法後受身的強制倒地。以前靠普通大足不給受身來硬疊投技的舊套路已不成立。
    • 懲罰反擊投（Punish Counter 投）強制原地受身：破撥擋或抓收招打出的懲罰反擊投，距離與幀數等於「一般投＋對手原地受身」，對手無法後受身且會被扣動力量表，進攻方可以穩定套用原地受身的壓起身套路。

    三、訓練場怎麼練才有效？（假人設定 3 步驟）

    1. 基本打投循環：把假人設定為「起身防禦」或「起身按輕攻擊／投技」，用你最穩的連段打倒對手後，練習在起身瞬間壓上投技；如果對方被投，就再壓一次；如果對方開始跳起逃跑，就改用昇龍或對空普通技攔截。
    2. 記得開「第 2 段以後防禦」＋「隨機受身」：像盧克這類角色練壓起身時，務必把假人的「第 2 段以後防禦」打開，同時把受身（Recovery）設為「隨機（原地／後受身）」，用視覺提示確認兩種受身都能穩穩壓到，再用「防禦反擊」設 4 幀蹲輕拳配合「全部防禦」測試連攜有沒有空隙（把計數設為第 3 下才反擊還能拿來測距離陷阱）。
    3. 進階高負荷三段錄製測試：在訓練場把假人投進角落並存檔（Save State），錄製以下隨機反應來訓練肌肉記憶與臨場確認：
    4. (1) 基礎測試：跳入 → 中腳 ／ 取消綠衝 → 輕拳（連防） ／ 取消綠衝 → 摔（有空隙）
    5. (2) 實戰綜合測試：在起身反擊與防禦反擊同時開啟「4 幀蹲輕拳」、「延遲 3 幀／8 幀拆摔」、「動力衝擊」、「前跳」與「無動作」隨機，練習看到拆摔再按鍵、看到 DI 反按 DI、看到前跳就對空。

    四、各角色實戰連段與起身流程補充

    以下整理各角色實戰常用的連段收尾與壓起身銜接，挑 1～2 套順手的先練熟即可。

    阿鬼

    • 毒爆與布毒流程：對手已中毒時，「猛毒牙」命中或被防都會觸發引爆（站著會崩潰可接連段、空中會翻滾）；不想續接也能趁長倒地時間設置壓起身。角落連段常用中毒引爆技＋猛毒牙結尾，若不放紫泡泉，可空揮蹲重拳轉成 +44 擊倒再壓起身；想在對手身上布毒，則走紫泡撒毒套路。
    • 國民連段與壓制：重腳 → 惡鬼蛇行 → 腳 → 兩次蹲輕拳 → 重蛇頭鞭（主軸）。下重拳有三種派生：拳（傷害最高但被擋不利）、腳（形成幀數陷阱）、投（指令投）。
    • 近身切換節奏：站輕拳接蹲輕拳後按住防禦就能壓制起身，就算對方出必殺技也來得及防；重蛇頭鞭後接中版蛇輕功可佔據有利位置接投技。

    豪鬼

    • 新手必學基本收尾：蹲輕拳 → 輕攻擊接「中龍捲」或「輕龍捲接掃倒／重昇龍」。輕龍捲後可做安全跳或直接前衝壓起身；中龍捲或重昇龍在畫面中央打擊重疊較少，建議直接前衝貼近。
    • 各常見收尾的起攻／重疊差異：
    • 弱龍捲 → 大足：無氣僅能重疊打擊、無法重疊投；開生衝則打擊、投與退康皆可。
    • 中龍捲：無氣打擊與走路投皆可重疊也能退康；若改用前衝雖能重疊投但因過近無法退康（打擊重疊較佳）。開生衝則三者兼顧，推薦 Set Play「蹲輕腳 → 前重拳」壓持續（但無法退康，想退康應停在蹲輕拳）。
    • 強龍捲／中或強昇龍收尾：強龍捲無論無氣或生衝皆無法重疊投（無氣用前衝接前重拳，或場中改用中龍捲收尾）；強龍捲接中昇龍／小技接強昇龍無氣僅可重疊打擊，開生衝則可兼顧投技（但小技點 3 下接強昇龍距離過遠時無法重疊投）。
    • 對蹲姿對手要注意：對蹲下的對手，連段要改用重拳昇龍收尾，或先用蹲中腳 → 綠衝取消 → 蹲中拳把對手逼回站姿。
    • 不耗氣與經典接法：站重拳打中接「↓↙←＋重拳」是不耗氣的穩定路線；掃倒後接雙重衝刺（66）可直接進入投技距離。
    • 翻身技與波掌擊進階：綠衝接重波掌擊後可接重翻身技（按住下方向取消為腳，再接空中翻身技選項）進入投距壓制；角落壓制時，強化版波動拳被擋後可接輕拳，之後投技幾乎必中。
    • 瞬獄殺壓起身（+3／+4 幀設置）：透過消費幀數（如空揮輕拳接下重腳後兩次前前）製造 +3 或 +4 有利幀時，7 幀發生的瞬獄殺能避開對手起身投技無敵並快過 4 幀最速攻擊（因無無敵仍怕凹無敵技，須備好抓跳躍的懲罰連段建立心理壓制）。

    艾力克斯

    • 簡單突進壓制：連段後直接接突進，持續用打擊重疊施壓就好，不必想得太複雜。
    • 步法與判斷：命中後可用一般步法接連段，或突進向深處攻擊；若突進後發現接不上，再改走另一條路線。踢倒後小跳踢背循環屬於較冷門的套路。
    • 蓄力重攻擊派生分歧：無 SA 量表時，「蓄力輔助重攻擊 → 輔助重攻擊」後接「後中攻擊」可保留起攻機會；接「後＋SP」會進指令投換邊（無起攻）；改按「後＋輔助＋SP」則升級為強化版指令投（起攻稍佳，還能接一鍵二級超必殺）。

    阿爾俊

    • 設置起攻為核心：阿爾俊極度依賴「設置（岩石／毒池）」打起攻。設置命中或設置中突進命中後接「倫理崩壞」再接設置，是火力最高的必學路線。
    • 不耗氣拉近與削血：連段後用「前捨」或「殺戮／突進類移動」佔位，有利時接中拳重疊削血；下重拳接中撞或反波拳（毒池切在腳底）都能製造很長的有利時間，直接進入打投二擇。
    • 角落壓制：角落接到能放極限技版石頭的連段後接一級超必殺，能逼對手硬猜；站中腳取消綠衝蹲重拳接 ↓↘→＋中拳可形成極難破解的連防壓制。

    布蘭卡

    • 截擊與人形套路：截擊連段可用蹲中腳接站重腳，或後中腳接站重拳；輕腳垂直旋轉突擊要接連段時，得先補兩次蹲輕拳才不會揮空。
    • 前跳繞背控制：連段中想落到對手背後，前跳要稍微延遲數幀；想落在前方就立刻按。
    • 人形（二級超必殺）基本流程：設置人形後，常用「後中腳 → 極限技版閃電雷擊 → 中段或下段二擇 → 連段」這套最速流程，搭配阿洛利投或地雷持續施壓。
    • 收尾選擇（大足 vs 電擊滾球 vs 蓄力垂直滾）：花 3 格氣取消綠衝後最穩是選「大足收尾接出奇前衝」，停在可摔距內 +8（對後受身也摔得到），能穩重疊「後中腳」兼顧退康與垂直跳；反之中電擊接中滾球只有 +3 壓起身極差幾乎不選。綠衝後想兼顧高傷與壓起身，可早點按「站重腳」並趁兩段判定期間按住下方向蓄力，第二段命中時取消接垂直翻滾（Up Ball）。

    嘉米

    • 螺旋飛箭（Arrow）為核心：2～3 下輕拳接螺旋飛箭後前衝，就能開始連續壓制；中距離常見起手是「蹲輕腳 → 蹲中腳 → 螺旋飛箭」，或蹲重拳命中強制站立後接後重腳。
    • 中螺旋飛箭後起攻：站中拳 → 中螺旋飛箭收尾後，前步（或前衝）接站中拳、蹲重拳或抓準時機的投技（現代模式在輔助弱接中螺旋飛箭後，可「前步 → 輔助中」壓滿幀數打亂動並循環；中足取消衝刺接大螺旋飛箭後則可接「前步 → 下強」壓滿幀數）；若跟對手站中拳互拼互換，可再接蹲中拳 → 重螺旋飛箭。
    • 遠距離與確認技巧：近距離接站重拳後立刻輸入 ↓↘→＋中腳，站重拳揮空時螺旋飛箭不會出、打中才會自動接出；對付愛起身反擊的對手，可用強化版螺旋飛箭（不接連段）再接輕流氓組合作二段壓制。

    春麗

    • 最基礎實用連段：站中拳 → 蹲中拳 → 特殊腳技，可在綠衝後或懲罰對手昇龍後使用；近距離也可用三下輕拳接迴旋鶴腳直接擊倒。
    • 不耗氣壓起身首選（迴旋鶴腳）：從「蹲輕腳 → 站輕拳」三段確認後，只要有下蓄力就改接輕版迴旋鶴腳（SBK），能不耗氣拿到優質倒地（輕百裂腳不倒地），之後前衝即可用後重拳（+7）或投技穩穩壓起身。

    迪傑

    • 迴旋後踢帶入二擇：命中後基本流程是「站中腳 → 蹲中拳 → 中迴旋後踢」擊倒對手，之後立刻進入擇壓制；站重拳取消必殺技前進後也能直接進擇。
    • 複合與拆摔應對：利用輕拳被擋 +2（影片所述，待驗證）的特性，接摔或用「↓↙←＋腳＋輕腳」打對手的解摔；綠衝停止畫面時輸入投擲還會自動轉成加強版挑空技。重版上踢（Jackknife Maximum）收尾後可往前衝壓制或直接前跳安全跳。

    達爾西姆

    • 低位鑽擊與火球：對手落地時低位命中鑽擊，可接瑜珈拱或瑜珈火球再接瑜伽轉移；斜下中腳滑行後接斜下後重腳與後必殺時，關鍵是拱形火球要在中腳之後命中。
    • 不耗資源與驅趕：不耗資源的倒地方式是在對方反擊時接輕拳重拳；被貼身時可用跳躍攻擊起手打倒對手，被防也不會被確反。

    埃德蒙本田

    • 尻壓後的有利壓制：尻壓命中後處於大幅有利，最基本是接墊步再按攻擊或投技；進階一點可接綠衝再接站中拳。注意改版後「尻壓 → 輕拳 → 尻壓」被擋會把人推開，已無法重複連壓。
    • 頭槌與近身循環：頭槌後用中拳接衝撞再接輕拳，對手想搶招很容易輸；近身壓制常用「中拳 → 輕拳 → 中拳 → 頭槌拉開 → 前重腳再接近」的循環。
    • 百貫落後自動對時：百貫落命中後立刻「揮空一次蹲輕拳」，會精準來到 +7F，之後指令投（打贏搶招與拆投）與站重腳（抓跳與後撤）皆為自動對時。注意「雙蹲輕拳 → 百貫落」對蹲姿對手會揮空，須改接中頭槌或輕百裂手；有手掌強化 Buff 時，極限技版百裂手不限站蹲都能穩接百貫落。

    艾德

    • 不需要綠衝也能壓起身：艾德的「殺戮步法（6踢踢）」是不耗資源的特殊前衝，用重昇龍或中／重念力迅擊拳擊倒後，直接用殺戮步法貼近就能站在有利位置進行打投二擇。
    • 主力確認與高性價比連段：站中拳命中可接輕腳三連，或「中拳 → 重拳」挑空後接殺戮步法／上勾拳／必殺技；近身搶動時因為重昇龍太慢接不到蹲輕拳，應改用輕版必殺技收尾。現代版可用「輔助重 → 極限技版紐 → 強紐 → 早出殺戮步法 → 強閃電拳」，被防也會拉近取得有利且實質回氣效率極高。
    • 安全跳路線：站近距離重腳接念力閃刺拳，再接重念力迅擊拳可做出安全跳並累積三級超必殺。

    艾蓮娜

    • 旋轉鐮刀與犀牛角踢：蹲重拳可接重旋轉鐮刀，再接中犀牛角踢（角落再補刮輪踢）；多數擊倒後（輕旋轉鐮刀、地面犀牛角踢、輕昇龍等）的壓起身情境都差不多，練熟一套就能通用。
    • 滾動派生與貼身壓制：確認命中 → ↓↙←＋踢 → 前拳 → 輕／中／重踢或空翻滾。進階滾要用「前重拳」派生才會滾得離對手夠近；若對手一直蹲防，滾動中按前輕拳或猛槌踢可打中段。實戰命中後常接「輕版翻滾×2 → 前輕攻擊」壓起身（被防仍貼身有利且在投距內）；純一鍵路線則可改「後翻滾×1 → 前重攻擊」打壓持續中段。
    • 花豹迅咬壓制：進階花豹迅咬壓起身就算被擋也能用蹲輕拳繼續壓制，命中就接完整連段，而且這條路線對「動力衝擊」反制更安全。

    蓋爾

    • 目標連段與距離取捨：站中拳 → 蹲中拳 → 中閃光踢可以連按完成；結尾選「重閃光踢」傷害高但推得遠（遇到對手後受身會失去起攻），改用「輕／小閃光踢」在對手後受身後依然能穩壓打擊／投／退康三擇且來得及防無敵技。想保留貼身壓制時，甚至可以不用超必殺收尾。
    • 換邊路線：在 DI 命中後改用「Drive Rush」換邊比單純前衝更強，因為 Rush 中途能煞車騙對手凹招；近距離高點命中閃光踢也能直接換邊。

    英格麗特

    • 穩定連段與壓起身：綠衝重腳命中後，最簡單接「中拳 → 中腳」目標連段再接中太陽旋昇，然後壓起身；角落衝擊命中可接「後重拳 → 重拳 → 太陽射擊 → 中太陽旋昇」（無氣也能做）。
    • 旋昇後接續：旋昇結束後前步接重腳可維持持續壓制；輕攻擊兩次接輕／中旋昇再接綠衝也能形成連續壓制。

    傑米

    • 站重腳懲罰與設置：輕攻擊兩下接蹲輕腳可穩穩接到站重拳；站輕腳接蹲輕拳連打幾乎無縫，對手想搶招會被反制。對局中也可先讓對手防住一招（如流水拳）再短暫停頓放重腳釣對手出招。
    • 不喝酒改留壓制與天晴腳混用：Lv1 用 LK Arrow Kick、Lv2+ 用 LK 結尾，雙前衝皆為 +4 幀（可同時覆蓋兩種受身）。適時混用 MK Arrow Kick（接 DR 6MK 中段被防 +3／命中 +7 接 2MP，或接 DR 2LP 空揮 → 5MP 被防 +3）與 HK Arrow Kick（空揮 5LP → 前衝 達 +4、空揮 2MP → DR 2MP 達 +6 進指令投區間；若天晴腳在較水平／後段幀擊中，雙前衝會多出額外有利幀直接進指令投或 5MP）。輕天晴腳擊中後也可改空揮 2HP 消費幀數，正好來到 +6 指令投黃金幀數。
    • Lv3 升 Lv4 凍結幀與 SA1／SA3 固定流程：改版後 SA1 結尾喝酒為 +4 幀（急降下踢或 OD 推掌接 SA1 可達 +7～+12 幀，但 OD 無影蹴接 SA1 需微延遲才不會漏段數）；若剛好從 Lv3 升至 Lv4 會產生額外凍結有利幀，升等後空揮 5LK 或 2MP 即可進入指令投／5MP 擇。SA3 後推薦統一用「生 DR → 微延遲 2HP」起手並分三種收尾：① 接 5HK 進穩定安全跳；② 接 輕推掌 → 2KK 飲酒壓起身；③ 接 2LP → DI 針對無 SA 的 Burnout 對手做必中暈眩重置。
    • Season 3 2LP DR 慣性改動與 Rekka 持續幀：因 2LP 生 DR 慣性延長 1 幀，舊有的「頭槌 TC（不喝酒）→ 空揮 2MP → 持續 5MP」會失準，需改為空揮 5LK 並手動微延遲出 5MP；另外 Rekka 後空揮 2LK（或 HK Rekka 後空揮兩下 2LP）可拿 +10 幀，讓持續 5MP 命中優勢從 +5 變 +8 接出 2MP/2MK。
    • SA3 後重置（Reset）變化：版中 SA3 → DR 天晴腳 浮空接 5LK 取消 DR 後，接 2LP 會留在前方壓持續、接 5LK 則穿過換邊壓持續；角落 SA3 → DR 天晴腳 → 2HP 取消 DR → 中段技 則會形成極難防的落地中段重置（防無敵 SA 可在天晴腳後停手防禦）。

    JP

    • 瞬移與高傷選擇：瞬移接跳重腳被防後立刻接跳輕腳，可形成連防中的中段／下段突襲，對手無法用無敵技插招；重攻擊能打到時建議改接跳點連段，傷害比目標連段更高。

    韓蛛俐

    • 站中拳為核心循環：韓蛛俐近身核心是站中拳，「站中拳 → 蹲中拳 → 取消中段必殺」打完後往前衝又能再接站中拳或投技，形成無限循環。現代模式在「輔助弱連段」具備自動命中確認且初段為下段，更新後「輔助中」也改成蹲中拳，能用「中 → 輔助中 → 後方必殺」單鍵存風波兼前衝無耗氣壓起身。
    • 綠衝與天穿輪起攻：對手倒地後綠衝過去，可用前中拳打中段，或用綠衝下輕腳／下中腳打下段；注意重拳系列會讓對手強制站立。強天穿輪收尾後可接生綠衝或「中拳空振」消費幀數取有利；壓起身想接投技時，最速投往往抓不到，要「稍微等一下（小步前進）」再投。

    肯

    • 迅雷腳與龍捲壓起身：蹲中腳接迅雷腳是推薦起手，對方站著接重式、蹲下接輕式；打中後可用綠衝前衝壓制（對手燒盡時特別強）。依位置選收尾：中央「奮迅龍捲」後接兩次前衝（66）是最靈活的壓起身，打、投、後跳任你選；近版邊「奮迅昇龍」前衝接重攻擊打亂動；想換邊可用「輔助中×4 → 強昇龍」。
    • 無綠衝穩定壓起身：掃倒普通命中後，前墊步接站重拳 → 蹲中拳 → 中龍捲旋風腳，是不耗氣最穩的選擇；另外「重龍捲／換邊火焰龍捲」後也可繞背或前衝壓制。
    • 角落壓制：角落重迅雷腳在對方反擊重拳後可接角落限定連段，被防也相對安全（注意與動力衝擊的互動見「說法不一」）。

    金伯莉

    • 丟罐（手裏劍）燒盡套路：擊倒後丟罐逼對手防禦，接「蹲中腳 → 站輕腳 → 輕流轉一文字」讓罐子爆炸，能狠狠消耗對手量表；重流轉一文字後接強化空中投 → 丟罐 → 前滑 → 中段攻擊也非常強力。
    • 近身接續：輕拳連打接輕腳、肘擊再接投；或站中腳／蹲中拳接跑步滑行施壓。

    莉莉

    • 有風與無風的壓制差：重鷹塔命中後前進就能形成極佳壓制；有「風之力」時，鷹塔被擋後近身仍是莉莉優勢，對手常不敢亂按，此時直接投或站輕腳接投就能形成無盡循環。

    盧克

    • 完美閃光拳與角落搬運：中央推薦「綠衝站重攻擊 → 完美重閃光拳」，角落搬運距離大，前墊步三次後仍非常有利；完美輕閃光拳後可接綠衝蹲重攻擊 → 蓄力中閃光拳 → 衝刺撞擊，再前墊步貼身施壓。
    • 場中／角落收尾切換：在場中想打退康或接 SA1 時，改用「弱閃光拳 → 重攻擊＋前墊步」比強閃光拳好（強閃光拳接追擊不在投距內且容易被起身精準撥擋）；「輕拳×2 → 閃光拳 → 昇龍」擊倒後立刻空揮「蹲中拳」即可穩定重疊投。
    • 不耗氣與近身：不耗氣可打蓄力輕閃光拳接蓄力重閃光拳（或略過重攻擊改衝刺撞擊直接站在對手身上壓起身）；近身也可用蹲輕拳連段接重昇龍擊倒後直接走近貼臉。

    拜森

    • 輕攻接炸彈要點：輕攻擊接輕炸彈「一定要從站輕腳取消」，靠前衝慣性才連得上（蹲／站輕拳只有完全貼臉才穩）。
    • 重炸彈與剪刀踢：重炸彈 → 綠衝 → 延遲中段攻擊 → 按住剪刀踢，好做又能補大量動力槽；起身後也可接後重腳 → 蹲輕拳 → 念力粉碎擊或炸彈。

    不知火舞

    • 無氣上大師核心循環：「蹲輕拳 → 蹲輕腳 → 站輕拳」可抓死防完第一下想走開的對手，接著以「輕腳肘擊／忍蜂（↓↘→＋輕腳）」收尾並前墊步接近，無論對手怎麼起身都能繼續打摔二擇。版邊強昇龍收尾後可空揮「輔助中」取 +4 有利；SA1 收尾後接前衝可取 +8 有利。
    • 強制站立與換邊：用後重腳強制對手站立，就能打出不受蹲站影響的穩定路線（如蹲中腳取消後重腳 → 蹲中拳 → 重龍炎舞 → 輕腳肘擊／重昇龍）。想換邊最實用是「後摔接綠衝」，或在對手跪地快倒下前接 OD 214P 再雙前衝。

    瑪濃

    • 獎章與下段突襲：常用「輕解離 → 生綠衝 → 後撤重拳連段」拿獎章跟傷害；預判對方防住後想跳，可接兩下蹲輕拳再接 ↓↘→＋重腳擊倒。站中腳被防後雖不適合直接接招，但可取消綠衝接蹲中拳繼續壓。

    瑪麗莎

    • 雙劍鬥士角落壓制：角落重雙劍鬥士後可直接後重拳打浮空，接著再做指令投二擇；偶爾也能用重雙劍鬥士第一下接蹲輕拳偷襲。

    拉希德

    • 緊密壓制與旋風設置：拉希德中段持續時間長，很適合在壓起身時疊加中段；角落常用目標連段（中拳接重腳）取消重阿拉伯旋風，或鷹襲後接二級超必殺逼對手起身防禦後再摔。壓制時注意別離對手太遠，輕攻擊三連後緊貼施壓最穩。

    隆

    • 輕攻擊＋重昇龍／輕龍捲基本套路：「輕腳 → 重昇龍拳收尾 → 中繼消費 → 站中拳」或「蹲輕攻擊連段 → 輕龍捲 → 前踏步輕波掌擊」是最穩的基本壓起身。注意壓起身時若想接「埋摔」，輕攻擊點 2 下比點 3 下更容易埋到摔，點 3 下容易太遠。若弱／中攻擊接龍捲後前衝在投距外，可改用蹲中拳壓搶招，或利用微遠距離原地不動騙對手拆投抓空氣後再用下重拳懲罰；「強波掌擊 → 生綠衝 → 後重攻擊 → 龍捲」前衝後則能直接最速重疊摔。
    • 中腳綠衝與波掌擊：中腳綠衝後以重波掌擊收尾（接中龍捲追擊再前踏步）是高階常用路線；前重拳接重型招式會縮短防禦後退距離，讓投技也能夠到。
    • 換邊與集中：背對角落動力衝擊反擊讓對手膝崩潰後，可透過連段接輕昇龍換邊；一級超必殺後也可保留集中狀態繼續壓起身。

    沙加特

    • 蓄力重昇龍與猛虎膝：蓄力重拳昇龍是不耗資源最高傷的強制倒地收尾，落地後可接中拳猛虎膝（場中 +2 且在投距內、可退康）或直接起手壓制；二級超必殺派生「下方向」可讓對手近距離倒地，直接進壓起身。版邊與其接「後重 → 強昇龍」，改接「強 → 中昇龍」傷害差距小卻能換取更佳的起身壓制狀況。
    • 跟進距離技巧：對手防住時若後重拳碰不到，先墊步前進再接後重拳 → 重猛虎膝 → 中昇龍，通常都來得及。

    泰瑞

    • 昇龍摔與能量衝鋒：輕版昇龍摔後接重版昇龍摔是主要擊倒來源，之後靠綠衝打二擇。場中從 Heavy Power Charge 帶入時，接三段 Heavy Crack Shoot 雖傷高但會打太遠失去起攻，實戰推薦改接「延遲 Heavy Burn Knuckle」（打在較低位置）兼顧推角與前衝三擇；進了角落就不需要換距離，可直接打三段 Crack Shoot。
    • 自動對時壓持續與不耗氣循環：重能量波命中後用中拳壓起身反擊，可接輕能量衝鋒連段或再次重能量波重疊循環；另從輕 Rising Tackle 對空或「2×站輕拳 → OD Quick Burn」等 +33~+36 擊倒後，可打出自動對時壓持續 Heavy Burn Knuckle（同時覆蓋原地與後受身）。

    維加

    • 炸彈安裝循環：維加的核心戰術就是「打中一次 → 安裝炸彈 → 引爆 → 再安裝炸彈」。無氣最大傷害收尾為中念力粉碎擊，之後前衝可直接用投擲壓過對手的 4 幀起身；若想防對手的延遲解摔，就混入輕拳、退康或延遲按鍵。
    • 版邊三種強度炸彈的專屬起攻：輕炸彈後揮空「站輕拳」接後重腳（可微延遲投或退康）；中炸彈後直接出「自動對時中段（Overhead）」命中 +5 可自然連入輕拳連段；重炸彈後「前衝 → 後重腳」（被擋 +1 且可退康或投）。若對手身上已有炸彈再補輕炸彈，接「輕念力粉碎擊」被防貼臉 +6 且對手起身開 DI 也來得及反打 DI！
    • 雙膝壓起手與 Devil's Reverse：學習維加的第一個目標是先練熟「輕／中雙膝壓」以及命中後的壓制循環（例如兩次蹲輕拳確認接輕雙膝壓）。此外 Shadow Rise 起跳後派生 Devil's Reverse 被防仍有 +4 幀有利可繼續摔或進攻，且出招後可用左右鍵調整前後落點讓對手難對空。

    桑吉爾夫

    • 近身立回與打樁機選擇：蹲揮擊或站中拳（建議只打第一段就停）命中後接螺旋打樁機、地獄插；貼身最大傷可接地獄插 → 極限技版西伯利亞特急（稍遠改用站輕腳）。
    • 裸綠衝壓起身套路：用螺旋打樁機或指令投擊倒後，可接「裸綠衝＋前中腳」壓起身（提早按空振 knee 可騙出時機直接接打樁機，尖端命中則可接輕攻擊連段或反衝擊）。
    • 角落輕攻擊交錯壓制：角落普通「拳拳」後交錯按「下輕手／下輕腳／下輕手」或「下輕手 → 後輕手」，是不需要體感的穩定壓制；若用動力衝擊把人撞上牆、對手位置太高時，改用前衝（66）追擊。

    五、說法不一與待驗證提醒

    以下為原影片資料中出現衝突、僅單一影片提及、或字幕辨識存疑的細節，實戰採用前建議先在訓練場實測確認：

    1. 說法不一（肯的壓制能否被動力衝擊打破）：有影片說「龍尾腳」壓制被防時不會被動力衝擊打破；另一支影片則說「角落重迅雷腳」壓制只有動力衝擊或中間插輕拳能打破。兩招特性不同，但實戰遇到對手愛凹動力衝擊時，建議先在訓練場錄製測試。
    2. 說法不一（泰瑞收尾取向）：有影片大推「中能量衝鋒」收尾優勢高；另一支影片則提到若想追求高傷害改走特定派生路線，起身壓制會變弱。兩者屬於「傷害 vs 起攻」的取捨。
    3. 隆的掃倒類型：有講者推測隆的掃倒命中後「可能」都是硬倒地，但未與其他來源交叉確認。
